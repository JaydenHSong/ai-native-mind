# 위키 보강 메모 (오케스트레이션·하네스·기획→구현·서버)

**날짜**: 2026-04-11  
**목적**: `ai-orchestration`, `harness-engineering`의 런타임·구현 공백 보완 + 패턴 2종 신설.

## 추가할 관점

1. **오케스트레이션**: 패턴(6종) 위에 상태, 멱등성, HITL, 타임아웃·재시도, 관측 훅.
2. **하네스**: 로컬 CLI 너머 — 배포 경계, 시크릿, 샌드박스, 스트리밍·비동기 잡.
3. **기획→구현**: 산출물 체인(의도→계획→설계→태스크→코드), 인간 게이트, 검증.
4. **에이전트 서버**: 동기 API vs 큐+워커, SSE, 상태 저장소, 서버리스 한계.

이 노트는 위키 페이지의 `sources`로만 쓰이며 별도 ingest 대상 원조 리서치는 아님.
