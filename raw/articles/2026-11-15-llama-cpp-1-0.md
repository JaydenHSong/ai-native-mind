# llama.cpp·ggml v1.0.0 출시 — 로컬 AI 추론의 안정 공개 API 약속 (11-13)

> ggml-org 팀이 11-13 llama.cpp v1.0.0과 그 아래 텐서 라이브러리 ggml v1.0.0을 출시했다. 프로젝트 시작(2023-03-10) 후 3년 반 만의 첫 1.0이다. 핵심은 속도가 아니라 약속이다. 앞으로 공개 C API를 깨는 변경은 메이저 버전 상승과 함께만 온다.

## 내용

- **버전 약속**: 두 라이브러리 모두 시맨틱 버저닝을 적용한다. MAJOR 상승은 공개 C API(`./include` 헤더) 변경, MINOR는 하위 호환 기능·백엔드 업데이트·모델 지원 추가·API 추가, PATCH는 API 변경 없는 버그 수정이다. 지금까지는 커밋 번호(b12359 등)로 버전을 매겼고 인터페이스가 수시로 바뀔 수 있었다.
- **정리**: 35개의 deprecated 공개 함수를 제거하고, warmup 설정과 defragmentation-threshold 옵션을 없앴다. NextN 추측 디코딩(speculative decoding) API를 확장 헤더(llama-ext.h)에서 메인 공개 헤더(llama.h)로 승격했다. ggml 1.0은 deprecated API와 레거시 DIAG_MASK 연산을 제거하고, 설정 가능한 YaRN truncation과 FP8 지원을 더했다.
- **기능**: FP8 키-값(KV) 캐시를 추가했다. Qwen2.5-7B 기준 32,768 토큰 KV 페이로드가 1,792 MiB에서 896 MiB로 절반이 된다(계산치). 호스트 메모리 MoE 전문가 캐시, 새 웹 UI도 포함됐다. llama-server는 SSRF·DNS 리바인딩·MCP 도구 취소에 강해졌다.
- **규모**: 150개 이상의 모델 아키텍처 변형을 지원한다. GitHub 스타 약 135,000개, MIT 라이선스. ggml-org 팀은 2026-02부터 Hugging Face 소속으로 프로젝트를 유지한다. v1.0.0은 빌드 b12359와 일치하고, 이후 빌드도 이미 나왔다. 릴리스 노트는 29,000자가 넘는다.
- **주의**: 공식 발표나 릴리스 노트에 전후 속도 측정 수치는 없다. 성능 개선 작업은 설명하지만 백분율로 제시하지 않았다.
