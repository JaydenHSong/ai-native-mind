# Google, Gemini 4 Argon 정식 출시 (GA) — 한시적 API 가격 $2/$10, Claude Opus 5.5 정가와 동일

> Google DeepMind SVP Koray Kavukcuoglu가 2026-10-13 Gemini 4 Argon의 정식 출시(GA)를 발표. 9/30 Fairwind 한정 출시의 후속. Google 공식 블로그 원문 + VentureBeat 교차 확인.

## 내용

- 출시 채널: 유료 Gemini API / AI Studio, Gemini 플랫폼 + Gemini for business, Gemini 앱 및 Search의 AI Mode (Pro/Ultra 티어), Google Antigravity (Ultra 전용).
- 모델 ID `gemini-4-argon`, stable. 입출력 통합 100만 토큰 제한 + 신규 "continuation protocol". 캐시 입력 95% 할인.
- 가격: 2026-11-30까지 한시적으로 입력 $2 / 출력 $10 (1M 토큰당). 이후 정가 입력 $4 / 출력 $20 — Claude Opus 5.5의 정가와 동일.
- Google 주장: Vals Index 1위, 내부 에이전트 코드 제출 +35% / 롤백 −30%, Antigravity에서 월 10만 명 이상의 Google 직원이 사용 중.
- Fairwind도 수백 개 파트너로 확대.

## 맥락

- [[concepts/gemini-4-argon]] — 2026-09-30 Fairwind 한정 출시 → 정식 GA 후속. 가격 전략(한시 할인 → Opus 5.5 정가 매칭)이 핵심 업데이트.
- [[comparisons/frontier-lab-economics]] — Claude Opus 5.5와 정확히 같은 정가 책정: "가격 결정력" 경쟁이 아닌 "가격 매칭" 국면. 한시 할인으로 API 채택 유도.
- 주의: Vals Index 1위·내부 생산성 지표는 Google 자사 발표. 독립 검증 지표와 구분해 볼 것.
