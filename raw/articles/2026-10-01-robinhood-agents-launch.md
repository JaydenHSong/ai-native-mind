# Robinhood Agents (9/29 HOOD Summit 발표, 9/30 보도) — 에이전트에게 실제 돈을 맡기는 상품화

> Robinhood가 9/29 HOOD Summit (Houston)에서 Robinhood Agents 발표: 앱 안에서 에이전트를 이름 짓고, 전용 agentic 계정을 열고, 모델을 고르고, 한도를 설정하면 시장 리서치·전략 수립·자동 매매 실행. 모델 선택지에 OpenAI GPT-6 계열·Anthropic Opus 4.8 (Fortune 인용).

## 안전 설계

- 거래 승인 기본값 ON (끄지 않으면 주문 전 승인 필요).
- 에이전트는 전용 계정의 자금만 접근 (메인 계정 분리).
- Robinhood는 에이전트를 감독·감사하지 않으며 손실 책임은 사용자라는 입장 (savingtoinvest 정리).
- "Loops" — 전략을 24시간 반복 실행하는 기능 예정.

## 채택 수치 — 출처 간 불일치 (양쪽 병기)

- PYMNTS: 5월 이후 agentic 계정 15,000+, 도구 사용 하루 ~3,000만 회.
- savingtoinvest: 150,000+ (8월 70,000의 2배+).
- 1차 확인 불가 — ingest 시 양쪽 병기 유지.

## 병행 발표·맥락

- 크립토 퍼페추얼 최대 10x (BTC·ETH, Bitstamp 경유), 주말 24/7 주식 거래 (규제 심사 대기), Cboe 기반 실적 이벤트 계약. HOOD 주가는 9/30 sell-the-news로 -3.2%.
- 5월 MCP로 서드파티 에이전트 연결 → 9월 인앱 내장. "에이전트에게 실제 돈을 맡기는" 메인스트림 금융 상품화의 첫 사례급.
- 별도 맥락: 8월 말부터 Claude가 Robinhood MCP 경유 매매를 거부한다는 사용자 보고 다수 — 플랫폼-모델 간 책임 경계 사례.
