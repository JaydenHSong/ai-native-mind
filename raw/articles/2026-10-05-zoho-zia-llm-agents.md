# Zoho, Zia LLM + 40개 Zia Agents 출시 (10/4)

> 인도에서 Nvidia 플랫폼으로 처음부터 훈련한 자체 파운데이션 모델. "right-sized 모델"로 비용을 낮추고 고객에게 전가 — Zoho식 에이전틱 AI 민주화 전략.

## 내용

- Zia LLM: Zoho 자체 대규모 언어 모델. 파라미터 1.3B / 2.6B / 7B 세 종, 오픈소스 동급 모델과 경쟁 성능. 구조화 데이터 추출·요약·RAG·코드 생성에 최적화.
- 전부 인도에서 Nvidia 플랫폼으로 훈련. CEO Sridhar Vembu (현 Chief Scientist): 내부 파운데이션 AI 구축으로 "세계 고객에게 첨단 도구를 더 낮은 비용으로".
- 함께 출시: 40개 프리빌트 Zia Agents, 노코드 에이전트 빌더 Zia Agent Studio, 서드파티 에이전트 연결용 MCP(Model Context Protocol) 서버.
- 영어·힌디어 저컴퓨트 최적화 ASR(자동 음성 인식) 모델 2종도 발표 — 향후 더 많은 언어 지원 계획.
- 전략 축: 프라이버시와 가치. Zoho 플랫폼의 제너릭 AI 모델은 소비자 데이터로 훈련하지 않고 고객 정보를 보관하지 않음. "은행을 털지 않는 right-sized 모델".

## 맥락

- 위키 tools/alibaba-agentcore(9/24)의 대척점: 알리바바가 'agentic cloud' 인프라로 간다면, Zoho는 '우리 모델을 직접 키워서 싸게' — 수직통합 vs 플랫폼.
- MCP 서버를 기본 탑재했다는 점에서 concepts/mcp와 직결 — Zoho의 에이전트 액션을 외부 에이전트와 연결하는 표준 채택.
- 10/4 raw의 DeepSeek open-weight 54→62% 흐름과 대비: 중국 오픈 웨이트 vs 인도 자체 모델 — '미국 외 LLM'의 다극화.
