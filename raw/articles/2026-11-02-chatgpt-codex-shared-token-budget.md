# ChatGPT·Codex, 12월부터 하나의 토큰 사용량 공유 — Work가 메인 채팅으로 합쳐진다 (OpenAI Help Center)

> OpenAI Help Center 'Understanding ChatGPT and Codex usage limits'(10-31 업데이트 포착)에 따르면, 12월부터 Plus·Pro·Business 플랜의 사용량은 ChatGPT와 Codex에서 공유된다. Work의 에이전트 기능이 메인 ChatGPT 경험으로 들어오는 과정의 일환이다. (OpenAI Help Center·THE DECODER·복수 보도 기반)

## 내용

- **공유 범위**: Plus·Pro·Business 플랜. 채팅과 코딩이 각각 별도 예산이던 구조에서 하나의 토큰 풀·하나의 리셋 시계로 바뀐다. API 플랫폼 키를 쓰는 개발자 과금은 별개로 보도됐다.
- **측정 단위**: 메시지 수가 아니라 토큰. 더 고성능 모델·복잡한 태스크일수록 더 빨리 소진된다. 플랜별 토큰 총량과 추가 크레딧 가격은 아직 공개되지 않았다.
- **예외**: Instant 채팅은 사용량에서 빠진다. 가벼운 질의는 계속 미터 밖이다.
- **확인 방법과 한도 도달 시**: 남은 사용량·리셋 시각은 Settings → Usage에서 합산 표시된다. 한도에 닿으면 리셋 대기, 플랜 업그레이드, 크레딧 구매 중 선택한다.
- **배경**: OpenAI는 이미 Chat·Work 병합을 예고했고, 최근 상위 플랜의 사용 한도를 2배로 늘렸다. Anthropic도 Claude에서 채팅과 Cowork를 통합한 바 있다. OpenAI는 "대부분의 사용자는 지금보다 리셋을 더 자주 기다릴 필요가 없을 것"이라고 전망했으나, 이는 보장이 아니라 예측이다.
