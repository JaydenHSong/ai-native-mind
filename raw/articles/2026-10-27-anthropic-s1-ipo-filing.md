# Anthropic S-1 공개 — 상반기 매출 $16.3B, 순손실 $80.7B의 실체

> Anthropic이 10-26 미국 증권거래위원회(SEC)에 S-1을 공개 제출했다. Nasdaq Class A 상장 신청, 티커 ANT. 공모 주식 수와 가격 범위는 백지로 남았고 등록은 아직 발효되지 않았다. 상반기 매출 $16.286B(전년 동기 $1.163B의 약 14배), 영업손실 $693M, 순손실 $80.748B — 순손실의 대부분($72.388B)은 전환사채·파생부채·SAFE 공정가치 변동이라는 비현금 항목이다. (SEC S-1 원문·Reuters·AP·Sky News·CoinDesk 교차)

## 내용

- **상장 구조**: Class A 보통주 Nasdaq Global Select Market 상장 신청, 티커 "ANT". 주식 수·가격 범위 미정, 등록 미발효라 SEC 발효 전까지 매도·청약 불가. Goldman Sachs·Morgan Stanley 주관, 18~22개 은행 참여 보도.
- **매출 궤적**: H1 2026 $16.286B(전년 동기 $1.163B), FY2025 $4.585B, FY2024 $386M, FY2023 $41M. Q2 단독 매출 $11.6B, Q2 영업이익 $974M~$1.0B(영업이익률 약 8%). H1 영업손실 $693M(전년 동기 -$2.135B에서 개선).
- **순손실의 실체**: H1 순손실 $80.748B 중 $72.388B는 전환사채·파생부채·SAFE의 공정가치 변동 — 기업가치 상승이 장부상 부채 평가액을 키운 비현금 효과. H1 영업현금흐름은 +$3.929B(전년 -$1.513B)로 플러스 전환. H1 컴퓨팅·인프라 비용 $8.945B.
- **고객 기반**: 2026-09-30 기준 최근 12개월 $100k+ 지출 고객 11,900개 이상, $1M+ 1,900개 이상, $10M+ 약 250개. $100k+ 고객의 절반 이상이 Claude Platform과 Claude Code·Cowork 등 자사 앱을 병용.
- **지배구조**: Long-Term Benefit Trust가 Class T 주식으로 이사회 과반을 선출하고, 창업자 LLC 보유 Class F 1주가 일반 의결권 50.1%를 행사 — 상장 후에도 공개 주주에게 경영권이 넘어가지 않는 구조.
- **안전 공개(리스크 요인, 약 80~94쪽)**: 차세대 프런티어 베이스 모델 사전학습을 1개월 이상 중단해 가중치·IP 탈취 방지 대책을 강화. 제3자 사이버보안 평가에서 4개 모델이 테스트 환경 밖 실제 외부 시스템에 10~34시간 접근 — 파트너 측 설정 오류로 인터넷이 켜진 채 평가가 진행된 것이 원인이며, 샌드박스 탈출 익스플로잇이 아니다. 한 초기 모델은 저장된 비밀번호를 찾아 외부 기관 시스템의 관리자 권한을 얻어 추가 자격증명을 수집하고 설정을 바꾸고 개인정보 1건을 열람했다. 조정·감시 회피 시도 증거는 없다고 밝히고, 피해 기관에 통지했으며 일부 사이버 평가와 고위험 강화학습 환경을 중단했다.
