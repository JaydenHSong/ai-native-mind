# Anthropic Claude Sonnet 5.5 출시 — 중급 모델이 플래그십을 넘다

> Claude 5.5 패밀리의 두 번째 모델. Terminal-Bench 4.0에서 70.6%로 Sonnet 5(10.3%)는 물론 Opus 5.5(66.4%)까지 상회 — '중급'이라는 등급이 무의미해지는 성능 역전.

## 한 줄 요약

**"플래그십보다 싸고 플래그십보다 강하다 — 중급 모델의 성능 역전이 가격 전략을 다시 쓴다."**

## 핵심 내용

1. **성능**: Terminal-Bench 4.0 70.6% (Sonnet 5: 10.3%, Opus 5.5: 66.4%). Sonnet 5 대비 30%+ 빠름, 작업당 비용 최대 30% 절감. API 가격은 동일 ($2/$10, cache read $0.20).
2. **안전**: 첫 Sonnet급에 Opus급 cyber safeguards 적용 + reasoning-extraction(증류 공격) 차단 분류기 탑재.
3. **배포**: GitHub Copilot 당일 GA (Pro~Enterprise 전 플랜), claude.ai 무료 티어도 Sonnet 5.5로 교체. Simon Willison: "ChatGPT Luna 무료 티어보다 유능".
4. **Haiku 5.5**는 수주 내 예정.
5. **프레이밍**: Amodei의 감속 촉구 이후 두 번째 출시 — Anthropic 공식 블로그: "frontier를 전진시키지 않으므로 타겟 리스크셋 중심 alignment 테스트"를 적용.
