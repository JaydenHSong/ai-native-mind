# Meta, Muse Wonder·Muse Wonder Full 프론티어 모델 출시 (에이전트 특화)

> Meta Superintelligence Labs가 2026-10-12 두 개 클로즈드 프론티어 모델 출시 — Llama 4 이후 첫 프론티어. Muse Spark 기반, Ohio Prometheus 데이터센터에서 훈련. 원문 전문 열람 + Reuters·Yonhap·TechCrunch·Artificial Analysis 교차 확인.

## 내용

- 출시: 2026-10-12. Meta Superintelligence Labs의 첫 프론티어 모델(Llama 4 이후). Muse Spark 기반, Ohio의 Prometheus 데이터센터에서 훈련.
- 라인업: Muse Wonder (Meta Model API + Muse Code에서 즉시 사용 가능), Muse Wonder Full (대형 모델, Muse Code 구독자 한정).
- 가격: API $4.00 / 1M 입력 토큰, $20.00 / 1M 출력 토큰 — Claude Opus 5.5와 동일 정가 (TechCrunch 경유 DX Today).
- 에이전트 특화: Active Memory(대화 간 사용자 컨텍스트 유지), Active Focus(장시간 멀티스텝 작업 지속, 중대한 행동 전 체크인), 1M 토큰 컨텍스트 윈도우.
- 벤치 주장: Harvey's Legal Agent Benchmark, FocusBench, SWE-Marathon 등 에이전트·코딩 벤치에서 SOTA 주장. 단 전체 안전성 평가 보고서는 미공개(발표 예정).
- 독립 검증: Artificial Analysis Intelligence Index — Wonder Full 56점 (Claude Opus 5.5 58, GPT-6 Astra 53).
- 시장 반응: 발표 후 Meta 주가 약 3~4% 상승 (Reuters).
