# DeepSeek, V4.1-Flash-1017 오픈웨이트 공개 — MIT 라이선스, Terminal-Bench 42.3·DeepSWE 77.0

> DeepSeek가 10/17 X를 통해 V4.1-Flash-1017을 발표 — 9월 V4.1-Flash의 마이너 업데이트. Hugging Face·ModelScope에 MIT 라이선스 가중치 공개, Search·Fetch 도구 API 신규 개방. 원문: MoneyToday(10/18), AIWeekly(10/17), AI Compass(10/17).

## 내용

- 출시: 2026-10-17 14:05 IST(X 발표). 763B 파라미터 MoE, 생성 시 활성 16B / 프리필 8B, 1M 컨텍스트, 출력 256K+ (HF 모델 카드).
- 벤치(자사 측정, 제3자 미검증): Terminal-Bench 4.0 31.2→42.3, DeepSWE v1.1 74.2→77.0, Automation-Bench 60.5, Agents' Last Exam 35.4, HLE(no tools) 42.6. 11개 테스트 중 4개에서 GPT-5.6 Sol·Claude Opus 5를 앞섰다고 주장(자사 테이블).
- 가격: 태스크당 비용 $0.5→$0.2 미만(자사 차트, 60%↓). API 출력 $0.6/1M 토큰(off-peak) — GPT-5.6 Sol $20, Claude Opus 5 $25의 약 1/42.
- 신규: Search·Fetch 도구 API $0.75/1,000 성공 호출; DeepSeek Harness·Claude Code·Codex 경유 서버측 호출은 10-31 16:00 UTC까지 무료.
- HF 공동창업자 Thomas Wolf(CSO) X 발언: "'소규모 업데이트'라 부르는 게 정말 웃기다(Terminal-Bench 31.2→42.3)… 내부 평가 밖에서도 유지될지 궁금하다."
