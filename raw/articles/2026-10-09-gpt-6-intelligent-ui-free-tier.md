# GPT-6 + Intelligent UI, Free/Go 티어로 확대 — 전 티어 롤아웃 시작 (10/8)

> OpenAI가 10월 7일 발표한 GPT-6의 ChatGPT 전 티어 롤아웃: Plus·Pro·Business·Enterprise는 10/7부터, Free·Go는 10/8부터. 새 기능 'Intelligent UI'는 답변이 텍스트를 넘어 차트·폼·탭 가능한 버튼 등 인터랙티브 인터페이스가 되게 함. 유료 티어는 GPT-6 Sol, Free/Go는 GPT-6 Luna 탑재.

## 내용

- 롤아웃: 2026-10-07 전역 시작. Plus·Pro·Business·Enterprise → GPT-6 Sol, Free·Go → GPT-6 Luna. 둘 다 일상 대화 튜닝. Enterprise는 워크스페이스 관리자 설정에 따름. Chat 경험에만 적용 — Work·Codex 뒤 모델은 변경 없음.
- Intelligent UI: 질문에 따라 응답 형식을 선택 — 비교는 나란히 배치, 설명은 인터랙티브 다이어그램, 레시피 타임라인·여행 경로 지도·계산기·청구서 분할·간단 게임 등 대화 안에 작은 도구 생성. 스트리밍 가능한 네이티브 컴포넌트 라이브러리 + 출력 생성 중 인터페이스를 컴파일하는 컴파일러로 점진 렌더링.
- 속도: GPT-6 Instant는 웹 서치 질문에서 GPT-5.6 Instant보다 평균 44% 빨리 답변 시작(회사 주장). 추론·툴 사용 중에도 먼저 답변 시작, 나중에 추가 발견분을 붙이는 방식. 작업에 따라 포맷을 바꾸는 것이 목표.
- 안전: 간접 프롬프트 인젝션 강건성 Sol 97.13%, Luna 95.80%(회사 주장). Astra의 안전 진전 계승, 사이버·생물 위협·폭력 관련 고위험 오용 방어 강화. 정직·능력 한계 인식 정렬 평가 포함.
- 구분 주의: Pro 추론 옵션은 GPT-6 Astra를 계속 사용하며 Intelligent UI 미지원 — Pro 구독과 Pro 추론 옵션은 별개 라벨.
