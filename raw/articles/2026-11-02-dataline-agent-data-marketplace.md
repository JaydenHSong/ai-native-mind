# Dataline, 에이전트용 데이터 마켓플레이스 확장에 $10.6M 조달 — x402 호출당 과금 (PYMNTS, 11-01)

> Dataline이 에이전트용 탈중앙 데이터 네트워크 확장을 위해 1,060만 달러를 조달했다고 10-31 보도자료로 밝혔다. 누구나 데이터 피드를 올리고, 어떤 에이전트든 x402로 호출당 결제해 쓰는 양면 마켓플레이스가 골자다. (PYMNTS·회사 보도자료 기반)

## 내용

- **조달**: 1,060만 달러. Lattice와 Samsung 지원 Dispersion Capital이 공동 주도했고 Symbolic Capital이 참여했다.
- **모델**: 라우팅 계층으로서 API 응답에 출처 신뢰도·신선도·일관성 기반의 AI 신뢰도 점수를 함께 제공한다. 가격·펀딩·포지션·예측시장 등 스킴 정규화된 피드를 에이전트 네이티브 실행용으로 내놓는다.
- **규모(회사 발표)**: 온체인 트랜잭션 1,940만 건, 커뮤니티 30만 명 이상. 독립 검증은 없다.
- **생태계**: AI Data Launch 파트너 1기 코호트를 조직했고, Base와 Robinhood Chain 위의 빌더에게는 무료 접근을 제공한다.
