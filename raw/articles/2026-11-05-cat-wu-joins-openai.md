# Cat Wu, Claude Code 제품 책임자 OpenAI로 이직 — Core Products 총괄 (11-05 발표)

> Anthropic에서 Claude Code와 Cowork의 제품 책임자를 맡았던 Catherine "Cat" Wu가 OpenAI로 옮겨 Core Products 제품 관리를 이끈다고 11-05 X에 발표했다. 10-30이 마지막 근무일이었고, 발표까지 일주일도 안 걸렸다. Anthropic 상장(나스닥 ANT, 10-26 S-1 공개)을 앞둔 시점의 핵심 인력 이탈이다.

## 내용

- **이동**: Wu는 OpenAI Core Products 제품 관리 책임자로 합류한다. Core Products를 이끄는 Thibault Sottiaux 아래에서 일하며, Nick Turley(기업 제품)·Ashley Alexander(소비자 제품)와 나란히 한다. 본인이 밝힌 우선순위는 "사용자를 통제권 안에 두면서 시간을 벌어주는 신뢰할 수 있는 에이전트" 개발이다.
- **이력**: 2024년 8월 Anthropic 합류, 연구 제품 관리에서 시작해 Claude Code가 작은 내부 도구이던 시절부터 제품화를 이끌었다. 2025년 Claude Code 제품 책임자가 됐고 이후 Cowork·Tag도 맡았다. 2025년 한 차례 Cursor로 떠났다가 복귀한 전력이 있다.
- **시기**: 11-03 X에 "금요일이 마지막 날"이라고 퇴사 발표, 11-05 OpenAI 합류 발표. Anthropic은 퇴사를 Business Insider에 확인했고, OpenAI는 영입을 확인했다. 후임자는 아직 발표되지 않았다.
- **연쇄 이탈**: 같은 주 Claude Code 엔지니어 Thariq Shihipar와 Anthony Morris도 하루 간격으로 퇴사를 발표했다. 매체 정정 기준 Wu는 "2주 내 세 번째"가 아니라 두 번째 이탈이다.
- **상장 맥락**: Anthropic은 10-26 S-1을 공개했고 11-02 수정 제출서류(S-1/A)에서 Q3 매출 약 $17B를 밝혔다. 상장은 이달 말로 예상된다. Wu 본인은 퇴사 글에 "post agi!"라고 적었다.
