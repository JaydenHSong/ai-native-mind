# LM Studio ships Agent Canvas — an interactive space you and the agent both edit

## 한 줄 요약

**"에이전트 협업의 인터페이스가 채팅에서 '공유 캔버스'로 — 사람이 그려 주고, 에이전트가 구현한다."
**

## 핵심 내용

1. **Agent Canvas**: 사용자와 에이전트가 **둘 다 보고 둘 다 편집**할 수 있는 인터랙티브 공간.
2. 용도: 플로우차트·프로세스 매핑·시스템 설계·목업 협업.
3. 워크플로우: 목업을 함께 다듬은 뒤 **Bionic에게 구현을 요청** — 설계와 구현 사이의 handoff를 같은 화면에서.
4. 로컬 실행 기반(LM Studio)의 인간-에이전트 협업 surface 확장.

## 시사점

- 협업 패턴의 진화: 채팅(순차 턴) → 공유 캔버스(동시 편집 공간). HITL의 "승인 게이트"가 아니라 **공동 작업 공간**으로.
- `[[patterns/claude-md-guide]]` (CLAUDE.md = 정책 객체) 흐름과 대비: 정책은 텍스트로 고정, 설계는 캔버스로 공동 편집 — "무엇을 어디에 남기는가"의 분리.
- `[[concepts/context-engineering]]` 관점: 캔버스는 **공유 컨텍스트 surface** — 에이전트와 인간이 같은 artifact를 바라본다는 것이 신뢰·감독의 전제.
