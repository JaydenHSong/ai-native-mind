# DigitalOcean, Agent Learning Services + Agent Data Services 출시

> 2026-10-12 발표 (Business Wire 회사 릴리스) → HPCwire 10/12 교차 확인. Open Intelligence Summit(샌프란시스코, 10/13) 앞두고 공개.

## 내용

- Agent Learning Services = 3제품 루프: Insights(에이전트가 무엇을 했는지 기록) → Signals(부족한 지점 플래그) → Evaluations & Simulations(고객 노출 전 변경사항 테스트). public preview.
- Agent Data Services = 에이전트 컨텍스트용 완전 관리형 데이터 레이어 (private preview). Inference Router 옵티마이저도 private preview.
- 사례: Amplitude CEO Spenser Skates 인용 — DigitalOcean Managed Agents가 Amplitude Wave("에이전틱 제품 팀")를 구동.
- 포지셔닝: "에이전트가 실행·학습·개선되는 몇 안 되는 클라우드 중 하나" (Inference Engine + Managed Agents와 함께).

## 맥락

- [[concepts/gen-ai-observability]] — 관측→탐지→테스트 루프가 클라우드 상품으로 패키지화. 에이전트 관측성이 범용 인프라가 되는 신호.
- [[patterns/agent-safety-runtime]] — Simulations(고객 노출 전 테스트)는 실행시점 안전 런타임의 사전 단계.
