# Replit CEO 'Anthropic과 더 이상 협력 안 한다' — 비용·성능 이유로 OpenAI로 전환, 단 내부 반박도

> TechCrunch Disrupt 10/16 무대에서 Replit CEO·공동창업자 Amjad Masad 발언 — TechCrunch 기사(페이지 스탬프 2026-10-16T21:22:28Z / 업데이트 22:50:05Z), Unite.AI(10/16, 세션 녹취). **사실관계 논란 중**.

## 내용

- 발언: Replit이 Anthropic과 'no longer working' — 이유: **비용(cost), 파트너십(partnership), 성능(performance)**.
- 인용: 'I think ChatGPT is better now... consistently, Sol and Astra perform better on building vibe-coded applications from scratch'.
- 근거 주장: 내부 VBench + 공개 벤치마크.
- 배경: 2026-08 Replit×OpenAI 파트너십 발표 (Free Mode가 GPT-5.6 Luna 기반).
- 반박: 익명의 내부 인사가 TechCrunch에 파트너십 '여전히 유효(still in place)'라고 반박 — **서로 상충하는 주장, TechCrunch가 추가 확인 대기 중**.
- 배치 중인 모순: 9월 말 Replit 블로그는 Replit Agent 프로덕션에 **Claude Fable 5/5.1**을 명시. Masad는 Replit이 Anthropic의 **상위 5위 고객** 중 하나라고 주장.
- 재무 맥락: 엔터프라이즈 계약이 매출의 약 15% (전년 ~2%), B2B 비중 50%+, NRR 400%+.
