# 골드만삭스, AI 코딩 도구를 엔지니어로 축소 — 트레이더·뱅커 접근 회수 (Bloomberg 경유, 11-02)

> 골드만삭스가 10월 내부 지침으로 Anthropic의 Claude Code와 Microsoft의 GitHub 코딩 도구를 사실상 엔지니어에게만 한정했다. 트레이더·뱅커의 '바이브 코딩' 실험을 접은 것이다. 11-02 Bloomberg 보도 건으로 11-03 정리에서 누락된 따라잡기 수집이다. (Bloomberg 원문은 유료, PYMNTS·Decoder 요약 경유)

## 내용

- **조치**: Claude Code와 Microsoft GitHub 도구에 대한 접근을 엔지니어 중심으로 제한한다. 하이브리드 퀀트-엔지니어 그룹인 'strats'는 계속 사용한다. 전체 직원 약 47,000명 중 엔지니어는 약 12,000명이다.
- **배경**: 수개월간 트레이더·뱅커가 도구를 써서 고객 거래 흐름을 추적하고 포지션을 모델링하며 문서·그래픽 초안을 만들었다. 7월 CIO Marco Argenti는 비기술 직원의 바이브 코딩을 공개적으로 장려했고, 엔지니어가 이를 다듬는 인계 구조를 그렸다.
- **이유(회사 설명)**: 대변인 Nick Carcaterra는 "실험 기간을 거쳐 생산성과 리스크 관리를 포함한 여러 요소를 평가"한 뒤 "장기적으로 가장 잘 활용할 수 있는 사람들"에게 도구를 맡긴다고 밝혔다. 보안 사고 공개나 정량적 생산성 평가는 없었다.
- **아닌 것**: 골드만이 Anthropic을 끊은 것이 아니다. 방화벽 안에서 여러 회사 모델(Claude 포함)로 돌아가는 자체 GS AI Assistant는 전 직원이 계속 쓴다. 제한된 것은 외부 에이전트가 직접 코드를 쓰고 실행하는 코딩 도구다.
- **대비**: BNY는 자체 Eliza 플랫폼에서 비엔지니어의 구축을 허용하고, Deutsche Bank는 전문 개발자에게만 두되 주당 1.5~2.5시간 절감 효과를 밝힌다. MUFG는 Claude Code가 정보 접근 제한을 우회할 수 있다며 자체 대안을 만들었다고 전해진다. 4월에는 홍콩 뱅커 대상 Claude 접근을 이미 제한한 바 있다.
