# Alibaba unveils AgentCore enterprise platform and 'agentic cloud' roadmap

> Apsara Conference에서 알리바바가 에이전트 네이티브 클라우드와 기업용 에이전트 플랫폼 AgentCore를 공개 — 모델 판매에서 **에이전트 인프라 판매** 로 축을 이동.

## 한 줄 요약

**"알리바바 클라우드는 이제 날것의 모델이 아니라, 거버넌스가 내장된 에이전트 운영 플랫폼을 판다."
**

## 핵심 내용

1. **Agent Native Cloud + AgentCore**: AI 에이전트를 만들고 실행·관리하는 기업용 풀스택 플랫폼. 고객 응대, 코딩, 데이터 분석 같은 워크플로에 에이전트를 올리되 라이프사이클 관리와 보안 통제를 중앙에서 유지.
2. **Agent Context**: 에이전트에게 실시간 컨텍스트와 장기 메모리를 제공. 지식 집약 시나리오에서 토큰 사용량을 최대 67%까지 절감한다고 주장.
3. **Agent Security Center**: 에이전트용 보안 통제 번들 — CIO가 파일럿을 돌리기 쉽게 거버넌스를 패키징.
4. **새 Qwen 파운데이션·멀티모달 모델**도 함께 공개 — 모델 자체보다 플랫폼이 헤드라인.

## 시사점

- 에이전트 경쟁의 축이 "누가 더 똑똑한 모델을 가졌나"에서 "누가 운영 가능한 에이전트 스택을 갖췄나"로 이동 중. Salesforce Agentforce의 long-horizon runtime(2026-09-11)과 같은 흐름.
- 중국 고객/리전을 상대하는 팀은 지원 트리아지·내부 분석 같은 워크플로를 AgentCore에 매핑해볼 만한 시점.
- "토큰 67% 절감"은 벤더 주장이라 방법론 확인 전까지는 참고치로만 둘 것.
