# 미 의회, AI 칩 수출통제 강화 추진 — NDAA에 3개 법안 포함 전망, OpenAI 지지 (11-15)

> Financial Times 보도(11-15~16)에 따르면 AI 칩 수출통제 강화 3개 법안이 연말 국방수권법(NDAA) 최종안에 포함될 가능성이 커졌다. 배경은 Jensen Huang 축출(11-12)과 Megaspeed 밀수 의혹이다. OpenAI는 11-12 세 법안에 대한 공개 지지를 밝혔다. 법안 통과가 확정된 것은 아니며, FT 원문은 직접 확인하지 못해 Newsmax의 FT·Reuters·SCMP 인용에 의존한다.

## 내용

- **3개 법안**: AI OVERWATCH Act(수출 규칙 변경에 대한 의회 심사 강화, 최강 칩 수출 18개월 동결안 포함), Chip Security Act(칩 위치 추적·밀수 방지 의무), MATCH Act(동맹국의 첨단 칩 제조 장비 대중국 판매·서비스 제한 압박). 네 번째로 Remote Access Security Act(원격 클라우드 경유 칩 접근 차단)도 거론됐다.
- **입법 상황**: 상원 NDAA안에 3개 법안이 이미 포함돼 있고, 하원 외교위원회는 Chip Security Act를 만장일치(42-0)로 통과시켰다. 초당적 공동발의 56명(상원 Banks·Warren 주도). 11-15 기준 최종안 포함 가능성이 크다고 FT가 보도했으나 통과 확정은 아니다.
- **배경**: Huang 축출(11-12, Megaspeed 임원 Alice Huang과의 관계 + 중국 정보기관 연루 의혹), NYT 보도(상무부의 Nvidia 칩 밀수 조사 중단 의혹). Huang은 추수감사절(11-26) 전 의회 증언 예정이며, Nvidia 법무총괄·상무부 수출통제 책임자도 소환 대상이다.
- **OpenAI 지지**: OpenAI는 11-12 세 법안에 대한 공개 지지를 밝혔다. Huang 축출로 수출통제 강화의 오랜 반대자가 사라지면서 워싱턴 역학이 바뀌었다는 평가다.
