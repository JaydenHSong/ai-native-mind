# Amazon Q3 — AWS +39%로 5년 만의 최고 성장, Trainium은 2027년 말 외부 판매

> Amazon이 10-29 장 마감 후 Q3 실적을 발표했다. 매출·EPS는 컨센서스를 소폭 밑돌았지만 AWS는 39% 성장으로 5년 만의 최고 속도를 냈고, 영업이익률은 사상 최고 13.9%를 기록했다. 같은 실적 콜에서 앤디 재시 CEO는 2027년 말부터 Trainium 칩을 AWS 외부에 직접 판매하겠다고 밝혔다. (Amazon 실적 발표·실적 콜·Reuters 교차)

## 내용

- **전체 실적**: 매출 $2,019억(전년 +12%, 컨센서스 $2,023억 소폭 하회), EPS $1.89(예상 $1.96 하회). 영업이익 $281억(+61%), 영업이익률 13.9%로 사상 최고. 순이익 $207억으로 전년 $212억보다 소폭 감소했는데, 전년 분기에 $95억의 Anthropic 지분 평가이익이 포함됐기 때문이다.
- **AWS**: 매출 $460억(+39.3%, 6분기 연속 가속, 5년 만의 최고 속도), 영업이익 $178억(마진 38.7%, 전년 $114억에서 +55%). 연간 run rate $1,840억, 전체 영업이익의 약 63%를 전체 매출의 약 23%에서 냈다. 백로그는 $5,780억으로 전년 대비 2배 이상이다.
- **전망**: Q4 매출 가이던스 $2,400억~$2,470억, 영업이익 $285억~$335억. 재시는 AWS 성장률이 2027년·2028년 모두 40%를 넘길 것으로 전망했고, 2027년은 대부분 매진, 2028년도 상당 부분 이미 계약됐다고 밝혔다. 2026년 현금 capex 가이던스는 약 $2,200억을 유지했고, 2027년에는 "의미 있게 더" 쓸 계획이다.
- **Trainium 외부 판매**: 재시는 2027년 말부터 Trainium 랙을 외부 데이터센터에 직접 판매하겠다고 실적 콜에서 밝혔다. 지금까지 Trainium은 AWS 임대로만 제공됐고, 외부 판매는 Nvidia와 직접 경쟁하는 첫 하드웨어 사업이 된다. Graviton·Trainium의 매출 약정은 각각 전년 대비 20배 이상 늘었고, Bedrock의 대부분이 이미 Trainium에서 돌아간다고 밝혔다. 다만 재시는 외부 판매보다 내부 활용이 5~6년 누적 수익·현금흐름이 더 크다는 절충도 함께 언급했다.
- **주가 반응**: 실적 미스에도 AWS 가속이 부각됐지만, 시간외 주가는 약 6~11% 하락했다는 보도가 엇갈린다(매체별 집계 시점 차이). 현금흐름 방향이 심판 기준이 된 하루였다.
