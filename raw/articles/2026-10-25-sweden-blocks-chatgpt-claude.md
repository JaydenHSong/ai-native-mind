# 스웨덴 정부, ChatGPT·Claude 업무용 PC 차단 — Copilot만 승인, 10-26 시행

> 스웨덴 정부청(Regeringskansliet)이 10-26부터 업무용 PC에서 ChatGPT·Claude 웹 접속을 차단하고 Microsoft Copilot을 유일한 승인 도구로 지정. 원보도는 스웨덴 공영라디오 Ekot(10-23), 영어권 보도는 10-24~25 확산. 이유는 모델 자체의 위험이 아니라 '정식 계약 없는 사용'이라는 정보보안 판단. 일부 직원은 정부 자체 구축 AI 플랫폼(Intric 경유)으로 두 모델에 계속 접근 가능. (Ekot 원보도·CEOWORLD·Decrypt·Bytes Europe·SVT 교차)

## 내용

- **조치**: 10-26(월)부터 정부청 직원 업무용 컴퓨터에서 ChatGPT·Claude 브라우저 접속 차단. 개인 기기·재택 PC는 언급 없음. Copilot은 보안 검토 후 설정 강화가 이뤄져 승인됨 — 강화 내역은 보안상 비공개.
- **근거**: 디지털화 국장 Mikael Wettercrantz의 직원 인트라넷 게시 — '계약 없이 AI 서비스를 쓰면 정보보안에 영향을 미칠 수 있다'. 민감 정보 입력 사례와 AI 답변 처리 문제 사례가 확인됐다고 밝힘. 미국법상 외부 서버 데이터 제공 강제 가능성도 배경.
- **예외 경로**: 일부 직원은 정부 자체 AI 보조 플랫폼을 통해 ChatGPT·Claude 모델 자체는 계속 이용 — 차단 대상은 '계약 없는 소비자형 경로'이지 모델 자체가 아님. 해당 인원·가드레일은 미공개.
- **선행·확산**: DeepSeek은 이미 제한됨. 국세청(Skatteverket)·국가시설관리위원회(SiS)도 유사 차단, 집행청(Kronofogden)은 결정 준비 중. 교통청 감사에서는 10개 오픈 AI 서비스가 '광범위하고 위험하게' 쓰인 것으로 파악.
- **주의**: '금지'가 아니라 '승인 도구만 사용'이라는 조달·계약 관점의 거버넌스 사례. Copilot에 Claude 모델이 탑재된 점과의 관계는 스웨덴 측 확인 없음.
