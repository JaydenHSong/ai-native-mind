# Microsoft·Alphabet Q3 실적 갈림 — Azure +48%와 현금흐름, 클라우드 2배와 마이너스 현금흐름

> 10-28 장 마감 후 같은 날 발표된 두 빅테크 실적이 정반대 반응을 낳았다. Microsoft는 매출·EPS·Azure·현금흐름 모두 예상을 넘기며 시간외 약 +4%, Alphabet은 매출·EPS 미달과 마이너스 현금흐름에 시간외 약 -10%를 기록했다. AI 수요 자체는 양사 모두 "공급이 수요를 못 따라간다"고 했지만, 시장은 그 수요를 어떤 재무 상태로 감당하느냐를 갈랐다. (Microsoft·Alphabet 실적 발표·Reuters·CNBC 교차)

## 내용

- **Microsoft(FY27 Q1, 9월 말 분기)**: 매출 $92.3B(전년 +19%, 예상 $90.7B 상회), 조정 EPS $4.89(예상 $4.73 상회), 순이익 $36.6B. Azure 매출 $33.17B(전년 +48%)로, Microsoft가 Azure를 달러 금액으로 처음 공개했다. Microsoft Cloud 매출 $63.9B(+30%), 영업이익 $45.9B. 자본지출은 $39.4B(리스 포함 $45.2B)로 우려보다 낮았고, 잉여현금흐름은 $18.6B로 예상($8.54B)을 크게 웃돌았다.
- **Alphabet(Q3, 9월 말 분기)**: 매출 $127.6B(전년 +25%, 예상 $128.2B 미달), 조정 EPS $2.67(예상 $3.02 미달), GAAP EPS $2.12(전년 $2.87에서 하락 — $8.7B 규모의 지분증권 손실이 기타수익을 -$8.2B로 뒤집었다). 검색 매출 $63.4B와 유튜브 광고 $11.2B도 예상을 밑돌았다.
- **Alphabet 클라우드의 역설**: Google Cloud 매출 $30.71B(전년 +103%)로 Azure 성장률의 2배를 넘겼고, 클라우드 영업이익도 $11.1B로 전년 $3.6B의 3배가 됐다. 그럼에도 분기 자본지출 $51.4B가 현금흐름을 -$9.07B로 밀어냈고, 이는 2분기 연속 마이너스다. Alphabet은 분기에 $28.7B 선순위채를 발행하고 $12.4B 주식을 매각했으며, 자사주 매입을 중단했다.
- **지출 가이던스**: Alphabet은 2026년 자본지출 가이던스 $195B~$205B를 유지했고, 2027년에는 "크게(significantly)" 늘어날 것이라고 밝혔다. Microsoft 쪽에서는 다음 분기 Azure 가이던스가 49~50%로 거론됐다.
- **AI 모드 수익화 단서**: Google은 AI Mode 검색의 수익화가 아직 일반 검색보다 낮다고 밝혔다. 검색 성장률은 약 12%였다. Gemini 앱 사용자 10억 명, 자사 모델 API 약 분당 320억 토큰 규모도 함께 언급됐다.
