# DeepL, 음성→음성 직통 번역 모델 Aure v2 출시 — 지연 50% 단축 (11-26)

> DeepL이 11월 26일 도쿄 첫 Unmute Summit에서 음성 AI 번역 모델 Aure v2를 출시했다. 말→글→번역→음성의 3단계를 거치지 않고 음성을 번역된 음성으로 직접 바꾸는 엔드투엔드 구조로, 전작 대비 중앙값 번역 지연이 50% 줄었다고 한다. DeepL Voice 고객에게 즉시 제공.

## 내용

- **구조**: 엔드투엔드 음성→음성 모델 + 강화학습. 기존 파이프라인(받아쓰기·번역·음성합성)의 단계 간 핸드오프를 없애 지연을 줄이는 방식. 번역된 음성이 화자의 리듬·억양·강조를 유지한다고 함.
- **수치(자사 주장)**: 전작 Aure 대비 중앙값 번역 지연 50% 감소. DeepL 내부 연구(2026년 11월, 10개 언어쌍·1분짜리 실제 음성 녹음, 인간 검증 전사본) 기준, 번역된 단어의 절반이 3.3초 안에 들린다고 함. 6개 경쟁 시스템 대비 전 언어쌍에서 품질 우위 주장 — 모두 자사 측정, 독립 검증 없음.
- **언어**: 출시 시 6개 — 영어·독일어·프랑스어·스페인어·일본어·한국어. 추가 언어 예정.
- **제공 범위**: DeepL Voice for Online Meetings(Teams·Zoom·Meet), Voice for In-Person Conversations, DeepL API for Voice. 지원 언어에서는 자동으로 켜지며 별도 설정 없음. 가격은 미공개.
- **속도**: 전작 Aure는 11월 11일 출시 — 불과 15일 만의 후속. DeepL Voice 사용량은 2026년 3분기 기준 전년 대비 음성 분 8배 이상, 번역 회의 분 7배가량 증가.

## 맥락

- 음성 에이전트·실시간 통역의 '지연' 경쟁: Grok Voice 3.0 등 음성 AI 축과 같은 흐름. 3단계 파이프라인을 단일 모델로 합치는 건 음성 에이전트 전반의 방향
- 모든 성능 수치는 자사 내부 연구라 위키 정제 시 confidence는 medium 이하로 둘 것
