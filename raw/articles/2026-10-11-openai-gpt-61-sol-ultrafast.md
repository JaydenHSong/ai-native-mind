# OpenAI, GPT-6.1 Sol에 'Ultrafast' 속도 티어 추가 (10/8)

> OpenAI가 GPT-6.1 Sol Ultrafast를 API·Codex·ChatGPT Work에 출시: 표준 대비 최대 8배 빠른 토큰 생성, API 가격은 표준의 6배($12/1M 입력, $60/1M 출력). 접근 제한: Pro 500 구독자·사용량 기반 Enterprise·크레딧 기반 Edu 플랜에 한해 Work/Codex 제품 접근, Pay-as-you-go 개발자는 API에서 이용 가능. US·EU 데이터 레지던시 지원. 개발자 불만 포인트: 고속 모드에서 토큰 소비 급증 우려, 현재 티어에서 선택이 아닌 상위 플랜으로 업그레이드 강제라는 지적.

## 내용

- 출시: GPT-6.1 Sol Ultrafast — API·Codex·ChatGPT Work 대상. 표준 대비 최대 8배 빠른 토큰 생성.
- 가격: API 기준 표준의 6배 — $12/1M 입력 토큰, $60/1M 출력 토큰.
- 접근: Pro 500 구독자·사용량 기반 Enterprise·크레딧 기반 Edu 플랜에 한해 Work/Codex 제품 접근. Pay-as-you-go 개발자는 API에서 이용 가능. US·EU 데이터 레지던시 지원.
- 개발자 불만: 고속 모드에서 토큰 소비 급증 우려, 현 티어에서 선택이 아닌 상위 플랜 업그레이드 강제라는 지적.
