# OWASP Top 10 for Agentic Applications 2026 (ASI01–ASI10)

> 출처: [OWASP Gen AI Security Project 공식](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/) · [공식 발표 (2025-12-09)](https://genai.owasp.org/2025/12/09/owasp-top-10-for-agentic-applications-the-benchmark-for-agentic-security-in-the-age-of-autonomous-ai/) · [DeepTeam 정리](https://www.trydeepteam.com/docs/frameworks-owasp-top-10-for-agentic-applications) · [Palo Alto Networks 분석](https://www.paloaltonetworks.com/blog/cloud-security/owasp-agentic-ai-security/) · [Giskard 정리](https://www.giskard.ai/knowledge/owasp-top-10-for-agentic-application-2026)

## 한 줄 요약

기존 **OWASP LLM Top 10** (LLM01~LLM10)이 모델 위협 중심이라면, **OWASP Top 10 for Agentic Applications 2026** (ASI01~ASI10)은 **에이전트 시스템 특수 위협**을 다룬다 — goal hijacking, tool misuse, identity abuse, dynamic runtime composition, cascading failures, rogue agents 등. 100+ 산업 전문가의 peer-review 결과. 2025-12 발표.

## 왜 별도 표준이 필요했나

LLM Top 10은 **단일 LLM 호출**을 가정한다. 에이전트는:
- **장기 실행**(메모리·세션)
- **도구 사용**(외부 시스템 변경)
- **자율 결정**(사람이 매 단계 검증 안 함)
- **에이전트 간 통신**(A2A로 다른 에이전트 호출)

→ 위협 표면이 근본적으로 다르다. **emergent autonomous behavior** 자체가 새 위험 카테고리.

## 10개 항목 (ASI01–ASI10)

| 번호 | 이름 | 핵심 |
|------|------|------|
| **ASI01** | **Agent Goal Hijack** | 에이전트의 의사결정 프로세스 탈취 — prompt injection이 단일 응답이 아니라 **전체 plan을 휘젓는** 형태로 진화 |
| **ASI02** | **Tool Misuse** | 정상 도구의 부적절한 사용 — 모호한 instruction, over-privileged access 때문 |
| **ASI03** | **Identity and Privilege Abuse** | 에이전트 세션·토큰·역할 — non-human identity의 **수명·권한 범위** 관리 부재 |
| **ASI04** | **Dynamic Runtime Composition** | 런타임에 컴포넌트(MCP 도구, A2A 에이전트, SKILL.md)를 동적으로 발견·로드할 때의 위험 (ClawHavoc 같은 사례) |
| **ASI05** | **Memory & State Manipulation** | 장기 메모리 오염 — 한 세션의 악성 instruction이 다음 세션에 persist |
| **ASI06** | **Inter-Agent Trust & Communication** | A2A 통신·delegated trust — 다른 에이전트의 출력을 신뢰할 때의 검증 부재 |
| **ASI07** | **Resource Hijacking** | 토큰·컴퓨팅·rate limit 자원의 무제한 소비 (LLM10의 agentic 진화) |
| **ASI08** | **Cascading Failures** | 단일 fault가 에이전트·워크플로 전체로 전파 — 디버깅의 악몽, 사일런트 데이터 손상 |
| **ASI09** | **Human-Agent Trust Exploitation** | anthropomorphism·authority bias의 무기화 — 에이전트가 "사람처럼" 보일수록 사용자가 검증을 멈춤 |
| **ASI10** | **Rogue Agents** | 행동 drift, collusion(공모), self-replication — 초기 침해 이후의 emergent behavior |

## 핵심 통찰

> "failures arising from goal misalignment, tool misuse, delegated trust, inter-agent communication, persistent memory, and emergent autonomous behavior."

→ **에이전트 보안은 모델 보안이 아니다**. 모델이 100% 안전해도 위 6개 축에서 사고가 난다. [[concepts/harness-engineering|Harness Engineering]]이 보안의 1차 답인 이유.

## 실무 우선순위 (Palo Alto Networks 권장)

1. **ASI01·ASI02**: 가장 흔한 1차 침해 — prompt injection이 도구 misuse를 일으킴
2. **ASI03**: non-human identity 관리 — agent가 늘면 sprawl 위험
3. **ASI04·ASI06**: MCP·A2A 채택과 함께 **공급망/통신** 신뢰 모델 정의
4. **ASI05**: 장기 메모리 도입 시점부터 즉시 (Managed Agents의 persistent memory 추가가 트리거)
5. **ASI07~ASI10**: 운영 모니터링 단계에서 점진 추가
