# OpenAI DevDay 2026 키노트 확정 발표 (9/29 10am PT, Fort Mason)

> 20+ 제품·기능·개발자 도구 발표. 헤드라인은 상시 에이전트 "Dots". "O" 루머가 Dots로, "Spaces" 루머가 "ChatGPT Space"로 각각 확정.

## 확정 발표

1. **Dots** — 상시 가동(always-on) AI 에이전트. 각 Dot이 자체 클라우드 컴퓨터·브라우저를 갖고 목표를 향해 백그라운드 작업 후 체크인. 4,000+ 앱 연결, 피드백 학습. ChatGPT·Slack·Teams에서 메시지 (텍스트ing 예정). 파워 모델: GPT-6 Astra. 초기 가용: ChatGPT Pro·Business Premium·Enterprise (Meta Muse 무료와 대비).
2. **ChatGPT Space** — 팀원과 Dot 에이전트가 함께 일하는 공유 워크스페이스. **Pages** (인간+에이전트 공동 생성 문서: 이미지·글·차트·시각화) 동시 발표.
3. **GPT-6.1 Sol** — GPT-6 Sol 출시 1주 만. $2/$10 (Astra의 1/5), 캐시드 input $0.10/1M (-95%). DeepSWE 1.1에서 Astra와 동점, OSWorld 2.0 +7점 (Astra -2.1점), GDP.pdf에서 Opus 5.5 상회 (작업당 절반 이하 비용). ChatGPT Work·Codex 전 플랜 즉시 (Chat 제외). **GPT-6.1 Astra는 발표 목록에 없음** (아침 철회 유지).
4. **ChatGPT Pro Max $500/월** — Plus 대비 25배 사용량 + Ultrafast 전체 접근.
5. **Ultrafast** 속도 티어 — Codex 최대 8배, API 최대 6배 토큰 생성.
6. **Decisions API** (Luna 기반 고속), **Agents API** 퍼블릭 베타 (Harness·Environment·Memory & Context·Compaction·Multi-agent).
7. **Codex Cloud** (폰 시작→데스크탑 연속, 공유 팀 환경), **Codex Security Cloud** (스케줄 저장소 스캔·제안 수정).
8. OpenAI Marketplace, plugin extensions, Sign in with ChatGPT (16개 런치 파트너), ChatGPT 1.2B 주간 사용자.
