# Microsoft revamps Copilot: "Code" tool and always-on "Autopilot" agent, plus AI cost visibility

> Microsoft가 Copilot 앱에 코드 생성 도구 "Code"와 상시 가동 에이전트 "Autopilot"을 추가하고 Word·Excel·PowerPoint를 Copilot 안에 내장. 직원이 자신의 AI 사용 비용을 직접 볼 수 있는 비용 관리 기능도 공개 (Reuters, 2026-09-25).

## 핵심 내용

1. **"Code" 도구**: 자연어 프롬프트로 앱·대시보드 등 소프트웨어를 만들 수 있는 코드 생성 도구. GitHub Copilot과 같은 기술 기반. 이달 말 얼리 액세스 고객 대상 출시, 365 Premium·Pro 구독자는 올해 말 프리뷰.
2. **"Autopilot" 에이전트**: 6월에 공개된 "Scout" AI 에이전트의 리브랜딩/개편판. 이달 말 프라이빗 프리뷰. 회사 디렉토리에서 **자체 정체성**을 갖고 사용자가 제어할 수 있는 **특정 권한**을 부여받는 "digital coworker" 개념.
3. **Office 내장**: Word·Excel·PowerPoint를 Copilot 안에 직접 임베드 — AI 도구를 떠나지 않고 협업 작업 가능. Copilot을 사무직의 "one-stop shop"으로 전환하려는 전략.
4. **비용 관리 기능**: 직원이 자신의 AI 사용에 따른 비용을 직접 확인할 수 있는 기능 공개. 기업의 AI 사용량 급증에 따른 예상치 못한 비용 우려가 커지는 시점의 대응.
5. **엔터프라이즈 메시지**: Annie Pearl(Copilot 제품 부문 CVP)은 "많은 조직이 보안·컴플라이언스·거버넌스 문제 때문에 에이전트를 기업에 도입하기 어려웠다"며, 기업에서 실제로 쓸 수 있는 방식으로 구축했다고 강조.
6. **경쟁 맥락**: 채팅 기반에서 벗어나 채택률을 높이려는 Microsoft의 행보 — ChatGPT·Claude와의 AI 챗봇 경쟁 구도.
