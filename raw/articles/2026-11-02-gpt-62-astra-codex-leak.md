# GPT-6.2 Astra, Codex 사용량 화면에 등장 — OpenAI 미확인 차세대 플래그십 유출설 (11-01)

> 2026-11-01, 여러 Codex 사용자가 사용량 분석 화면에서 모델 선택기는 GPT-6 Astra로 표시되는데 사용량 내역에는 `gpt-6.2-astra`라는 이름이 찍힌 스크린샷을 게시했다. OpenAI는 확인하지 않았고, 9월에 안전 테스트 문제로 취소됐던 GPT-6.1 Astra를 건너뛴 버전이라는 해석이 붙었다. (Van Data Team의 증거 추적·ChainCatcher/AIBase 보도 기반)

## 내용

- **무엇이 포착됐나**: Codex 사용량 breakdown에 `gpt-6.2-astra` 라벨이 등장했고, 사용 비중 80%·19.8% 같은 수치와 JSON 조각이 함께 돌았다. 모델 선택기 자체는 여전히 GPT-6 Astra를 표시했다.
- **배경**: GPT-6.1 Astra는 9월 안전 기준 미달로 출시가 취소됐다고 보도된 바 있다. 6.2는 한 달간 재학습한 뒤 그레이 테스트에 들어갔다는 것이 유출설의 줄거리다.
- **주장 vs 확인**: ChainCatcher/AIBase 계열 보도는 Codex 트래픽의 약 20% 처리, 28일간의 Codex 하부 시스템 개편, 수 시간 연속 작업을 위한 서브프로세스 생성 등을 전한다. 그러나 Van Data Team의 검증에서는 스크린샷들이 서로 같은 이미지를 재사용했고, 전체 요청으로 추적되는 증거는 없다고 평가했다.
- **공식 상태**: 2026-11-02 현재 OpenAI의 발표·가격·스펙은 없다. 유출설일 뿐 출시가 아니다.
