# 2026-11-27 학습 일지

## 오늘 배운 것

- **삼성, Galaxy AI용 프라이빗 클라우드 'SPAC' 준비 중 — One UI 9.5 코드에서 발견 (11-26)** (Android Authority, 11-26): One UI 9.5 Beta 1(Galaxy S26 Ultra) 코드 분석에서 삼성의 프라이빗 클라우드 AI 프레임워크 'SPAC' 흔적이 발견됐다. 애플 Private Cloud Compute와 같은 설계: 요청은 서버에서 처리하되 누가 보냈는지 연결되지 않게 한다. 삼성은 아직 공식 발표하지 않았고 기능은 꺼진 상태다. 발견 위치는 4개 앱 안의 SPAC SDK — Photo Editor, IntelliVoiceService(음성·언어 서비스), Smart Capture, PhotoRemasterService. 서버 측 게이트웨이 이름은 'Arcane', 토큰·신원·사기 탐지 서비스가 별도로 언급됨. 프라이버시 설계(코드 기준): (1) 서드파티 릴레이를 거쳐 요청이 전달돼 삼성이 '무엇을' 물었는지는 봐도 '누가' 물었는지는 모르게 함. (2) 폰이 서버 소프트웨어가 변조되지 않았는지 검증(attestation). (3) 서버 동작이 조용히 바꿀 수 없는 공개 기록에 남음. (4) 기기는 익명 일회성 패스로 인증받아 사용자를 드러내지 않음. 일부 검사를 건너뛰는 'unattested' 모드도 있으나 내부 테스트용으로 보임. 언급된 모델: Google Gemma 4, Alibaba Qwen 3.6, Black Forest Labs FLUX.2 klein 4B, 삼성 자체 Gauss — 코드상 참조일 뿐 실제 사용 확인은 안 됨. 연결되는 기능: AI Select, 클라우드 사진 지우기·업스케일, 실시간 통역, Writing Tools, Now Brief, Daily Briefing, Bixby Work 등 Galaxy AI 클라우드 기능 상당수. 공개 인증서 기록상 SPAC 서버 주소가 갱신되고 미국 릴레이가 추가되는 등 백엔드 준비는 진행 중. 11월 27일 업데이트: Android Authority가 Galaxy S26 Ultra에서 SPAC을 AI Select와 함께 제한적으로 동작시키는 데 성공.
- **OpenAI, '프라이빗 추론' 알파 테스트 시작 — 처리 중에도 프롬프트를 못 보게 (11-25)** (Unite.AI, 11-25): 샘 올트먼이 11월 25일 X에 올린 글 — OpenAI가 소수 비즈니스 고객과 함께 'Private Inference' 테스트를 시작했다. 모델이 프롬프트를 처리하는 바로 그 순간에도 OpenAI가 내용을 볼 수 없게 하는 것이 목표다. DevDay 2026(9월 29일)에서 예고한 Private Intelligence의 두 번째 축이다. 기밀 컴퓨팅(confidential computing) + 검증 가능한 통제 — 프롬프트와 응답이 모델 처리 중에도 암호화된 채로 격리된 하드웨어에서 실행됨. 대부분의 프라이버시 약속이 '답변 후' 데이터를 어떻게 다루는지에 관한 것이라면, 이건 '답변 중'을 겨냥한다. 범위: 비즈니스 API 고객 대상 소규모 알파. 소비자용 ChatGPT가 아님. 가격·지원 모델 목록·정식 출시일 모두 미공개. 관심 기업은 @shekar4x(OpenAI 담당자)에게 연락하는 방식. 함께 공개된 것: ZDR with Private Safety Processing — 안전 검토에 걸린 콘텐츠를 고객 소유 클라우드(AWS·Azure·Google Cloud·OCI)에 암호화 저장하고, 고객은 최소 30일간 보관해야 함. 자동 안전 검토는 OpenAI 직원이 원본 내용을 보지 않고 수행됨. 백서: 10월 26일 Private Safety Processing 백서 — 키는 런타임 신원·하드웨어 증명·소프트웨어 측정값 검증 뒤에만 해제, 내부 키는 매일 교체·30일 뒤 파기, 측정값은 변조 방지 로그에 기록. 단, 표준 안전 런타임은 '추론 전체에 대한 Zero Operator Access 보장'을 제공하지 않는다고 명시. 확장 계획: 올트먼은 대규모 출시를 위해 기밀 컴퓨팅 용량을 확보 중이라고 밝혔으나 일정은 없음.
- **DeepL, 음성→음성 직통 번역 모델 Aure v2 출시 — 지연 50% 단축 (11-26)** (PR Newswire, 11-26): DeepL이 11월 26일 도쿄 첫 Unmute Summit에서 음성 AI 번역 모델 Aure v2를 출시했다. 말→글→번역→음성의 3단계를 거치지 않고 음성을 번역된 음성으로 직접 바꾸는 엔드투엔드 구조로, 전작 대비 중앙값 번역 지연이 50% 줄었다고 한다. DeepL 내부 연구(2026년 11월, 10개 언어쌍·1분짜리 실제 음성 녹음, 인간 검증 전사본) 기준, 번역된 단어의 절반이 3.3초 안에 들린다고 함. 6개 경쟁 시스템 대비 전 언어쌍에서 품질 우위 주장 — 모두 자사 측정, 독립 검증 없음. 언어: 출시 시 6개 — 영어·독일어·프랑스어·스페인어·일본어·한국어. 제공 범위: DeepL Voice for Online Meetings(Teams·Zoom·Meet), Voice for In-Person Conversations, DeepL API for Voice. 지원 언어에서는 자동으로 켜지며 별도 설정 없음. 가격은 미공개. 속도: 전작 Aure는 11월 11일 출시 — 불과 15일 만의 후속. DeepL Voice 사용량은 2026년 3분기 기준 전년 대비 음성 분 8배 이상, 번역 회의 분 7배가량 증가.

- **Cloudflare, 'Search for Agents' 베타 — 웹사이트를 AI 에이전트용 검색 API로 (11-25)** (Cloudflare Blog, 11-25): Cloudflare가 11월 25일 Search for Agents를 베타로 출시했다. 대시보드 토글 하나로 자기 웹사이트를 AI 에이전트가 검색할 수 있는 상태로 만든다. 사이트를 일일이 크롤링하는 대신 도메인 자체의 검색 엔드포인트를 쓰게 하는 방식이다. Free 포함 전 플랜에서 사용 가능. 동작: 존의 Overview 페이지 Quick Actions에서 켜면 AI Search 인스턴스(search-for-agents-<ZONE_ID>)가 자동 생성되고, 사이트를 크롤링·인덱싱한 뒤 `https://<도메인>/.well-known/search` 엔드포인트를 노출. GET과 HTTP QUERY(RFC 10008) 요청 지원, 결과는 AI가 만든 답이 아니라 Markdown 콘텐츠. 발견 가능성: 모든 HTML 페이지의 <head>에 agent:endpoint·agent:method 등 검색 엔드포인트 메타데이터를 자동 삽입하고, Markdown for Agents가 켜져 있으면 Markdown 응답에도 포함. 에이전트가 엔드포인트를 스스로 찾아 키워드·자연어 질의를 보낼 수 있음. 검색 방식: 하이브리드(벡터+키워드) 검색, Discover 크롤링(사이트맵+링크, 최대 10만 페이지, 24시간마다 재동기화), 임베딩 모델 @cf/qwen/qwen3-embedding-0.6b. 기본 설정은 하위도메인 제외. 요금: AI Search 요금 체계 적용, 과금은 2026년 12월 1일부터 시작. 이후 포함량(월 의미 검색 1,000건) 초과 시 하이브리드 질의 1,000건당 $0.75 — 에이전트가 검색할 때마다 사이트 소유자가 부담. 통제: 봇 관리·AI Crawl Control·WAF 설정이 그대로 적용됨. 검색은 정보를 찾는 기능이지, 에이전트가 내용을 올바르게 해석·인용한다는 보장은 아님.

Google은 실수할 수 있다며 내비게이션·장애물 감지·이동 보조기구 대체 용도로 쓰지 말라고 경고. 연관: 12월 10일 판매 시작하는 Google의 Gemini 스마트 글라스도 Guided Vision을 지원.

## 인사이트

**오늘의 축은 "프라이버시 컴퓨트와 에이전트의 감각 확장"이다. 삼성 SPAC과 OpenAI Private Inference는 같은 주에 '답변 후'가 아니라 '답변 중·보낸 사람'까지 가리는 프라이버시로 수렴했고, Anthropic의 Enterprise Frontier Safeguards까지 합치면 프론티어 랩·디바이스 제조사 모두가 '익명 클라우드'를 공통 답으로 삼기 시작했다. 반대쪽에서는 에이전트의 문이 열리는 중이다 — Cloudflare는 사이트가 에이전트에게 검색 창구를 '제공'하는 표준을 내놨고, Duet은 4개국으로, Guided Vision은 아이폰으로, Aure v2는 음성 직통으로 에이전트의 손발이 넓어지고 있다. 공통된 질문은 하나다. "에이전트가 어디에 살고, 무엇을 보고, 누구에게 들키지 않는가" — 상주 위치·감각·프라이버시가 같은 날 한 묶음으로 움직였다.**

**함께 정리한 것**: 삼성 SPAC(11-26) — [[concepts/samsung-spac-private-ai-cloud]] 신규(One UI 9.5 코드 발견·릴레이+attestation+공개 기록·미발표·코드 기반 추론). OpenAI Private Inference 알파(11-25) — [[concepts/openai-private-inference-alpha-trials]] 신규(기밀 컴퓨팅·처리 중에도 못 보게·비즈니스 알파·ZDR with Private Safety Processing·Zero Operator Access 전면 보장 아님). DeepL Aure v2(11-26) — [[concepts/deepl-aure-v2-speech-to-speech]] 신규(엔드투엔드 음성→음성·지연 50% 감소·3.3초·자사 수치만). Claude Duet 확대(11-25~26) — [[concepts/claude-duet-proactive-agent]]에 보강(인도·인도네시아·브라질·일본·독립 앱·Team 퍼블릭 베타·Enterprise 프라이빗 베타). Cloudflare Search for Agents(11-25) — [[concepts/cloudflare-search-for-agents]] 신규(.well-known/search·하이브리드 검색·12월 1일 과금·1,000건당 $0.75) + [[concepts/websites-block-ai-agents]]에 반대 방향 보강. Gemini Live Guided Vision iOS(11-25) — [[concepts/gemini-live-guided-vision-ios]] 신규(카메라 음성 안내·Aira 협업·내비게이션 대체 금지 경고). [[concepts/agent-residence]]에 프라이버시 컴퓨트 보강(익명 클라우드 세 번째 옵션).
