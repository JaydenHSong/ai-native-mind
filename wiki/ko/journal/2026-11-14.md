# 2026-11-14 학습 일지

## 오늘 배운 것

- **Sierra Poppy 1.0** (Sierra, 11-13): Personal Agent Protocol 1.0 출시. 개인 에이전트가 기업을 발견하고 허용된 행동을 협상하는 표준으로, MCP·OpenAPI·Shopify UCP 위에 구축되고 OAuth로 사용자가 권한을 통제한다. Shopify 175개국 이상 전 상점이 poppy.json을 자동 게시(상인 추가 구현 불필요), Meta Muse는 모든 사용자에게 켜져 방문하는 모든 사이트에서 Poppy를 먼저 찾는다. 디자인 파트너 60곳 신규 합류로 총 100곳 돌파. 실가동: Mercury(잔액·거래 조회, 승인 정책 하 결제·이체 개시), Synchrony(금융·리워드 연계 쇼핑), Turkish Airlines(운임·예약 조회, 마일리지 비즈니스 업그레이드). 단 스펙은 여전히 draft 1.0 표기라 파괴적 변경이 가능하다.
- **OpenAI ChatGPT Wallet** (Reuters, 11-13): 상시 가동 dots 에이전트가 사용자 대신 결제를 완료한다. 사용자가 상품·총액·카드를 확인한 뒤 Face ID/지문으로 승인하면 결제 네트워크가 토큰화된 대체 카드 번호를 발급하고, 에이전트와 가맹점은 실제 카드 번호를 보지 못한다. Amex·Mastercard·Visa와 공동 구축, 사기 탐지 Forter·Riskified·Sardine·Signifyd, 결제 처리 Adyen·Checkout.com·Stripe. 미국 ChatGPT Pro·18세 이상·적격 미국 발급 신용카드만, 직불·가상카드 미지원, dot 대화 안에서만 동작(Chat·Work·Codex 불가). 출시 시 OpenAI 수수료 0%. OpenAI는 ChatGPT 주간 사용자 12억 명이라고 밝혔다. 반대 방향으로 United Airlines는 11-11 운송약관을 바꿔 무단 AI 에이전트의 티켓 구매를 금지했다.
- **FBI ARTEX 경고** (11-13, FLASH-20261113-001): 오픈소스 자율 침투 테스트 프레임워크 ARTEX를 범죄·국가 연계 행위자들이 무기화하고 있다. Go 작성 프레임워크가 LLM 에이전트에 연결돼 평문 목표를 명령으로 바꿔 실행한다. Claude·GPT·DeepSeek·GLM·Grok·Kimi에 연결되고 공격자 배포에서는 DeepSeek Flash가 가장 흔하다. Google 관찰로는 개별 자동 버스트가 2~25초, 일부 침입은 최초 표적 식별에서 권한 탈취까지 3시간 미만. 최소 2026-08부터 금융·정부·기술·방위·에너지·헬스케어에서 관측, 한국 금융기관 공격으로 약 67,000명 개인정보 유출, ConnectWise Cloud Backup 공급망 침해로 2,250개 이상 하위 테넌트 표적 시도(확정 침해 수 아님), 11월 초 기준 공개 노출 콘솔 1,600개 이상(노출이 곧 악용은 아님). Microsoft는 ARTEX를 중국 국가 연계 Storm-0940과 연결했고, 한 사례에서는 GitHub 비밀 검색에서 Azure Key Vault 탈취까지 5분. 개발자가 10-08 저장소를 삭제했으나 포크·복사본이 유통 중이다. FBI 권고: 노출된 관리 도구 제한, 앱 권한 축소, 저장소 비밀 스캔.
- **DeepSeek 앱 기능 API 개방** (11-13, 공식 API 변경 로그): 자사 소비자 앱의 기능을 개발자 API로 개방했다. 인용 포함 웹 검색(심층 사고 검색 모드 포함)·이미지 검색·파일 입력(PDF·Office·이미지)·URL 읽기·음성 상호작용·안전 검사를 서버 쪽에서 처리한다. deepseek-flash는 이제 V4.1-Flash-1017을 가리킨다(9월 릴리스의 날짜 갱신판, API 방식·토큰 가격 그대로). Search·Fetch 1,000건당 $0.75, OCR 1,000페이지당 $0.225, ASR·TTS 출시 50% 할인. deepseek-flash 토큰 가격은 비피크 입력 $0.15/출력 $0.60(100만 토큰당), 피크 2배. API 기반 공개 앱은 안전 검사를 반드시 켜야 하고, 오픈소스 데모 채팅 클라이언트도 함께 공개됐다.
- **OpenAI 로봇 팀 해산** (Fortune 단독 보도, 11-13, 회사 대변인 확인): 독립 로봇 팀을 해산했다 — 두 번째 해산(첫 번째 2020~21년). 범용 프론티어 모델, 특히 GPT-6 Astra를 로봇 제어에 직접 적용할 수 있게 됐으니 로봇 전용 모델을 만드는 별도 팀이 더 이상 가장 빠른 길이 아니라는 판단이다. 연구 인력은 Mark Chen 최고연구책임자 산하 메인 연구 조직으로, 응용 로봇·하드웨어 인력은 Greg Brockman 사장 산하 Applied 조직으로 이동한다. 근거는 Nvidia 10-14 연구: GPT-6 Astra 에이전트가 시뮬레이션 pick-and-place 벤치마크 RoboLab-120에서 74.8%, 최고 전용 로봇 모델 51.0%를 앞섰다. 단 시뮬레이션 결과이지 물리 로봇 증거가 아니며, 호출당 토큰 비용 약 $36.40, 소요 약 18.56초다. 로봇은 장기 비전의 핵심이라고 밝히고 2027년 휴머노이드 데모 목표를 유지한다. 인원수 비공개, 자체 블로그 게시물 없음. Fortune은 최근 분기 영업손실 $109억, 2027년 초 IPO 가능성을 함께 전했다.
- **Cloudflare Kitesurf 오픈소스 공개** (Unite.AI, 11-13): AI 에이전트용 브라우저 엔진 Kitesurf를 Apache 2.0 라이선스로 공개했다. 2026-08-06 출시 때 한 약속의 이행이다. Chromium이나 브라우저 컨테이너 없이 HTML 파싱·CSS 적용·페이지 JavaScript 실행·스크린샷 렌더링을 한다. Cloudflare Workers 위에서 전적으로 동작하고(Rust/WASM 컴포넌트), Puppeteer·에이전트 하네스용 CDP 엔드포인트를 노출한다. 개발자가 검사·수정·로컬 실행하거나 자신의 Workers 계정에서 셀프 호스팅할 수 있다(유료 플랜 필요). 단 여전히 실험 단계로 Chrome·웹 플랫폼 호환성이 불완전하고, 셀프 호스팅은 인증을 직접 추가해야 한다(내장 인증 없음, workers.dev URL은 기본 공개). 'Chromium보다 CPU·메모리 적게 쓴다'는 Cloudflare 주장은 공개 측정값이 없어 미검증이다.

## 인사이트

**에이전트가 문을 열고(Poppy), 돈을 내고(Wallet), 웹을 직접 읽는(Kitesurf) 날, 사람에게 남는 일은 범위와 승인뿐이고, 그 문턱을 낮추는 순간 공격자도 같은 문으로 들어온다(ARTEX).** 어제(11-13)의 "사람에게 남는 자리는 범위·승인·책임 세 가지"가 오늘은 더 날카롭다. Poppy·Wallet·Kitesurf는 에이전트의 입구·지갑·브라우저를 같은 날 열어젖혔고, OpenAI는 로봇마저 범용 모델에 맡기겠다고 선언했다. 그런데 그 문이 열린 바로 그 날, FBI는 에이전트 주도 침입이 이미 3시간 단위로 벌어지고 있다고 경고했다. 에이전트 시대의 편의와 보안은 같은 문을 쓴다 — 문을 넓힐수록 잠그는 방식도 같은 속도로 설계해야 한다. 1인 개발자의 하네스도 마찬가지다. 에이전트에게 입구·지갑·브라우저를 줄수록, 범위·승인·책임의 세 문턱은 더 단단해야 한다.
