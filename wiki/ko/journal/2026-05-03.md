# 2026-05-03 학습 일지 — 일요 데일리: 프레임워크 GA + 1,000개 트레이스 + 7계층 메모리

## 이 글을 읽는 법 (30초)

자동 데일리 인제스트. AI 에이전트 엔지니어링 자료 3편을 `raw/articles/`에 정리하고, 관련 위키 페이지에 **추가만** 했다 (기존 본문·링크 보존).

세 글을 한 그림으로 묶으면 — **표준화 / 프로덕션 정량화 / 메모리 다음 세대**.

- **Microsoft Agent Framework 1.0**: Semantic Kernel + AutoGen 통합 GA. **5 오케스트레이션 패턴 + MCP·A2A 1차 + Claude Code SDK as harness**. 표준이 빠르게 굳고 있다.
- **Datadog State of AI Engineering 2026**: 1,000+ 회사 트레이스 데이터. **70%+가 3+ 모델, 프레임워크 채택 1년에 2배, 시스템 프롬프트가 입력 토큰 69%, 그러나 caching은 28%만, rate limit이 1위 실패**. 운영 부채는 빠르게 쌓이고 있다.
- **ZenBrain (arXiv 2604.23878)**: 신경과학 영감 7계층 메모리 + Predictive Memory. **Self/Autobiographical과 Predictive 두 축이 새로 들어왔다**.

## 한 그림으로 잇기

```
표준화                     정량 진단                    다음 세대
─────────                ─────────                  ─────────
MS Agent Framework  →    Datadog 7대 사실      →    ZenBrain 7계층
5 패턴 + MCP/A2A         캐싱 28% / 429 1위         Self + Predictive
                          context 69% sys prompt
```

운영 흐름:
1. **MCP·A2A·5 패턴**으로 **표준 위에 짓고**(MS 1.0이 인프라를 굳혔다).
2. **Datadog 데이터 7가지**로 어디가 새는지 **즉시 감사** — caching·budget·trace propagation·모델 retire 룰이 즉효 ROI.
3. **ZenBrain의 Self·Predictive**가 다음 단계 — 장시간 자율 운영의 페르소나 표류와 retrieval 폭주 둘 다에 답.

## 한 줄 요약

표준은 빠르게 굳고 있고(MS 1.0), 프로덕션은 운영 부채를 쌓고 있고(Datadog), 메모리 모델은 다음 세대로 가고 있다(ZenBrain). 1인 개발자가 다음에 손댈 곳은 — **prompt caching prefix 정렬** + **rate-limit 안전 장치(budget)** + **persona/forgetting 정책 명시**, 이 셋이 가장 ROI 높다.
