# 2026-11-18 학습 일지

## 오늘 배운 것

- **NVIDIA Q3 FY2027, 매출 $115.8B(+103%) — 황 사임 후 첫 실적, H200 중국 출하 중단** (NVIDIA, 11-17): FY2027 Q3 매출 $115.84B(+103% YoY, +20% QoQ), 컨센서스 ~$109.1B 및 자체 가이던스 $108B 상회. 비GAAP EPS $2.68(예상 ~$2.47), 순이익 $65.3B(+105%), 매출총이익률 74.9%. 데이터센터 $107.61B(+110%), 전체의 약 93%. Vera Rubin이 첫 양산 분기에 약 $20B 기여, 회사 역사상 가장 빠른 램프. Q4 가이던스 $130B(±3%, 14주 분기), 매출총이익률은 71~72%로 하락 전망. 같은 콜에서 임시 CEO Kress가 라이선스 Hopper(H200) 칩의 중국 출하 중단을 밝혔고, Q4 가이던스에는 중국 데이터센터 컴퓨팅 매출을 0으로 가정. Q3에 해당 제품이 중국에서 $2.4B 팔렸으나 중단 이유·영구 여부는 밝히지 않음. 배경으로 11월 16일 미 상무부의 제3국 데이터센터 경유 원격 접근 차단 규칙과 베이징의 H200 수입 보류(약 60만 개 칩이 홍콩 대기 중, Reuters)가 거론됨. 같은 날 이사회는 국가안보·수출통제 감독위원회를 신설. 이사회 의장은 황의 CEO 복귀 의사가 없다고 밝힘.
- **Anthropic IPO, 오늘 밤 가격 결정 — 공모가 $80 상회 전망, 11-19 ANT 상장** (Invezz, 11-18): 가격 결정 2026-11-18 저녁(미 동부), 거래 개시 2026-11-19 Nasdaq Global Select Market, 티커 ANT. 공식 공모 범위 주당 $70~78(8.25억 주, $78 기준 $64.35B 조달). WSJ는 $80 초과 가격을, Bloomberg는 수요가 공모 물량의 약 7배라고 보도. 별도로 Google·NVIDIA·AMD·Microsoft·Broadcom·Micron·TSMC 등이 IPO 가격으로 $26B 규모 Class N 주식 동시 사모에 참여. 2026년 10월 31일 기준 연환산 매출 run-rate 약 $81B, S-1 기준 Q3 2026 매출 ~$17B(+47% QoQ, Q2의 +144%에서 둔화), 다년간 컴퓨팅·인프라 약정 약 $900.9B. 창업자 보유 Class F 주식이 의결권 50.1%를 유지. **단, 최종 가격은 이 파일 작성 시점에는 아직 확정되지 않았다 — 내일 후속 확인 필요.**
- **OpenAI GPT-6.2 Astra·Sol 출시 — Astra 가격 20% 인하, 첫 'High' 자기개선 등급** (WinBuzzer, 11-17): 11월 17일 ChatGPT Work·Codex·API에 출시. Astra $8 입력/$40 출력(기존 $10/$50에서 20% 인하), 컨텍스트 105만 토큰. Artificial Analysis Intelligence Index에서 Astra 62점(Claude Fable 5.2의 65점에 이어 2위), Sol 57점. OpenAI는 자체 평가에서 작업당 비용이 3분의 1 미만으로 줄었다고 주장했으나 독립 측정치는 Artificial Analysis 36% 감소($6.24→$4.00/작업), Vals AI 50% 감소. 시스템 카드 기준 Astra는 AI 자기개선 'High' 등급을 받은 첫 외부 공개 OpenAI 모델, 두 모델 모두 사이버보안 'Critical' 등급. Astra의 ExploitBench 내부 임의 코드 실행률은 53.5%로 GPT-6 Astra(31.5%)보다 22점 상승. 영국 AI Security Institute는 사전 출시 버전에서 견고성 하락과 범용 탈옥을 발견. 출시 당일 개발자 평가는 거칠었다 — 반복 루프 보고, 한 유명 테스터는 "OpenAI가 낸 최악의 모델"이라고 평했다. 9월 GPT-6.1 Astra가 안전 기준 미달로 취소된 지 7주 만의 출시.
- **Microsoft Ignite 2026 — MAI Code 2 공개, Copilot Autopilot·Agent 365 5,000만 개** (Microsoft, 11-17): 7개 자체 MAI 모델 공개. 코딩 모델 MAI Code 2는 GitHub Copilot에서 GA(약 2.8T 전체 / 77B 활성 파라미터). Microsoft 주장(자체 내부 하네스, 독립 재현 없음): Claude Opus 5.5 대비 96% 성능을 5% 비용으로, GPT-6.1 Sol 대비 98% 성능을 40% 비용으로 제공. 비용은 50% 프로모션 가격 기준($0.50/$2.50, 2027년 5월 17일까지). MAI Code 2 Flash는 약 398B 전체 / 12B 활성 파라미터. Copilot은 Chat·Cowork·Code·Autopilot 4개 모드로 재편, 24시간 상주하는 Autopilot 에이전트와 Agent 365 등록 에이전트 5,000만 개 돌파. Maia 300 자체 AI 칩 공개(선도 GPU 대비 와트당 토큰 40%↑ 주장, 자체 기준). MAI Licensed Weights 프로그램도 함께 발표. **단, 성능·가격 수치는 모두 Microsoft 자체 주장이며 독립 검증이 없다.**
- **에이전트 커머스, 주류로 — Gemini Tasks 무료화·전화·결제 + Klarna 어시스턴트** (Google, 11-17): 기존 월 $19.99 AI Pro 구독이 필요했던 Gemini Tasks를 미국·일본·한국·캐나다·호주·인도에서 무료 제공. 미국에서 먼저 Tasks가 현지 업체에 병렬로 전화를 걸어 가격·재고·예약을 확인(AI임을 밝히고 통화, 업체 수신 거부 가능, IN·LA·MN·MT·NE 주에서는 불가). Google Pay 경유 결제, AP2 기반, Visa·Mastercard 토큰 지원(Amex 곧 추가), 사용자 지출 한도 설정(최대 $1,000, 기한 14일 이내), 영수증은 Google Wallet에 저장. 같은 날 Klarna가 컨시어지형 AI 어시스턴트 발표 — 최적 상품·가격 탐색, 구매, 반품 처리, 식당·예약, 일상 행정 대행. WhatsApp·iMessage와 Klarna 앱 안에서 동작, 소수 조기 사용자 대상 라이브, 공개 대기자 명단 개설. "도착하기 전에는 결제하지 않는다"는 통제 프레이밍. Q3 실적과 함께 발표: 매출 4분기 연속 $1B 초과(+12% YoY), 순손실 $65M, GMV $36.1B(+10%).
- **Microsoft Agent Framework PyPI 침해 — 악성 1.26.1·1.26.2가 클라우드 자격증명 탈취** (Socket Research Team, 11-17): 악성 버전 1.26.1(20:35 UTC)과 1.26.2(21:08 UTC)가 11월 17일 PyPI에 업로드, 약 1시간 만인 21:30 UTC경 제거. 두 버전 모두 Python 시작 훅(`.pth`)으로 Azure·GitHub Actions OIDC 토큰과 각종 자격증명을 수집해 webhook.site로 유출. 설치 시 심는 `.pth` 파일(`agent_framework_meta.pth` / `af_runtime_diag.pth`) 때문에 `agent-framework`를 import하지 않아도 파이썬이 뜨면 스틸러가 돈다. Socket이 최초 분석, 8개 보안 업체가 수 시간 내 플래그. 유출 엔드포인트 무료 티어라 Wiz가 확인한 요청은 최대 50건, 실제 설치·피해자 수는 미공개. 패키지는 주간 약 4.1만 다운로드, 월간 약 19만 다운로드 수준. Wiz의 11월 18일 14:00 UTC 업데이트에 따르면 공격자가 Microsoft ESRP용 클라이언트 인증서·개인키를 탈취한 것으로 보이며, 공격 도구 자체가 "Cairn"이라는 오픈소스 AI 침투 테스트 프레임워크임을 드러냈다. Microsoft는 11월 18일 현재 공식 postmortem을 아직 내놓지 않았다. 최근 안전 버전은 1.26.0. 해당 시간대(11-17 20:35~21:30 UTC)에 설치·업데이트한 환경은 자격증명 유출을 가정하고 로테이션해야 하며, 환경을 닦기보다 깨끗한 환경에서 복원하는 것이 권고됨.

## 인사이트

**오늘의 축은 "돈이 되는 날과 돈이 새는 날"이다. NVIDIA는 분기 매출 $115.8B를 찍고, Anthropic은 내일 상장을 앞두고, OpenAI와 Microsoft는 모델 가격을 내리며, Google·Klarna는 에이전트에게 지갑을 쥐여 줬다 — AI의 돈줄이 한 방향으로 흐르는 날이다. 그런데 같은 날, Microsoft의 에이전트 프레임워크 자체가 PyPI에서 털렸다. 에이전트가 클라우드 자격증명을 들고 다니는 시대에, 에이전트를 만드는 도구가 뚫리면 털리는 건 돈이 아니라 열쇠다.** 돈의 흐름과 보안의 구멍이 같은 날 같은 회사(Microsoft — Ignite의 화려한 발표와 Agent Framework의 침해)에서 교차했다는 점이 오늘의 핵심이다. 그리고 GPT-6.2의 'High' 자기개선 등급과 'Critical' 사이버 등급, MAI Code 2의 "96% 성능에 5% 비용"이라는 검증되지 않은 주장은 같은 질문을 던진다 — 싸지고 똑똑해지는 속도를, 안전과 검증이 따라가고 있는가.
