## Theme A 딥다이브 (4편) — 핵심 발견

- **[Claude Managed Agents 출시 (Anthropic 공식, 2026-04-08)](raw/articles/2026-05-01-anthropic-managed-agents-launch.md)**: 핵심 메시지는 가격($0.08/세션-시간)이 아니라 **"production agent에 필요한 인프라(샌드박스·체크포인트·자격증명·트레이싱)를 수개월→며칠로 단축"**. 도입사례 임팩트(첫 패스 오류 97%↓, 통합 수개월→수주)가 시간을 사는 가치를 정량화. **Brain/Hands/Session** 분리는 prompt injection이 코드 실행에 도달해도 자격증명 못 훔치게 하는 architectural 답.

- **[Anthropic Agent Skills (SKILL.md)](raw/articles/2026-05-01-anthropic-agent-skills.md)**: MCP에 이은 두 번째 표준 시도. The New Stack은 "Anthropic's Next Bid to Define AI Standards"라 표현. **progressive disclosure** — startup엔 name·description만, 본문은 lazy 로드 — 가 도구 많은 일반화 에이전트의 **context bloat 문제**를 우회. Lance Martin의 통찰("Claude Code도 도구 12개, Manus도 20개 미만")과 일관.

- **[LangChain Deep Agents + Skills (2025-11-25 → 2026-04 진화)](raw/articles/2026-05-01-langchain-deep-agents-skills.md)**: Anthropic SKILL.md 포맷을 **LangChain이 그대로 채택**한 것이 표준화 신호. 4월 한 달간 Deep Agents 라인이 가장 활발히 진화 (4/16 백그라운드 subagent, 4/17 Cisco 파일럿, 4/20 production runtime 24min 분석, 4/29 모델별 튜닝). Managed Agents의 오픈 대안.

- **[AGENTS.md 표준 (Linux Foundation)](raw/articles/2026-05-01-agents-md-spec.md)**: 60,000+ 저장소가 이미 채택. OpenAI Codex 자체 저장소만 88개의 AGENTS.md. OpenAI·Amp·Jules(Google)·Cursor·Factory의 협업 결과 → Linux Foundation 산하 Agentic AI Foundation으로 이관. **MCP가 표준이 된 경로와 같음**. 충돌 시 우선순위는 **closest-wins** + 사용자 명시 지시가 모든 것 override — [[concepts/harness-engineering]]의 정책 층과 같은 결.

## 백필 6편 — 나머지 흐름 따라가기

### B. 멀티에이전트 / 제어 평면

- **[A2A 프로토콜 스펙](raw/articles/2026-05-01-a2a-protocol-spec.md)** — Google → Linux Foundation. 50+ 파트너. MCP의 자매 표준(에이전트 ↔ 도구 vs 에이전트 ↔ 에이전트). 새 위키 [[concepts/a2a-protocol]] 생성.

### C. Eval · 관측 · 보안

- **[Prompt Injection Defense 2026](raw/articles/2026-05-01-prompt-injection-defense-2026.md)** — 3년 연속 OWASP #1. 공격 성공률 50~84%. 2025~6 production CVE: Microsoft Copilot 9.3, GitHub Copilot 9.6, Cursor IDE 9.8. **dual-LLM 패턴**(privileged + quarantined) + 6층 defense in depth가 유일한 viable 답. PromptArmor (ICLR 2026)는 AgentDojo에서 false rate <1%. 위키 [[patterns/owasp-llm-typescript-mitigations]]에 agentic 확장이 필요한 신호.
- **[Agent Eval Frameworks 2026](raw/articles/2026-05-01-agent-eval-frameworks-2026.md)** — DeepEval / LangSmith / Braintrust / Langfuse / Inspect AI / RAGAS 6대장. **단일 챔피언 없음**. agent eval은 단일 점수가 아니라 **trajectory(궤적) 전체** 캡처가 핵심. OTel 시맨틱 컨벤션이 진화하면 eval framework lock-in이 약해질 것.

### D. Solo dev × Agent + 보너스

- **[Solo Founder AI Stack 2026](raw/articles/2026-05-01-solo-founder-ai-stack-2026.md)** — 5대 영역(코드·콘텐츠·CS·디자인·자동화) 월 $300~$500, 연 $3K~$12K. 전통 팀 비용 대비 **95~98% 절감**. MVP 출시 $1K~$5K. Customer Support 자동화는 티켓 60~80% 자동.
- **[Anthropic Advisor Strategy (2026-04-09)](raw/articles/2026-05-01-anthropic-advisor-strategy.md)** — Managed Agents 다음 날 발표. **메인 모델 + on-demand advisor** 패턴. orchestrator-workers의 사촌. 비용·지연·품질 절충 다시 잡음.

## 인사이트 (이 백필에서 새로 보인 것)

1. **표준화 가속**: MCP → SKILL.md → AGENTS.md → A2A 의 4단 표준화가 6개월 안에 다 일어났다. 모두 Linux Foundation 또는 그 흐름. 위키의 "**오케스트레이션 패턴 → 런타임 → 플랫폼 → 통신 표준**"의 4층이 모두 stable로 굳었다.
2. **자유도 vs 운영부담의 완전한 트레이드오프**: Managed Agents와 Deep Agents Deploy가 **거의 동일한 추상화에 도달했지만 패키징·운영 모델이 정반대**. 한 쪽에 답이 없다 — 트래픽·팀·규제로 선택.
3. **사람이 쓴 컨텍스트 파일 > LLM이 쓴 것**: AGENTS.md 실증 데이터가 명시적 — 사람이 쓰면 +4%/-35~55%, LLM이 쓰면 -성공률/+20% 비용. 위키의 [[patterns/llm-wiki]] 패턴(LLM이 위키를 유지)과 미묘한 긴장 — **유지보수는 LLM이 OK, 컨텐츠는 사람이 큐레이션**이라는 절충이 답.
4. **보안의 layered가 답이라는 합의**: prompt injection 단일 기법으로는 못 막는다. 6층 defense in depth + dual-LLM 패턴 + HITL이 2026 표준. 위키 [[patterns/owasp-llm-typescript-mitigations]]를 agentic 확장으로 키울 가치가 분명.
5. **비용 모델의 새 변수**: 세션 단가($0.08/시간)가 등장. 시간을 사는 가치(MVP 단계 합리)와 누적 부담(트래픽 시 부담)의 변곡점이 이제 1인 창업자 의사결정의 명시적 변수가 됨.
