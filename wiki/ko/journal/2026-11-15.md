# 2026-11-15 학습 일지

## 오늘 배운 것

- **Blackwell 지문** (Unemployment Labs 보고서, 11-12): 중국 4개 랩의 최신 모델 6종이 공개 가중치에 NVIDIA Blackwell GPU의 초기화 지문을 남겼다. PyTorch가 Philox 난수 생성기로 초기 가중치를 채울 때 GPU의 SM 수만큼 스레드를 나눠 배치하는데, SM 수가 다르면 같은 시드라도 가중치 배열이 달라진다. Hopper 132 SM, B200/B300 148 SM, GB200/GB300 152 SM. 대상은 DeepSeek-V4-Flash·DeepSeek-V4-Pro·Kimi K3·Kimi K3.1-Pro·MiniMax-M3·Ling-3.1-flash. 증거 강도 49~1,385 시그마(우연 최대 약 8 시그마), DeepSeek-V4-Flash와 Kimi K3는 실제 Blackwell 칩에서 직접 대조 확인. 규모 추정은 5개 실행 합계 약 12,000개 GPU·5억 달러 이상이나, 효율·토큰 수·기간 가정에 의존해 저자 스스로 확신하지 않는다고 밝힌다. 단 칩의 위치·입수 경로·법 위반 여부는 입증하지 않는다. Alibaba·Zhipu·Tencent·Xiaomi·StepFun은 여전히 Hopper, Meituan LongCat-2.0에서는 NVIDIA 지문이 나오지 않았다. TechCrunch 11-13 보도, CPU 재현 스크립트 오픈소스 공개.
- **Cursor 보안 사고** (Cursor 조사 결과, 11-13·iFynx 경유): 10-29 마켓플레이스에 올라온 변조된 Claude Code 확장의 출발점은 Fireworks AI에 노출된 접근 키였다. 공격자는 키로 공유 읽기 전용 버킷을 복사해 2025년 무렵 Privacy Mode 미적용 코딩 에이전트 트레이스를 얻었고, 그 안의 검열되지 않은 API 자격증명으로 내부 시스템까지 파고들었다. 트레이스 노출 사용자 0.05% 미만, 자격증명 노출 고객 0.01% 미만. 10-29 변조된 `Anthropic.claude-code` 2.1.312·2.1.313이 마켓플레이스 캐시에 약 11시간 노출돼 최대 5,000명이 받았을 수 있다. 변조본은 시스템 정보 수집·공격자 SSH 키 설치·원격 로그인 활성화·역방향 터널로 지속성을 노렸다. Privacy Mode 사용자의 프롬프트·코드, 코드 저장소, 프로덕션 시스템, 공식 앱은 영향받지 않았다. 마지막 공격 활동 11-01 차단. Cursor는 모든 추론 트래픽을 Fireworks에서 옮기고 공유 데이터셋 접근을 끊었다. Uber도 같은 Fireworks 경유로 운전자 면허 데이터가 유출됐다.
- **Meituan LongCat-2.5** (The Decoder, 11-15): 1.6조 파라미터 에이전트 모델의 가중치를 MIT 라이선스로 공개했다. 11-02 공개 후 11-10 가중치 배포. 전체 1.6조 중 토큰당 약 480억 개만 활성화되는 네이티브 멀티모달 MoE. 전작에 이미지 이해를 더했고 긴 다단계 코딩·사무 작업용으로 강화 학습했다. Meituan 자체 측정 기준 Terminal Bench v2.1 88.4점(Claude Opus 5 89.1점)이나 회사 스스로 참고용이라고 밝혔고 독립 검증은 없다. 전문가 가중치·활성화를 4비트 양자화하고, 자가 호스팅 가이드의 샘플 구성은 Huawei Ascend Atlas A2 194개다. Nvidia GPU 안내는 없다. 전작 LongCat-2.0은 5만 개 이상의 중국 AI 칩 클러스터에서 학습했다고 회사가 밝혔다. API 프로모션 가격은 100만 토큰당 입력 약 €0.27·출력 약 €1.07. 단 "Nvidia 없이 학습했다"는 회사 주장이고, 학습 칩 벤더는 회사 게시물에 명시되지 않았다.
- **Anthropic Claude Projects 재설계** (Anthropic 원문, 11-14): Projects를 파일 폴더에서 조율된 작업 세션 집합으로 재설계했다. 코디네이터가 목표 범위를 정하고 병렬 스레드에 일을 나눠주고 결과를 검토·합친다. 각 스레드는 자기 브랜치와 저장소 복사본에서 도는 Claude Code 클라우드 세션이고, 서브에이전트·루프·워크플로우로 더 쪼갤 수 있다. 겹침은 일반 PR의 머지 충돌로 드러난다. 모든 스레드가 공유 메모리에 기여하고, 프로젝트 라이브러리가 파일·산출물을 모은다. 휴대폰에서 조율 가능하고 사용자가 자리를 비워도 작업이 계속된다. 오늘부터 클라우드 세션을 쓰고 기존 프로젝트가 없는 일부 Pro·Max 구독자에게 베타 제공, 다음 주 확대, 이후 Claude 전체·Team·Enterprise로. 스레드 하나가 세션 하나라 사용량 한도에 더 빨리 도달한다. 하루 신규 스레드 200개 상한은 보도 인용. 로컬 머신 실행은 "곧" 온다고 한다.
- **Google Antigravity /teamwork** (Google Research 블로그, 11-13): 멀티 에이전트 기능 /teamwork 성과를 공개했다. 전문 서브에이전트 팀과 Lean 4 증명 검사기 같은 자동 반증자를 짝짓고, Gemini 4 Argon·Carbon·Hydrogen이 기반이다. /teamwork-LEAP이 Weil 추측의 기계 검증 형식화를 완전 자율로 만들었다고 한다(약 180만 줄 Lean, 서브에이전트 호출 28,800회). Courtade–Kumar 추측 증명을 Lean 4로 형식화해 약 5,000만 줄(인간 수학자와 협업), Hilbert 10번 문제 첫 형식화(약 92만 줄), Birkhoff 추측 첫 형식화, 3차원 Bochner–Riesz 증명의 빈틈 수정도 포함. NMR 분자 구조 식별 top-1 95%·top-3 100%, Zircon 마이크로커널 Rust 재작성 약 80만 줄, libgav1 Rust 포팅이 C++보다 20~30% 빠르다고 한다. 외부 연구자·개발자가 Antigravity에서 오늘부터 쓸 수 있고, 학계 연구자 10,000명에게 최상위 티어 6개월 무료 신청을 열었다. 단 독립 점검에 따르면 Courtade–Kumar 5,000만 줄 중 사람이 읽을 수 있는 증명 코드는 약 23만 8,690줄이고 나머지 99.5%는 생성된 인증서 데이터다. Weil 형식화는 저장소·논문이 공개되지 않아 외부 확인이 안 되고, Axiom이 11-06 이미 자체 Weil 형식화를 공개했다.
- **llama.cpp·ggml v1.0.0** (Unite.AI, 11-13): 로컬 LLM 추론 엔진 llama.cpp와 텐서 라이브러리 ggml이 3년 반 만에 첫 1.0을 냈다. 핵심은 속도보다 약속이다. 앞으로 공개 C API를 깨는 변경은 메이저 버전 상승과 함께만 온다. 35개 deprecated 공개 함수 제거, NextN 추측 디코딩 API를 메인 공개 헤더로 승격, FP8 KV 캐시 추가(Qwen2.5-7B 기준 32,768 토큰 KV 페이로드 1,792→896 MiB 계산치), 호스트 메모리 MoE 전문가 캐시, llama-server의 SSRF·DNS 리바인딩 방어 강화. 150개 이상 모델 아키텍처 지원, GitHub 스타 약 135,000개, MIT 라이선스. 단 전후 속도 측정 수치는 없다.

## 인사이트

**오늘의 축은 "증거"다. 가중치는 칩을 말하고(Blackwell 지문), 트레이스는 공급망을 말하고(Cursor), 가중치 공개는 성능 주장을 검증 가능하게 만든다(LongCat).** 어제(11-14)의 "에이전트가 문을 열고 돈을 내는 날, 공격자도 같은 문으로 들어온다"가 오늘은 더 구체적이다. Cursor 사건은 에이전트 도구의 공급망이 곧 내 보안 경계라는 것을, Blackwell 보고서는 공개된 숫자만으로 거대한 지정학 주장을 검증할 수 있다는 것을 보여준다. 한편 Anthropic Projects와 Google /teamwork는 같은 "멀티 에이전트"를 정반대 방향에서 푼다. Projects는 코디네이터 한 명이 일을 나누는 관리형 팀이고, /teamwork는 검사기가 틀린 답을 쳐내는 검증형 팀이다. 두 설계 모두 "검사·합치기"를 중심에 둔다는 점에서, 1인 개발자의 하네스도 결국 같은 질문으로 수렴한다. 에이전트에게 무엇을 맡길 것인가가 아니라, 그 결과를 무엇으로 검증할 것인가.
