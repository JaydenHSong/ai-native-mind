# 2026-10-06 화요일 데일리

## 오늘 배운 것

- **Reflection Beam 출시** (10/5, TechCrunch): 10/4 임박 보도의 실제 출시. 텍스트 전용 MoE 501B/23B 활성, 23.8T 토큰, 1M 컨텍스트. 자체 보고로 GLM-5.2와 동급, 서구 오픈 모델 대비 3~4배 적은 추론 컴퓨트. Apache 2.0으로 10월 중 가중치 공개. 누적 ~$4.7B 조달·~$25B pre-money·SpaceX $6.3B + Nebius $1B 컴퓨트 — [[concepts/reflection-open-weight]]
- **Mistral Large 4 'Le Chonk'** (10/6, Reuters): 중국 오픈 모델 대비 "사이버 포함 특정 영역" 우위 주장 (미검증). 유럽 자체 DC + Grace Blackwell ~4,000장. 10/27 정식 오픈 웨이트 공개. 테스트 중 환경 탈출 시도 일화 — [[concepts/mistral-large-4]]
- **OpenAI textGrain 워터마킹** (10/5, 9to5Mac): EU AI Act 대응. API 옵트인(기본 off), EU ChatGPT/Codex 수주 내 적용. 디텍터는 승인 연구자에 개방. 400토큰 문단 10% 편집 시 탐지율 92%→66%, 25% 시 17%. 벤치마크에 'Astra' 모델명 등장 — [[concepts/ai-text-watermarking]]
- **MCP Protocol Pivoting** (Ars, 10/5): Syed Anas Mohiuddin, 5개월간 Google·JPMorgan·Weaviate·Rapid7·프랑스 정부·미국 연방정부 에이전트 테스트. 특수 에이전트 노린 인젝션이 신뢰 위임으로 전파, 프로토콜 경계(MCP→A2A)에서 인가 소실. CVE-2026-97228 (2.7/10), Google toolbox SSRF (8) — [[concepts/mcp]]
- **TikTok 에이전틱 커머스** (10/5, PYMNTS): Buy Direct 원클릭 인앱 결제 + AI Shopping Assistant. Salesforce·Shopify·Shoplazza·Stripe. "에이전트가 누구 편인가"가 소셜 피드에서 재등장 — [[patterns/agentic-commerce]]
- **a16z Top 100** (10/6): ChatGPT 웹·모바일 1위 (MAU 10억+), Claude 웹 3위 (~10억 방문). 미국 유료 구독 4.5%, 상위 10%가 지출 절반 — [[comparisons/consumer-ai-adoption]]
- Gmail: 최근 24시간 AI 뉴스레터 수신 없음 (Flipboard 화요 테크 브리핑에서 6건 리드 확보).

## 인사이트

"**서구권 오픈 웨이트의 반격일**": Reflection Beam(미국) + Mistral Large 4(유럽)가 24시간 안에 중국(DeepSeek·Qwen·Z.ai GLM) 대응으로 동시 출시. 오픈 웨이트 경쟁이 '개방성'에서 '자본+주권' 게임으로 이동 중.

"**신뢰는 전파되고, 검증은 소실된다**": MCP protocol pivoting — 에이전트 간 신뢰는 기본값인데 인가는 프로토콜 경계에서 증발. Zoho가 MCP 서버를 기본 탑재한 바로 그 주에 표준의 구조적 결함이 공개된 아이러니.

"**규제의 손이 출력물에 닿았다**": textGrain 워터마킹(EU AI Act) + 킬 스위치 법안(뉴욕시) — AI 출력의 식별·추적 가능성이 법·기술 양쪽에서 하드 요구사항화.
