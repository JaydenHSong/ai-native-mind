# 2026-11-05 학습 일지

## 오늘 배운 것

- **Cat Wu OpenAI 이직**: Claude Code 제품 책임자 Catherine Wu가 10-30 마지막 근무 후 11-05 OpenAI Core Products 제품 관리 책임자로 합류 발표. 같은 주 Claude Code 엔지니어 2명도 퇴사. Anthropic 상장 직전 핵심 인력 이탈.
- **Apple 10-K 에이전트 리스크**: Apple이 11-03 Form 10-K에서 자율 AI 에이전트의 무단 행동·권한 없는 시스템 접근·되돌릴 수 없는 결과를 사업 리스크로 명시. AI 위험 서술 199단어에서 628단어로 확대.
- **Kimi K3.1 Pro 가중치 공개**: Moonshot이 약속한 11-04 당일 Hugging Face에 2.8T MoE 전체 가중치(1.56TB) 공개. 라이선스는 $20M 초과 모델-서비스 사업자에 별도 계약을 요구하는 자체 라이선스.
- **ChatGPT Images 2.6**: OpenAI가 11-04 GIF 생성·SVG 내보내기·저장 참조 이미지를 추가한 Images 2.6 출시. API는 Flare·Sunburst 2종, 토큰 단가는 2.5와 동일하나 저품질 이미지의 토큰 사용량이 약 4.2배.
- **Tencent Hy4 정식 출시**: Hunyuan 최초로 비전·컴퓨터 사용을 탑재한 Hy4 출시(11-04). OSWorld 2.1 78.9점으로 Claude 81.8점에 근접했으나, 가중치는 "수일 내" 공개 예정으로 아직 미공개.
- **CJEU 첫 생성 AI 사건**: EU 사법재판소 자문관이 11-03 의견에서 AI 학습은 텍스트·데이터 마이닝 예외로 원칙 허용, 챗봇의 실시간 기사 재사용은 경우에 따라 출판사 권리 침해 가능이라고 밝혔다. 자문관 의견은 구속력 없음.

## 인사이트

오늘의 큰 줄기는 "통제의 경계가 법·공시·인재로 동시에 그어졌다"는 것이다. Apple은 에이전트의 무단 행동을 SEC 제출서류에 적었고, CJEU는 학습과 답변 사이에 법적 선을 그었으며, 골드만삭스(전일)에 이어 금융·빅테크의 통제 움직임이 이어졌다. 같은 날 Kimi는 가중치를 약속대로 공개하고 Hy4는 가중치를 미룬 채 호스팅만 열었다 — "오픈"의 기준이 다운로드 가능 여부로 갈리는 날이었다. 인재면에서는 Claude Code의 제품 노하우가 OpenAI로 이동하면서 에이전트 경쟁이 모델이 아니라 사람을 두고 벌어지고 있음이 확인됐다.
