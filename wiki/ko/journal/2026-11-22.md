# 2026-11-22 학습 일지

## 오늘 배운 것

- **리만 가설 증명 주장 — Claude와 6주 작업, Lean·Mathlib 독립 검증 통과, 수학계 합의는 아직** (Scientific American, 11-21): Anthropic 수학자 Levent Alpöge가 Claude와 약 6주간 작업해 1859년 제기된 리만 가설의 증명을 찾았다고 11월 20일 발표했다. 일반화 리만 가설(GRH)까지 해결했다고 주장. 증명은 논문이 아니라 Lean 코드 약 1,740만 줄(175,187개 파일, Mathlib 전체의 약 7.6배)로만 공개됐다. 11월 21일 Lean FRO·Mathlib Initiative 공동성명 "명제와 증명 모두 옳다"고 인증 — MIT Andrew Sutherland 등 독립 연구자들이 자체 재컴파일해 175,187개 모듈 전부 오류 0건, 3개 표준 공리만 사용, 기호 재정의·커널 악용 여부 확인하는 comparator run도 완료. 다만 Alpöge 본인도 증명 일부를 완전히 파악하지 못했다고 인정했고, Clay 연구소는 상($100만) 심사를 위해 출판 후 최소 2년 검증 기간을 요구해 현재 미해결 표기 유지. 같은 날 인간 단독 증명 주장(Alessandro Masullo)도 등장. 시기: Anthropic 상장(11월 19일, $813억 조달) 바로 다음 날 발표라 시점 논란도 있음. Anthropic은 공식 논평 없음. 수치 주의: GRH 인증 상태는 보도마다 서술이 갈린다.
- **OpenAI 211분 장애 — 인증 DB 복제본 2개 동시 붕괴로 요청 75% 실패** (AI Agent Update·OpenAI, 11-22): 11월 21일 13:48~17:21 PT, 총 211분(약 3.5시간) 동안 OpenAI API와 ChatGPT 요청 실패율이 최대 75%. 원인은 정기 점검 중 Primary API 서비스(전 스택 인증 담당)가 쓰는 Postgres 읽기 복제본 2개의 동시 실패 — 복제본이 인증 경로의 하중을 지고 있던 구조적 단일장애점. 영향: API 전 영역(Chat Completions, Fine-tuning, Embeddings, Images, Batch, Audio, Moderations, Realtime, Files)과 ChatGPT(대화·로그인·검색·파일 업로드·음성 모드). 복구: 신규 복제본 2개를 같은 리전에 띄워 11월 21일 저녁 복구, 11월 22일 아침 전 시스템 정상. 쿼리를 주 DB로 100% 전환해 복제본이 원인임을 확인. 재발 방지: 유사 점검 중단, 연결 churn 감소 설정 조정, 복제본에서 트래픽을 비율 단위로 빼는 기능 플래그 배포. 시장 맥락: 나스닥100이 5.61% 급락한 다음 날이라 파장이 컸고, OpenAI는 비상장이라 MSFT(-2.8%, $484.52)가 대리 지표. 수치 주의: 일부 매체는 장애 시간을 213분으로 보도.
- **Together AI 프롬프트 유출 — 코딩 에이전트가 커밋한 키, OpenRouter 공급사 3곳 퇴출** (Together AI·OpenRouter, 11-21~22): Together AI가 11월 21일 공식 보안 공지에서 AI 코딩 에이전트가 실수로 커밋한 자격증명 탓에 고객 프롬프트 샘플이 유출됐다고 밝혔다. 공개 GitHub 저장소 `xorl` 개발 중 코딩 에이전트가 비공개 Hugging Face 저장소 접근 자격증명을 커밋했고, 자동 스캔이 탐지·되돌렸으나 노출 창구 동안 무단 제3자가 저장된 프롬프트 샘플을 전부 다운로드. 유출 범위: MiniMax M3·GLM-5.2·Kimi K2.6 요청(주로 2026-06-24, 07-04, 07-08, 07-14)에서 일상 테스트용으로 수집한 프롬프트 샘플. 침입자는 샘플 속 타 서비스 자격증명을 찾아 유효성을 테스트했고, 그중 5개가 Dragos 실험용 카나리아 토큰이었다. 실제 자격증명 유출 여부는 검토 중. 대책 4가지: 범위·단기 자격증명 및 키리스 접근, 전 PR 자격증명 검사, 신규 계정 ZDR 기본값, 코딩 에이전트 사용 개발 프로세스 개정. OpenRouter 조치(11-22): 공급사 3곳 퇴출(업체명 비공개), ZDR 적격 엔드포인트 125개 제외(일부 예방적), 잠재 피해 고객 전원 통지, OpenRouter 자체 침해는 없었다고 밝힘. Novita도 05-28~11-11 MiniMax 경유 요청의 제3자 접근 가능성을 별도 공지. 배경: Dragos 카나리아 토큰 연구(7~11월 약 200만 개 프롬프트, 11월 20일 공개)의 후속 파장 — ZDR 표시에도 프롬프트가 저장·전달된 사례가 확인돼 "ZDR은 라벨일 뿐 보장 아니었다"는 문제 제기.
- **Oracle, OpenAI 인프라 계약 '완전 자금 조달 완료' 선언 — 5년 $300B·4.5GW, 주가는 -8.5%** (AI Agent Update·Reuters, 11-21): Oracle이 11월 20일 X 게시물로 OpenAI 인프라 계약의 자금 조달이 완료됐다고 선언. 계약 규모는 5년 약 $3,000억 컴퓨팅 용량, 미국 내 4.5GW 추가 데이터센터 용량(Abilene Stargate 부지 외). "현 투자 사이클에 완전 자금 조달된 첫 하이퍼스케일러" 자칭. 11월 자금조달 약 $200억: 주식 약 $100억(86,206,897주, 주당 $116) + 채권 약 $100억(만기 2029~2046, 금리 7~8.65%). 2027~2030회계연도 추가 자본시장 조달 상한 $200억을 이번 조달로 소진. 진행 상황: Abilene 캠퍼스 준공 임박, Shackelford County 차기 GW급 캠퍼스 인허가 완료, Nvidia Vera Rubin 랙 인도 임박. 2028회계연도 하반기 잉여현금흐름 흑자 전환, 2029회계연도 $300억 이상 목표. 시장 반응: 발표 당일 ORCL -8.48% → $101.19, 52주 최저 종가 — 자금조달 완료보다 부채 부담·AI 지출 회의론에 반응했다는 해석.

DeepSeek 본사는 공식 발표가 없다. 투자자: 텐센트·CATL 연계 펀드가 투자자 파트너십에 각각 약 9.6%씩 출자, 중국 국가 AI 펀드 직접 지분도 0.4%로 확대. 밸류에이션: 1차 외부 자금(2026-07) 500억 위안·밸류에이션 3,500억 위안에서 4개월 만에 약 +76% 상승. 수치 주의: The Information은 약 1,055억 위안(약 $158억)·밸류에이션 약 6,155억 위안(약 $890억)으로 보도해 Caixin과 차이가 있다 — 두 수치 모두 등기 기록·보도 기반이다. 배경: 11월 15일부터 컴퓨팅 부족을 이유로 장시간 대화·일부 문서 읽기 기능 제한 중.
- **자율 에이전트 Cairn, 의료 영상 서버 제로데이를 11분 만에 찾아 루트 탈취 — AWS 공개** (BleepingComputer·AWS, 11-20): AWS가 11월 20일 공개한 글에 따르면 중국 연계로 추정되는 행위자가 오픈소스 자율 펜테스트 프레임워크 Cairn에 "셸 접근 획득"이라는 목표만 주고 동아시아 외 중국 대학들을 노렸다. 9월 8~10일 약 48시간. 의료 영상 주석 서버 MONAI Label의 경로 순회(path traversal) 제로데이를 API 매핑부터 임의 파일 쓰기까지 약 11분 만에 발견 — CVE-2026-133968, CVSS 9.8. 후속 세션에서 `sitecustomize.py`에 리버스 셸을 심고 학습 API 엔드포인트로 루트 프로세스를 띄워 루트 탈취. 발견 경위: AWS가 9월 10일 인증 없이 노출된 Cairn 인스턴스를 발견해 공격자 대시보드 자체를 열람하며 재구성 — 10월 NorForge 캠페인과 같은 "노출된 대시보드가 단서" 구조. 패치 상태: 수정은 10월 19일 병합됐으나 설치 가능한 릴리스는 아직 없음(최신 0.8.5는 2024년 11월). 자율 공격 에이전트의 실전 제로데이 발견 첫 구체 사례.
