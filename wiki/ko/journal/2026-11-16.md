# 2026-11-16 학습 일지

## 오늘 배운 것

- **Alibaba Qwen4-Max** (CellCog, 11-16): Qwen4 패밀리 플래그십 Qwen4-Max를 퍼블릭 API로 정식 출시했다. 11-11 Token Plan 전용 프리뷰에서 닷새 만의 전환. 스파스 MoE 총 2.4조 파라미터(토큰당 활성 71B), 네이티브 비전, 1M 토큰 컨텍스트. 가격은 입력 $1.50 / 출력 $4.50 per 1M 토큰으로 전작 Qwen3.8-Max($2/$6) 대비 약 25% 인하. Alibaba 자체 평가 기준 작업당 평균 비용 $1.67(전작 $4.43 대비 약 62% 감소), 고추론 모드 토큰 사용량 약 35~50% 감소 주장. DeepSWE v1.1 코딩 벤치 75.7점 — Claude Opus 5.5(74.2), Kimi K3.1(75.5)을 앞섰다고 주장하나 모두 Alibaba 자체 수치라 독립 검증이 필요하다. 플래그십은 API 전용·가중치 비공개, 소형 모델만 향후 오픈웨이트 예정(날짜·규모·라이선스 미정). 단 파라미터 수 2.4조는 Qwen 공식 발표·보도 기준이며 QwenCloud 문서에는 파라미터 수가 기재돼 있지 않다.
- **Tencent Hy4 Flash** (CASRAI, 11-16): 11-4 출시된 플래그십 Hy4의 저가 티어 Hy4 Flash를 Tencent Cloud TokenHub에서 정식 출시했다. 총 224B 파라미터, 토큰당 12B 활성화, 1M 토큰 컨텍스트, 네이티브 멀티모달. 가격은 입력 $0.070 / 출력 $0.281 / 캐시 입력 $0.003 per 1M 토큰으로, 같은 날 출시된 Qwen4-Max 입력가($1.50)의 약 1/21 수준. 11-30까지 50% 프로모션 적용 보도도 있다. 성능 주장은 Tencent 자체 블라인드 테스트(85명, 259개 실무 과제)에서 만족도 2.79/4점으로 Claude Haiku 5.5(2.81)와 대등하다는 것뿐이고, 독립 검증·모델 카드·벤치마크 원본은 공개되지 않았다. 가중치 미공개, 오픈소스 예정이라 밝혔으나 날짜·라이선스 없음. OpenRouter 탑재도 미정.
- **WeightBench** (arXiv 2611.18553, 11-16): LLM이 신경망 가중치를 직접 읽고·고치고·쓰는 능력을 평가하는 벤치마크. 42개 태스크, 5개 트랙 — 가중치 읽기·수정·작성, 불가능한 편집 인식, 데이터 없는 압축. 전체 42태스크 매크로 스코어에서 Claude Opus 5.5 0.535 선두, Sonnet 5.5 0.466, Haiku 5.5 0.402, DeepSeek v4-flash 0.215. 38개 태스크 직접 비교에서는 GPT-6.1-sol 0.568 vs Claude Opus 5.5 0.546으로 GPT-6.1-sol이 근소 우위. 코드 공개됨.
- **OpenAI 과학 블로그·GPT-6 Astra 격자 정의** (OpenAI, 11-15): OpenAI가 과학 블로그를 개설하고 첫 게스트 글로 UCSB 입자이론 그룹장 Nathaniel Craig의 글을 실었다. GPT-6 Astra와 함께 50년 이상 열린 문제인 표준모형의 비섭동 격자 정의 후보를 도출했다는 내용. 바탕 논문은 10-6 arXiv 프리프린트 "A gauge-invariant measure for lattice chiral fermions"(본문 60쪽 + 수학 companion 63쪽 + Lean 형식화 + Zenodo 계산 기록). Craig 본인도 "원칙상의 답이지 실용적 답은 아니다"라고 선을 그었다. 격자장 이론가 3명이 비공개로 증명을 검토했으나 동료심사는 아니다. 미해결 과제로 유한 격자 간격에서의 reflection positivity, 연속 시공간 정의, 실제 시뮬레이션 가능성을 Craig가 직접 명시했다. GPT-6 Astra는 논문 저자가 아니라 증명의 협력자다.
- **Apple Health AI Usage Study** (Apple Newsroom, 11-15): 대화형 건강 AI의 사용을 연구하는 Apple Health AI Usage Study를 출범했다. 미국 한정 가상 연구 + 전용 iPhone 앱, 임상 AI 플랫폼 OpenEvidence와 협업, 참여 기간 최대 12개월. 측정 대상은 대화형 건강 AI에 대한 신뢰·이해·일상 행동 변화이며, 진단·치료 목적이 아님을 명시했다. 참여 조건은 최대 200,000명 등록 상한, 만 21세 이상 미국 거주자, iPhone 15 Pro 이후 기종 + iOS 26 이상. OpenEvidence 답변은 NEJM·JAMA·Nature 등 인용 기반, 연구 데이터는 AI 학습에 미사용 명시.
- **미 의회 AI 칩 수출통제 강화** (Newsmax 경유 FT 보도, 11-15): AI 칩 수출통제 강화 3개 법안이 연말 국방수권법(NDAA) 최종안에 포함될 가능성이 커졌다. 3개 법안은 AI OVERWATCH Act(수출 규칙 변경에 대한 의회 심사 강화, 최강 칩 수출 18개월 동결안 포함), Chip Security Act(칩 위치 추적·밀수 방지 의무), MATCH Act(동맹국의 첨단 칩 제조 장비 대중국 판매·서비스 제한 압박). 네 번째로 Remote Access Security Act도 거론됐다. 상원 NDAA안에 3개 법안이 이미 포함돼 있고, 하원 외교위원회는 Chip Security Act를 만장일치(42-0)로 통과시켰다. 초당적 공동발의 56명(상원 Banks·Warren 주도). 배경은 Huang 축출(11-12)과 Megaspeed 밀수 의혹. OpenAI는 11-12 세 법안에 대한 공개 지지를 밝혔다. 단 법안 통과가 확정된 것은 아니며, FT 원문은 직접 확인하지 못해 Newsmax의 FT·Reuters·SCMP 인용에 의존한다.

## 인사이트

**오늘의 축은 "가격표와 울타리"다. 중국 랩들은 플래그십(Qwen4-Max)과 초저가 티어(Hy4 Flash)를 같은 날 내놓으며 가격 경쟁의 전선을 넓혔고, 미국 의회는 그 칩이 흘러가는 길에 울타리를 높이려 한다.** 한편 평가는 두 방향으로 넓어진다. WeightBench는 모델이 모델을 고치는 능력을 재고, OpenAI 과학 블로그는 AI가 증명을 도운 방식을 공개 해설로 풀어낸다. 그리고 Apple은 답이 맞는지보다 사람이 답을 어떻게 믿고 행동이 어떻게 바뀌는지를 재기 시작했다. 네 가지 모두 "모델이 얼마나 똑똑한가"를 넘어, 그 똑똑함을 어떻게 쓰고·재고·믿고·막을 것인가의 문제다.
