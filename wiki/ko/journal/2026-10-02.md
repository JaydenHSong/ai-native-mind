# 2026-10-02 학습 일지

## 오늘 배운 것

- OpenAI Dots 정식 출시 (DevDay 9/29, 10/2 보도 정리): 첫 dot은 Pro/Business Premium 무료, 대화는 한도 미포함·작업은 포함. Pro 500 ($500/월, Ultrafast) 신설, 신규 Pro 200은 낮은 allowance (기존은 10/29까지). GPT-6.1 Sol 동반 (Astra의 1/5 토큰가). "Sign in with ChatGPT" + MCP Apps 병행. [[concepts/persistent-agent]] 보강.
- DIVD 침해 (9/21 발생, 10/2 보도): 자율 AI 에이전트가 Zammad 제로데이 2개 (CVE-2026-102489 RCE + CVE-2026-102490 root 상승) 체인해 수 초 만에 완전 장악. 완전 자율 사이버 작전의 첫 상세 문서화. 자원봉사자 이메일 탈취, 네트워크 분할이 측면 이동 차단. [[concepts/agent-supply-chain-security]] 보강.
- OpenAI, Moonshot AI 연관 세력의 hidden reasoning 추출 시도 차단: "모델을 만드는 경쟁이 아니라 어떻게 생각하는지를 지키는 경쟁". 추론 과정은 가중치만큼 핵심 IP. [[concepts/reasoning-extraction-attack]] 신규 (confidence medium).
- Decision model 웨이브: Cloudflare Clef/Clef-flash 오픈소스 (Apache 2.0, Workers AI RL 파인튜닝) + Strands Decider 2B (20억, 로컬, 수십~수백 ms). LLM 액션 전 로컬 decider 게이팅 패턴 ("이 툴 호출은 grounded한가?"). [[concepts/semantic-decision-engine]] 보강 (low → medium).
- DeepSeek × Huawei Ascend 파트너십 (10/2): Ascend 최적화 오픈소스 인프라 공동 구축. 저가 파괴자 → 가격 결정력 인프라 → 하드웨어 수직 통합의 3단계. [[comparisons/frontier-lab-economics]] 보강.
- GitHub Copilot computer use 퍼블릭 프리뷰 (10/2): 화면 읽기·클릭/입력/스크롤/드래그, 앱 제어 전 사용자 승인. API 없는 레거시까지 자동화 범위. [[comparisons/ai-coding-tools]] 보강.
- (보강 후보 처리) Transluce 후속 (BleepingComputer 10/1): 미 교육부 대상 하루 약 20만 요청 규모 확인 → agent-supply-chain-security Transluce 섹션에 규모 상향 보강. Sonnet 5.5 Terminal-Bench 70.6은 9/29에 이미 반영 — 추가 보강 없음.

## 인사이트

- 오늘의 축은 **"에이전트의 몸"**: Dots(상시 가동)·Copilot computer use(화면 조작)·DIVD 침해(자율 사이버 작전) — 에이전트가 화면과 네트워크를 직접 건드리는 주체가 되면서, 능력의 확대와 공격 표면의 확대가 같은 날 문서화됐다.
- **"생각의 보호"가 새 전선**: Moonshot reasoning 추출 차단 + GLM-5.3 추론 선채움 붕괴 (9/30) — 추론 과정이 IP이자 공격 표면. "모델을 지키는 것"과 "생각을 지키는 것"은 다른 문제.
- **비용 축의 2차원화**: Dots(상주 시간)·Pro 500(속도)·decision model(생성 회피) — 2026-10의 비용 최적화는 "어떤 모델"이 아니라 "어떤 과금 축"을 고르는 문제.
