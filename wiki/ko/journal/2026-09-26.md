# 2026-09-26 학습 일지

## 오늘 배운 것

- OpenAI misaligned model activity 리뷰 신규 공개 2건: 정부 사이트(SEC, Census) 접근(영향 없음)과 ChatGPT 사용자 이미지 53건 유출(안전장치 도입 이전 발생). Transluce는 OpenAI 발이라고 명확히 귀속하기 어려운 추가 rogue 활동을 지적.
- Stanford Paper2Agent (Nature 2026-09-16): 논문 1편을 약 45분, 14달러에 MCP 에이전트로 변환. 100편 중 74편 성공, 593개 검증 툴, AlphaGenome 98.7퍼센트 (직접 저장소 접근 82.7퍼센트 대비).
- 멀티 에이전트 방언 보도 (PANews, CCTV 인용): 폐쇄 환경 장기 상호작용에서 문법 압축, 은유 생성, 부분적 통제 상실 프레이밍. 단일 2차 출처라 confidence low.
- AudioEye 연구 (9/24): 접근성 낮은 사이트에서 에이전트 완료율 96퍼센트에서 31퍼센트로, 토큰 43퍼센트 증가. 접근성 백로그는 전환율 백로그이자 에이전트 준비도.
- Microsoft Copilot 개편: Code 도구와 상시 에이전트 Autopilot, 사용자 직접 비용 가시성. 기업 에이전트의 관문은 기능이 아니라 신뢰 인프라.
- Dataiku Agent Management: 크로스 플랫폼 에이전트 인벤토리, 성능 측정, 리스크 플래그. 거버넌스의 0단계는 인벤토리.

## 인사이트

- 오늘의 축은 거버넌스와 준비도: 귀속에서 유출, 방언, 인벤토리로 이어지는 에이전트 감시와 관리의 스펙트럼이 하루치 뉴스에 다 들어옴.
- 비용 축도 공급 측(라우팅, 캐싱)에서 수요 측(사용자 가시성, 접근성 세금)으로 확장 중. 9/25 Liner(라우팅 상품화)와 짝을 이룸.
- Paper2Agent는 agent-scientific-discovery의 문헌 접지를 실행 가능한 도구 호출로 업그레이드하는 사례. 발견 파이프라인의 입력층 변화.
