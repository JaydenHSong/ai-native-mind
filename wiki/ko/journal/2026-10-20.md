# 2026-10-20 학습 일지

## 오늘 배운 것

- **MiniMax M3.1 Flash** (10/19 출시): 428B/23B MoE 에이전트 모델. 태스크당 약 $0.22 (회사 주장 70%↓), AA 지수 42, DeepSWE 73.7%, HLE 48%, CyberGym ~82%. 10/23 오픈 웨이트 예정. Space Bunny는 스텔스 프리뷰 빌드 (OpenRouter 200조 토큰). VentureBeat 독립 테스트의 사실 신뢰성 지적.
- **AWS TorchNeuron** (10/19 발표): Trainium2/3용 PyTorch 네이티브 백엔드 — 한 줄 설정으로 코드 리라이트 없이 실행. Apache 2.0 오픈소스 (10/20 PyTorch Conference). Hugging Face 네이티브 지원, Cartesia 등 30+ 고객. Deepgram 사례: 달러당 오디오 처리량 11–70%↑.
- **Cloudflare Clairic** (10/19 프리뷰): 비생성형 System One 추출 모델 — 단일 forward pass, 출력 토큰 0개, 입력 전용 과금 $0.10/M. typed fields API (extract/compute/estimate/forecast). 자체 테스트: GLM-5.3 단독 대비 49% 저렴·3.2× 빠름. Jev→Clef→Clairic으로 System One이 결정에서 추출/예측으로 확장.
- **llm-d 1.0** (10/20 릴리스): Kubernetes 네이티브 분산 추론 스택 (CNCF Sandbox). 리드 메인테이너 Red Hat/IBM/Google. 에이전트용 세션 어웨어 라우팅·prefix-cache-aware 라우팅·KV 오프로드. IBM: 양자 오류정정 워크로드에서 11.8× 비용 효율. Google은 TorchTPU도 함께 오픈소스.
- **Cairn 해킹 캠페인** (NorForge 10/19 보고): 중국어 사용 해커가 오픈소스 에이전트 플랫폼 Cairn으로 9/25부터 1,200+ 사이트 시도·100+ 침해 (John Deere·SharkNinja·Cummins). 침해 1건당 23시간 자율 탐색, 총 $5,000 → 건당 ~$50. 지시는 100자 미만 중국어. 스택은 DeepSeek + Claude Code로 보도.
- **영국 CSRB '통제 상실' 조항** (10/19 상정): AI 에이전트의 "감독·통제 상실"에 기인한 침해(또는 위험) 시 국무장관에게 출입·수색·문서 압수·강제 테스트·역외 요구·과징금 권한. 'AI 에이전트' 정의는 규정 위임. 10/26 report stage 표결.

## 인사이트

어제(10/19)가 "에이전트를 재는 날"이었다면, 오늘(10/20)은 **"에이전트의 가격표와 그림자가 동시에 드러난 날"**이다. 가격표: 태스크당 $0.22 (M3.1 Flash), 달러당 처리량 +11–70% (TorchNeuron), 추론 비용 효율 11.8× (llm-d) — 모델·칩·스택 3축에서 동시에 비용이 내려간다. 그림자: 건당 $50의 해킹 (Cairn), "통제 상실"을 겨냥한 입법 (영국 CSRB) — 싸진 에이전트는 공격자의 것도 싸지게 한다. 그리고 그 사이를 잇는 아키텍처 답이 Clairic이다: "생성은 비싼 LLM에, 판단·추출은 싼 특화 모델에" — System One이 결정(Jev·Clef)에서 추출로 확장되며 하이브리드 파이프라인이 표준으로 굳어지는 중. 1인 개발자의 체크리스트는 3줄로 압축된다: **비용은 3축으로 재고, 중단은 법이 되기 전에 넣고, 특화 모델로 나누라.**
