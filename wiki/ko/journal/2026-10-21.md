# 2026-10-21 학습 일지

## 오늘 배운 것

- **NVIDIA OpenShell** (10-21 GTC Berlin 발표): AI 에이전트용 풀스택 참조 아키텍처 — "생각은 Rubin에서, 행동은 Vera에서, 통제는 BlueField에서". Vera CPU의 오픈소스 OpenShell 보안 런타임이 하네스 경계를 설정하고, BlueField-4 DPU의 Sentry가 대역 외로 감시해 실리콘 레벨에서 정책 강제. 위반 시 밀리초 단위 격리·중단. 참여사: Anthropic·AWS·Google Cloud·Meta·Microsoft·OpenAI·SpaceX Super Intelligence 등. 약점: NVIDIA 하드웨어 종속, OpenShell GitHub 미해결 보안 이슈, 텔레메트리 기본 수집.
- **DHS DeepSeek 연방 금지 공식화** (10-20 Federal Register 게재): DHS Exclusion and Removal Order #2026-01 — 연방 민간행정부 기관의 딥시크 제품 조달 금지 + 기존 시스템 제거. 대상은 Hangzhou DeepSeek AI Co., Ltd 및 계열사 + 딥시크 기술 기반 제3자 제품/서비스. 7-24 발령, 60일 예외신청 후 10-20 공식 게재 (FR Doc. 2026-21447). 근거는 2018년 FASCA. 중국 외교부 "국가안보 개념 과도 확대" 반발. 어제 탈락 후보의 지시된 후속 추적 결과.
- **국무부 'Super Intelligence' 용어 지시** (10-19 cable): 전 직원에게 새 문서에서 "artificial intelligence" 대신 "Super Intelligence"(SI) 사용 지시. 거버넌스 기구·프로그램 명칭 전부 교체 (American AI Exports Program → American SI Exports Program). 법률·조약·계약 등은 예외. 트럼프 9-29 행정명령 이행의 최초 부서 차원 지침.
- **Mastercard Agent Pay for Machines** (10-20 발표): AP4M 바이어/셀러 양면 API·SDK·샌드박스 얼리 액세스 개방 (파일럿). 핵심은 x402 오픈 결제 프로토콜 — 휴면 HTTP 402 코드를 되살려 오프체인 서명 바우처로 기계 속도의 API 호출 결제, 서브센트도 정산 비용 없이. Coinbase가 Base·Solana에서 이미 1억 건+ 처리. BVNK (8월 인수)가 법정화폐/스테이블코인 양면 정산. 데모: 사전 승인 예산 하나로 9회 결제.
- **Supermicro × Nutanix 프라이빗 추론 스택** (10-21 발표, 계획 단계): 온프렘 프라이빗 추론의 토큰당 비용 절감 목표 공동 엔지니어링. 노드당 Blackwell Ultra 8개 + Nutanix Cloud Platform·Agentic AI·Kubernetes + Spectrum-4·ConnectX-7/8·BlueField-3. 2027년 초 판매 예정. "에이전틱 워크로드 = GPU 추론 + CPU 툴 호출·코드 실행·검색·오케스트레이션"을 풀스택 패키지로.
- **NVIDIA DSX POD** (10-21 발표): Vera Rubin AI 팩토리 전체를 모듈 컨테이너에 공장 통합·검증 후 납품하는 참조 설계. 준비된 사이트 기준 6개월 → 최단 14일 배치 주장 (키노트 구두 "약 1개월"과 불일치). 황: "1GW DC는 $500억, 연 $400억 매출 — 3개월 지연이면 $100억 매출 지연". Dell·HPE·Foxconn·Schneider·Vertiv 2027년 초 납품. Crusoe·Armada×Johnson Controls (500MW) 합류.

## 인사이트

어제(10/20)가 "에이전트의 가격표와 그림자"였다면, 오늘(10/21)은 **"통제와 속도의 날"**이다. 통제의 축: OpenShell이 에이전트 안전을 실리콘 레벨 강제 집행으로 끌어올렸고, 영국 CSRB (어제)에 이어 미국 DHS가 딥시크 제거를 명령하고 국무부가 용어까지 통제한다 — "보고 → 권고 → 집행"의 사다리에 "용어"와 "공급망" 칸이 추가됐다. 속도의 축: DSX POD의 "14일 배치"와 x402의 "기계 속도 결제" — 인프라를 깔아내는 속도와 에이전트가 돈을 쓰는 속도가 동시에 빨라진다. 두 축이 만나는 지점이 1인 개발자의 설계 공간이다: **빨라진 에이전트에게 돈(결제 레일)과 몸(팩토리)이 생기는 동안, 멈추는 방법(실리콘 강제·중단 훅)과 멈춘 기록(감독 로그)은 법이 되기 전에 갖춰야 한다.** 체크리스트는 3줄: **통제는 하드웨어까지 내려가고, 결제는 HTTP로 들어오고, 용량은 공장에서 찍혀 나온다.**
