# Microsoft·Alphabet Q3 실적 갈림 — Azure +48%와 현금흐름, 클라우드 2배와 마이너스 현금흐름

## 쉽게 읽기

**비유**: 같은 AI 파티에 간 두 회사가 계산서에서 갈렸다. 한쪽은 파티 비용을 내고도 현금이 남았고, 다른 한쪽은 파티가 더 컸는데도 현금이 마이너스였다. 시장은 "얼마나 컸느냐"보다 "그걸 감당할 체력이 있느냐"를 봤다.

| 용어 | 풀이 |
|------|------|
| **잉여현금흐름(FCF)** | 영업현금흐름에서 자본지출을 뺀 현금. 빚 없이 쓸 수 있는 진짜 여유 자금 |
| **Azure·Google Cloud** | Microsoft·Google의 클라우드 사업. AI 수요가 가장 직접 드러나는 매출 |
| **조정 EPS** | 일회성 항목을 제외한 주당 순이익. 시장 예상과 비교하는 기준 |

## 한줄 정의

2026-10-28 장 마감 후 발표된 Microsoft·Alphabet 분기 실적 — Azure +48%·FCF $18.6B의 Microsoft는 시간외 +4%, Cloud +103%에도 FCF -$9.07B의 Alphabet은 시간외 -10%.

## 핵심 내용

- **Microsoft는 전부 상회**: 매출 $92.3B(전년 +19%), 조정 EPS $4.89, Azure $33.17B(+48%, 달러 금액 첫 공개), Microsoft Cloud $63.9B(+30%), FCF $18.6B. 자본지출은 리스 포함 $45.2B로 우려보다 낮았다.
- **Alphabet은 클라우드만 상회**: 매출 $127.6B(전년 +25%)·조정 EPS $2.67·검색 $63.4B가 모두 예상 미달. GAAP EPS $2.12는 $8.7B 지분증권 손실의 직격탄이다.
- **클라우드 2배의 역설**: Google Cloud $30.71B(+103%)·클라우드 영업이익 $11.1B(전년 $3.6B의 3배)에도, 분기 자본지출 $51.4B가 FCF를 -$9.07B로 밀어냈다. 2분기 연속 마이너스이며, Alphabet은 $28.7B 채권을 발행하고 $12.4B 주식을 팔고 자사주 매입을 멈췄다.
- **앞으로의 지출**: Alphabet 2026년 자본지출 $195B~$205B 유지, 2027년 "크게" 증가 예고. Google은 AI Mode 검색 수익화가 일반 검색보다 아직 낮다고 밝혔다.

## 왜 중요한가 (1인 개발자 관점)

1. **클라우드 가격·용량의 선행 지표**: Azure·Google Cloud의 성장률과 FCF는 1인 개발자가 쓰는 API·GPU 단가의 방향을 가른다. FCF가 마이너스인 사업자는 가격 인상이나 용량 배분으로 이를 메울 유인이 커진다.
2. **"AI 수요는 있다"는 말의 검증법**: 양사 모두 수요 초과를 말했지만, 시장은 FCF로 검증했다. 벤더의 장밋빛 수요 발언보다 현금흐름표를 보는 습관이 그대로 통한다.
3. **멀티클라우드 분산의 근거**: 한 클라우드의 재무 압박이 다른 클라우드의 기회(혹은 가격)가 된다. 단일 벤더 종속은 가격 협상력을 깎는다.

## 한계 (명시)

- 시간외 주가 변동(+4%/-10%)은 발표 직후 반응으로, 이후 거래에서 달라질 수 있다.
- Microsoft 자본지출은 정의에 따라 $39.4B와 $45.2B(리스 포함) 두 수치가 혼용되므로 비교 시 기준 확인이 필요하다.
- AI Mode 수익화 발언은 정량 수치 없는 경영진 코멘트다.
