# Amazon Q3 — AWS +39% 가속, Trainium 외부 판매는 2027년 말부터

## 쉽게 읽기

**비유**: 가게 전체 매출은 예상보다 조금 모자랐는데, 가장 돈 되는 코너(클라우드)는 5년 만의 최고 속도로 커졌다. 그리고 사장은 "지금은 우리 가게에서만 쓰는 칩을 2027년 말부터는 남에게도 팔겠다"고 선언했다. 클라우드 회사가 칩 회사로 한 발을 내딛은 날이다.

| 용어 | 풀이 |
|------|------|
| **백로그** | 계약은 됐지만 아직 매출로 잡히지 않은 일감 |
| **Run rate** | 분기 실적을 연간으로 환산한 속도 |
| **Trainium** | Amazon이 자체 설계한 AI 학습·추론 칩 |

## 한줄 정의

2026-10-29 Amazon Q3 — 매출 $2,019억·EPS $1.89로 컨센서스 소폭 하회, AWS $460억(+39.3%)·영업이익률 13.9% 사상 최고, Trainium 외부 판매 2027년 말 예고.

## 핵심 내용

- **전체**: 매출 $2,019억(전년 +12%), EPS $1.89(예상 $1.96 하회). 영업이익 $281억(+61%)으로 마진 13.9% 사상 최고. 순이익은 전년보다 소폭 감소했으나, 전년 분기의 $95억 Anthropic 평가이익이라는 기저 때문이다.
- **AWS**: 매출 $460억(+39.3%, 6분기 연속 가속), 영업이익 $178억(마진 38.7%). Run rate $1,840억, 백로그 $5,780억(전년 대비 2배 이상). 전체 영업이익의 약 63%를 전체 매출의 약 23%에서 냈다.
- **전망**: Q4 매출 $2,400억~$2,470억, 영업이익 $285억~$335억. AWS 성장률 2027·2028년 모두 40% 초과 전망, 2027년은 대부분 매진 상태다. 2026년 현금 capex 약 $2,200억 유지, 2027년은 더 늘릴 계획이다.
- **Trainium 외부 판매**: 2027년 말부터 Trainium 랙을 AWS 외부 데이터센터에 직접 판매한다. 지금까지는 임대로만 제공됐다. Graviton·Trainium 매출 약정은 각각 전년 대비 20배 이상 늘었고, Bedrock의 대부분이 Trainium에서 돌아간다. 다만 재시는 외부 판매보다 내부 활용이 5~6년 누적 수익이 더 크다는 절충을 함께 밝혔다.
- **주가**: AWS 가속에도 시간외 주가는 하락했다는 보도가 매체별로 6~11% 범위로 엇갈린다. 실적 자체보다 현금흐름·지출 전망이 심판 기준이 됐다.

## 왜 중요한가 (1인 개발자 관점)

1. **칩의 상품화**: 클라우드 사업자가 자체 칩을 외부에 파는 것은 Nvidia 독점 구도에 균열을 낸다. Google TPU의 외부 판매 흐름과 같은 방향이다.
2. **수직 계열의 경제학**: 칩을 팔아 빨리 돈을 버는 것과, 자기 클라우드에서 써서 오래 버는 것 사이의 절충을 CEO가 공개적으로 계산했다. 인프라 의사결정의 기준이 드러난 발언이다.
3. **실적 읽는 법**: 매출 미스와 사상 최고 마진이 같은 분기에 공존한다. 헤드라인 하나가 아니라 부문별 현금흐름·백로그·가이던스를 함께 봐야 한다.

## 한계 (명시)

- Q3 현금 capex 정확치는 매체별로 달라(약 $759억 vs $773억) 본문에서 제외했고, 연간 가이던스(약 $2,200억)만 썼다.
- 시간외 주가 하락 폭은 매체별 집계 시점이 달라 범위로 표기했다.
- Trainium 외부 판매는 2027년 말 계획이며, 규모·가격·고객은 미공개다.
