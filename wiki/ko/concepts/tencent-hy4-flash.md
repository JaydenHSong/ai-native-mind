# Tencent Hy4 Flash 출시 — 입력 $0.07의 초저가 티어, Hy4의 저가형 (11-16)

## 쉽게 읽기

**비유**: 같은 가게에서 파는 음료의 '작은 사이즈'라고 생각해 보자. 큰 사이즈(Hy4 플래그십)와 맛은 비슷하게 내되, 양을 줄여서 값을 20분의 1로 낮췄다. 다만 "맛이 비슷하다"는 말은 가게 주인이 자기 손님 85명에게만 물어본 결과다.

| 용어 | 풀이 |
| **저가 티어** | 같은 모델 가족에서 성능을 조금 낮추고 가격을 크게 낮춘 버전 |
| **블라인드 테스트** | 어떤 모델의 답인지 모르게 한 채 사람이 답의 질을 매기는 평가 방식 |
| **네이티브 멀티모달** | 글·이미지·영상 등 여러 종류의 입력을 처음부터 함께 배우도록 설계된 모델 |
| **토큰** | AI가 글을 읽는 단위. 영어 단어 하나가 대략 1개 토큰이다 |

## 한줄 정의

2026-11-16 — Tencent가 Tencent Cloud TokenHub에서 Hy4 Flash를 정식 출시했다. 11-4 출시된 플래그십 Hy4의 저가 티어로, 입력 토큰 100만 개당 $0.07이라는 초저가다. Qwen4-Max 입력가의 약 1/21 수준이다.

## 핵심 내용

- **출시**: 2026-11-16 Tencent Cloud TokenHub 정식 출시. 11-4 출시된 플래그십 Hy4의 저가 티어다. 모델 ID `hy4-flash`, OpenAI·Anthropic 프로토콜 호환 API 제공.
- **구조**: 총 224B 파라미터, 토큰당 12B 활성화, 1M 토큰 컨텍스트, 네이티브 멀티모달.
- **가격**: 입력 $0.070 / 출력 $0.281 / 캐시 입력 $0.003 per 1M 토큰. 같은 날 출시된 Qwen4-Max 입력가($1.50)의 약 1/21 수준이다. 11-30까지 50% 프로모션 적용 보도도 있다.
- **성능 주장(Tencent 자체 발표)**: Tencent 자체 블라인드 테스트(85명, 259개 실무 과제)에서 만족도 2.79/4점으로 Claude Haiku 5.5(2.81)와 대등하다고 주장. 독립 검증·모델 카드·벤치마크 원본은 공개되지 않았다.
- **공개 여부**: 가중치 미공개. 오픈소스 예정이라 밝혔으나 날짜·라이선스 없음. OpenRouter 탑재도 미정이다.

## 왜 중요한가 (1인 개발자 관점)

1. **"판단은 싸진다"는 흐름이 더 깊어진다**: 입력 $0.07이면 대량 호출이 필요한 분류·요약·라우팅 같은 작업의 단가가 사실상 0에 가까워진다. 내 하네스에서 경량 판단 모델의 선택지가 넓어졌다.
2. **가격 경쟁의 축이 플래그십에서 저가 티어로 내려왔다**: 같은 날 Qwen4-Max(플래그십)와 Hy4 Flash(저가 티어)가 함께 나온 것은, 중국 랩들이 가격대 전선을 넓히고 있다는 뜻이다.
3. **성능 주장은 검증이 없다**: 만족도 점수는 Tencent 자체 블라인드 테스트에만 기대고 있다. 85명·259개 과제라는 규모도 작다. 내 태스크로 직접 비교해 보기 전에는 Haiku급이라 단정할 수 없다.

## 한계 (명시)

- 성능 주장은 Tencent 자체 블라인드 테스트에만 기대고 있어 독립 검증이 없다. 모델 카드·벤치마크 원본도 공개되지 않았다.
- 가중치는 미공개이고, 오픈소스 예정이라는 말만 있을 뿐 날짜·라이선스가 없다. OpenRouter 탑재도 미정이다.
- 11-30까지 50% 프로모션 적용은 보도 기준이며, 정식 요금표와 다를 수 있다.
