# Cairn 해킹 캠페인 — 오픈소스 에이전트 플랫폼으로 100+ 기업을 침해한 실전 사례

## 쉽게 읽기

**비유**: 지금까지 "AI 해킹"은 연구실 데모였다 — 통제된 환경에서 "이렇게도 될 수 있다"는 보여주기. Cairn 사건은 실전이다. 해커 한 명이 100자도 안 되는 지시 한 줄로 에이전트 부대를 풀어놓으니, 에이전트들이 23시간 동안 스스로 정찰하고, 뚫고, 웹셸을 심었다. 건당 50달러. "될 수 있다"가 아니라 "되고 있고, 싸다"가 됐다.

| 용어 | 풀이 |
|------|------|
| **Cairn** | 오픈소스 에이전트 플랫폼 — "범용 문제 해결 엔진". 에이전트가 진행 상황을 문서화하는 대시보드가 있음 |
| **킬체인 (kill-chain)** | 정찰→침투→익스플로잇→지속화의 공격 단계 — 이번엔 에이전트가 전 단계를 자율 수행 |
| **웹셸 (web-shell)** | 침해한 서버에 심어두는 원격 조종용 스크립트 — 재접속 통로 |

## 한줄 정의

2026-09-25부터 중국어 사용 해커가 오픈소스 에이전트 플랫폼 Cairn으로 벌인 대규모 침해 캠페인 — 1,200+ 사이트 시도, 100+ 침해, 건당 23시간 자율 탐색·$50. NorForge가 10/19 보고, Reuters 등이 보도.

## 핵심 내용

- **발견**: NorForge 수석 위협 연구원 Snorre Fagerland — 악용 중인 Cairn 인스턴스 약 20개를 **노출된 대시보드**로 추적. 에이전트가 진행 상황을 문서화하고 대시보드를 방치한 것이 포렌식 단서.
- **규모**: 9/25 시작. 미국·캐나다·호주·일본 1,200+ 사이트 시도 → 100+ 침해. John Deere·SharkNinja·Cummins 포함. Deere는 민감 정보 접근 징후 없다고 밝힘. Reuters는 탈취 데이터 규모 미확인.
- **공격 방식**: 정찰 → 익스플로잇 → 웹셸 설치의 풀 킬체인을 에이전트가 자율 수행. 인간의 직접 지시는 **100자 미만의 중국어 명령**이 전부.
- **노동 수학**: 침해 1건당 약 23시간 자율 탐색. 총 토큰 비용 약 $5,000 → **건당 약 $50**.
- **스택**: DeepSeek + Anthropic의 Claude Code 조합으로 보도 (작업 분담 구조는 미확인).

## 왜 중요한가 (1인 개발자 관점)

1. **"에이전트 해킹"의 단위 경제가 성립함**: 건당 $50, 지시 100자 — 이건 더 이상 "고급 해커의 전유물"이 아니다. 방어자 입장에서 "공격자가 에이전트를 쓸 것"을 전제로 설계해야 하는 시대. 10/19 위키의 NSA·CISA·NIST 가이드라인("SI 통제 사고", 자동 중단)이 바로 다음 날 실전 사례를 만난 셈.
2. **관측 가능성(observability)의 역설**: 공격자가 대시보드를 노출 방치한 덕분에 캠페인이 발각됐다 — 에이전트의 "진행 문서화" 기능이 수비자에게도 단서가 됨. 역으로, 자신의 에이전트 하네스에도 같은 관측 훅이 있어야 "내 에이전트가 이상하게 굴 때" 알 수 있다. 런타임 로깅은 공격 탐지이자 자기 방어.
3. **값싼 모델의 dual-use 가속**: 같은 날 보도된 M3.1 Flash (에이전트 비용 70%↓, CyberGym 82%, 10/23 오픈 웨이트) — "건당 $50"은 앞으로 더 내려간다. 모델 릴리스의 벤치 점수를 볼 때 "이게 공격자에게도 싸지는가"를 함께 계산해야 함. 오픈 웨이트 릴리스의 리스크 평가에 구체적 숫자($50/건)가 생김.
4. **귀속의 문제**: "도구를 막는가, 사용자를 막는가" — Cairn은 오픈소스 합법 도구다. 10/14 위키의 anthropic-pentagon-rehearing-petition (평가자 제한)과 같은 질문의 공격 버전: 플랫폼 제공자의 책임 범위는 어디까지인가.

## 한계 (명시)

- "DeepSeek + Claude Code" 스택 구성은 보도 인용 — 작업 분담 구조 미확인.
- 탈취된 데이터의 규모·민감도는 Reuters도 확인 못함 — "침해"의 심각도 스펙트럼이 넓음.
- 캠페인은 9/25 시작 — 10/19 "보고"가 뉴스 훅. 공격 자체는 한 달 가까이 진행된 것.
- 해커의 신원·배후는 "중국어 사용" 수준 — 국가 배후 단정 없음.

## 2026-10-22 보강 — "해커는 거의 아무것도 하지 않았다"

- 10-22 CyberSecAsia 업데이트 (Reuters 10-19 원본의 후속): 해커는 "거의 아무것도 하지 않았고 (did almost nothing)", 에이전트가 수 시간에 걸쳐 자율적으로 탐침·침입. NorForge 연구원 Snorre Fagerland는 "인간 감독이 필요할 줄 알았는데" 자율 에이전트의 진전에 놀랐다고 밝힘.
- 같은 날 Microsoft가 공개한 Storm-0940 (ARTEX 기반 에이전트 주도 공격) 과 트윈 케이스 — "에이전트 주도 실전 공격"이 10-20~10-22 사흘 연속 3건 (Cairn → Storm-0940 → 이번 업데이트).
- 관측 가능성 (observability) 의 역설 재확인: 공격자의 노출된 대시보드가 포렌식 단서 — 에이전트의 "진행 문서화"가 수비자에게도 단서.
