# Claude Duet — Anthropic의 상시 대기 에이전트 리서치 프리뷰

## 쉽게 읽기

**비유**: 지금까지 AI 어시스턴트는 "부르면 오는 비서"였다. Claude Duet은 "먼저 챙겨주는 비서"다 — 아침마다 오늘 처리해야 할 일을 정리해 브리핑하고, 낮에는 앱들을 수시로 들여다보다가 이상한 것만 콕 집어 알린다. 단, 돈이 나가거나 (결제) · 도장이 찍히거나 (문서 서명) · 뭔가 사라질 때 (삭제) 는 반드시 당신 허락을 받는다. 주식 거래와 계좌 이체는 허락해도 못 한다 — 원칙적으로 막아뒀다.

| 용어 | 풀이 |
|------|------|
| **proactive 에이전트** | 사용자가 호출하지 않아도 스스로 일을 시작하는 에이전트 — "대기 중"이 아니라 "순찰 중" |
| **승인 게이트 (approval gate)** | 에이전트가 되돌릴 수 없는 행동을 하기 전 사용자 승인을 강제하는 관문 |
| **모닝 브리프** | 매일 아침 연결된 앱의 우선순위를 정리해 보내는 요약 알림 |

## 한줄 정의

2026-10-21 Anthropic이 공개한 Claude Opus 5.5 기반 상시 대기 에이전트 리서치 프리뷰 — 모닝 브리프 + 주기적 앱 점검, 6,000+ 커넥터 연동, 결제·서명·삭제 사전 승인 게이트, 미국 Pro/Max 대기목록.

## 핵심 내용

- **출시**: 2026-10-21 Anthropic — Claude Duet 리서치 프리뷰. 기반 모델 Claude Opus 5.5.
- **동작 패턴**: 매일 아침 모닝 브리프 (연결된 앱의 우선순위 정리) + 수 시간마다 앱 확인 → 주의가 필요한 건만 메시지 알림. "부르면 오는"에서 "순찰하다 알려주는"으로.
- **연동**: Claude Marketplace 6,000+ 커넥터 — Stripe·QuickBooks·Gusto·Shopify·DocuSign 등 업무 앱 직결.
- **승인 게이트**: 메시지 발송·결제·문서 서명·삭제 전 사용자 승인 필수. 주식 거래·계좌 간 자금 이동은 사전 승인으로도 금지 (원칙적 차단).
- **실행 환경**: 가상 머신 + 브라우저 — 사용자 기기가 꺼져 있어도 작업 지속. persistent agent의 상용 구현.
- **접근/과금**: 미국 Pro/Max 구독자 대기목록 방식. 백그라운드 점검도 플랜 사용 한도를 소모.
- **패턴 수렴**: ChatGPT Dots (10-02) · Meta Muse (10-13) 에 이어 6주 내 세 번째 빅랩 proactive 에이전트 — 에이전트 UX가 "상시 대기/브리프/승인 게이트"로 수렴 중.

## 왜 중요한가 (1인 개발자 관점)

1. **에이전트 UX의 수렴점**: 6주 새 3개 빅랩이 같은 형태 (브리프+순찰+승인 게이트) 로 나옴 — 이게 "에이전트 제품의 표준 인터페이스"가 될 가능성이 높다. 본인 서비스를 만들 때 이 UX 문법을 차용하면 사용자가 이미 익숙한 패턴이다.
2. **권한 설계의 실전 답안**: "승인 게이트 + 원칙적 금지"의 2층 구조. [[patterns/agent-authority-model]]의 5단계 권한 프레임워크가 이론이었다면, Duet은 "돈/서명/삭제는 묻고, 주식/송금은 아예 막는다"는 구체적 선긋기다. 에이전트에게 돈 맡길 때의 권한 모델 참고안.
3. **과금 모델의 신호**: 백그라운드 점검이 플랜 한도를 소모 — "순찰"도 유료다. 상시 대기 에이전트의 단위 경제는 "사용자가 시킨 일"이 아니라 "에이전트가 스스로 한 일"까지 과금된다는 점에서 비용 거버넌스 (Accenture $29 상한 사례) 와 직결.

## 한계 (명시)

- 리서치 프리뷰 단계 — 미국 Pro/Max 대기목록, 정식 출시 시점·가격 미정.
- 승인 게이트의 UX (승인 피로·우회 가능성) 는 아직 검증되지 않음.
- 백그라운드 점검의 실제 한도 소모량은 공개되지 않음.
