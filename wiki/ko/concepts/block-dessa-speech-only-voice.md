# Block Dessa — 텍스트 없이 음성만으로 학습한 풀듀플렉스 음성 AI

## 쉽게 읽기

**비유**: 지금까지 음성 비서는 '들은 말을 글로 적고, 글로 답을 짓고, 다시 소리로 읽는' 3단계를 거쳤다. Dessa는 그 중간 단계를 없앴다 — 소리를 듣고 소리로 바로 답한다. 그래서 웃음·망설임·끼어들기 같은 '말의 결'이 살아 있다. 대신 배운 것이 전부 대화 녹음이라, 글로 된 지식은 없다.

| 용어 | 풀이 |
|------|------|
| **풀듀플렉스** | 말하면서 동시에 듣는 양방향 실시간 대화 |
| **백채널** | '응', '알겠어' 같은 듣고 있다는 신호의 짧은 맞장구 |
| **음성 전용 학습** | 텍스트 데이터·사전학습 모델 없이 음성 녹음만으로 학습 |

## 한줄 정의

2026-10-23 Block이 공개한 음성 전용 풀듀플렉스 모델 — 텍스트 변환 없이 음성에서 음성으로 직접 처리하며 단일 GB200 NVL72 랙으로 학습, M4 Max MacBook Pro 로컬 실행을 주장하는 연구 프리뷰.

## 핵심 내용

- **아키텍처**: 음성 입력→음성 출력, 중간 텍스트 없음. 텍스트 변환이 감정·억양·타이밍을 버린다는 문제의식에서 출발.
- **학습 효율 주장**: 텍스트 LLM보다 '수백 배 적은 단어'로 언어 학습. 음성은 단어당 수천 배 많은 바이트를 차지해 학습이 어렵다는 설명과 함께 단일 GB200 NVL72로 학습 완료.
- **실행**: 실시간보다 빠른 추론, M4 Max 이상 MacBook Pro 로컬 실행 주장. 토론토 스타트업 Dessa 출신 소형 연구 조직(Thurairatnam 주도, Dorsey 직보)이 8년 이상 음성 모델 개발.
- **공개 범위**: 연구 프리뷰, 대기자 명단. 소수 AI 안전 연구자에게 먼저 접근을 열어 예상 못한 위험을 찾는다는 방침. 파라미터·API·가격·벤치마크 전부 미공개.
- **데모와 반응**: 유도 없는 실시간 대화 녹음 공개, GPT-Live-1과의 대화 포함(해당 개발자 검증·지지 없음). The Verge는 대체로 자연스럽지만 어색한 구간도 있다고 평가. 인간다움에 대한 경탄과 전화 사기 악용 우려 동시 보도.

## 왜 중요한가 (1인 개발자 관점)

1. **음성 에이전트의 별도 갈래**: 텍스트 LLM + TTS라는 기본 공식 바깥에 '음성 자체로 배우는' 갈래가 실증됨 — 음성 제품 설계 시 아키텍처 선택지가 하나 더 생김.
2. **로컬 실행의 의미**: M4 Max 노트북에서 돌아간다는 주장이 사실이면 음성 에이전트의 배포·프라이버시 구조가 달라짐 — 클라우드 왕복 없이 감정을 처리.
3. **사기 리스크가 곧 제품 리스크**: 인간다울수록 전화 사기 악용 우려가 커짐 — 음성 신원 확인·표시 같은 안전 기능이 제품 스펙의 일부가 될 신호.

## 한계 (명시)

- 증거는 Block 자체 데모 녹음뿐 — 독립 검증 전, 파라미터·벤치마크 미공개.
- 연구 프리뷰 단계로 일반 이용 불가, 출시일 미정.
- 어제 수집에서 프리뷰 단계로 보류했던 주제 — 10-24 보도 확산과 로컬 실행·사기 우려 맥락이 더해져 오늘 정식 수집으로 승격한 경위임.
