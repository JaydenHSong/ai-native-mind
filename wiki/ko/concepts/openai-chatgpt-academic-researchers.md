# OpenAI, 학술 연구자에 ChatGPT Plus 5만 건 무료 제공 — 선착순, 20만 명 목표

## 쉽게 읽기

**비유**: 대학 연구자들이 AI를 연구에 쓰려면 보통 비싼 유료 요금을 내야 했다. OpenAI가 "연구하는 사람들에게는 공짜로 쓰게 해 주겠다"며 ChatGPT Plus 이용권을 5만 장 뿌리기 시작했다. 먼저 신청한 순서대로 주고, 최종 목표는 20만 명이다. 다만 Plus 요금제만 주는 것이고, API 크레딧이나 특수 모델은 포함되지 않는다.

| 용어 | 풀이 |
|------|------|
| **ChatGPT Plus** | ChatGPT 유료 요금제. 무료 버전보다 더 좋은 모델·더 높은 한도를 쓴다 |
| **그랜트 (grant)** | 조건을 갖춘 사람에게 주는 지원·무료 이용권 |
| **선착순 (first-come, first-served)** | 신청한 순서대로 주는 방식. 추첨이 아니다 |
| **파일럿 (pilot)** | 정식 확대 전에 작게 먼저 해 보는 시험 운영 |
| **대기자 명단 (waitlist)** | 신청을 미리 받아 두고 순서가 되면 안내하는 목록 |

## 한줄 정의

2026-11-23 OpenAI가 학술 연구자 대상 'ChatGPT for Academic Researchers' 프로그램 신청을 열었다 — 이번 라운드에 5만 건의 ChatGPT Plus 무료 이용권을 선착순으로 제공하며, 프로그램 자체는 11월 16일 발표됐고 전체 목표는 20만 명이다.

## 핵심 내용

- **규모**: 이번 라운드 신규 그랜트 50,000건, 선착순(first-come, first-served) — 파일럿의 추첨제 폐지. 각 그랜트는 수혜자 + 협업자 최대 2명에게 ChatGPT Plus 무료 접근 제공. 이 라운드로 최대 15만 명까지 지원.
- **등급 변경**: 파일럿은 Pro였으나 사용량 검토 결과 대부분 연구자가 Plus 한도 내에서 충분해 Plus로 변경.
- **대상**: 전 세계 학술 연구자(과학·수학·공학). 대기자 명단 등록자 중 자격 충족자는 개시 전 이메일로 활성화 안내 수신.
- **파일럿 실적**: 7월 이후 33개국 20,000명 참여. OpenAI 자체 연구에 따르면 AI 없이 했을 때보다 작업 시간이 거의 2배 걸렸을 것이라는 추산. 프로그램 데이터는 기본적으로 모델 학습에 사용하지 않음.
- **부가**: Simons Foundation 수학 이니셔티브에 500만 달러 기부, 'Science at the Frontier' 연구 공개.
- **세부 조건**: 정확한 개시 시각·자격 세부 규칙·그랜트 기간은 OpenAI 발표에 없음. 2차 보도(CASRAI 등) 기준으로는 12개월, 연구 교수·박사후 연구원 대상, 중국·홍콩 제외, API 크레딧·특수 모델 미포함.
- **날짜 주의**: 프로그램 발표는 11월 16일, 11월 23일은 신청 개시일임.

## 왜 중요한가 (1인 개발자 관점)

1. **AI 과학 연구의 접근성 확대**: [[concepts/riemann-hypothesis-proof-claude-lean-verification]]의 Claude+Lean 증명이나 [[concepts/openai-ai-science-three-discoveries]]처럼, 프론티어 모델이 연구 현장에 들어가는 속도가 빨라지고 있다. 연구자 20만 명에게 Plus를 푼다는 건 "AI와 함께 연구하는 방식"이 소수 특권에서 표준 장비로 넘어가는 신호다.
2. **"울퉁불퉁한 전선"의 다른 면**: [[concepts/openai-research-acceleration-jagged-frontier]]가 AI가 연구를 얼마나 가속하는지를 쟀다면, 이번 건은 그 가속을 누가 누릴 수 있는지를 넓히는 쪽이다. 연구 현장의 AI 활용도가 올라가면, 개발자가 만드는 연구 도구·에이전트의 수요도 함께 커진다.
3. **데이터 정책의 선례**: "프로그램 데이터는 기본적으로 모델 학습에 사용하지 않음"이라는 조건은 연구 데이터의 민감성을 고려한 설계다. 연구용 AI 제품을 만들 때 참고할 만한 패턴이다.

## 한계 (명시)

- 세부 조건(12개월 기간, 교수·박사후 대상, 중국·홍콩 제외, API 크레딧·특수 모델 미포함)은 2차 보도(CASRAI 등) 기준이며 OpenAI 발표에는 없다 — 1차 출처와 구분해서 다룬다.
- "작업 시간 거의 2배" 추산은 OpenAI 자체 연구 기준 — 독립 검증 없음.
- 정확한 개시 시각·자격 세부 규칙·그랜트 기간은 OpenAI 발표에 없음.
- confidence는 medium — OpenAI 1차 발표 + 2차 보도 교차이나, 세부 조건은 2차 출처 의존.
