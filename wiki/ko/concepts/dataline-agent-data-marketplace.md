# Dataline 에이전트 데이터 마켓플레이스 — x402 호출당 과금의 데이터 라우팅 계층

## 쉽게 읽기

**비유**: 에이전트가 데이터를 살 때 매번 API 계약서를 쓰지 않고, 자판기처럼 호출 한 번에 값을 치르고 신뢰도 점수가 붙은 데이터를 받아 가는 시장이다. 파는 쪽은 누구나 피드를 올릴 수 있다.

| 용어 | 풀이 |
|------|------|
| **x402** | HTTP 결제 프로토콜, API 호출당 결제하는 방식 |
| **AI 신뢰도 점수** | 출처 신뢰도·신선도·일관성을 기준으로 매긴 데이터 품질 점수 |
| **스킴 정규화** | 서로 다른 피드를 같은 구조로 맞춰 에이전트가 바로 쓰게 만드는 것 |

## 한줄 정의

2026-11-01 조달 발표 — Dataline이 $10.6M을 조달해, 누구나 피드를 올리고 어떤 에이전트든 x402로 호출당 결제해 쓰는 탈중앙 에이전트 데이터 마켓플레이스를 확장한다는 소식.

## 핵심 내용

- **조달**: $10.6M. Lattice와 Samsung 지원 Dispersion Capital 공동 주도, Symbolic Capital 참여.
- **구조**: 양면 마켓플레이스 + 라우팅 계층. API 응답에 출처 신뢰도·신선도·일관성 기반 신뢰도 점수를 함께 제공한다.
- **데이터**: 가격·펀딩·포지션·예측시장 등 스킴 정규화된 피드. 에이전트 네이티브 실행을 겨냥한다.
- **규모(회사 발표)**: 온체인 트랜잭션 1,940만 건, 커뮤니티 30만 명 이상. AI Data Launch 파트너 1기 코호트 조직, Base·Robinhood Chain 빌더 무료 접근.

## 왜 중요한가 (1인 개발자 관점)

1. **에이전트 경제의 결제층이 데이터로 확장된다**: 결제(x402)가 모델 호출을 넘어 데이터 피드로 번지고 있다. 에이전트가 스스로 데이터를 사고파는 구조에서는 '데이터 비용'이 에이전트 운영비의 한 축이 된다.
2. **신뢰도 점수가 곧 필터다**: 출처·신선도·일관성을 점수화해 붙인다는 발상은, 에이전트가 환각이 아니라 '나쁜 데이터'에 속는 문제를 시장 메커니즘으로 풀려는 시도다. 점수 산식의 투명성이 관건이다.
3. **1인 개발자에게는 공급자 기회이기도 하다**: 누구나 피드를 올릴 수 있는 구조라, 틈새 데이터(예: 특정 도메인 지표)를 가진 개인이 에이전트 경제의 공급자가 될 수 있는 경로가 열린다. 다만 규모 수치는 회사 발표로 미검증이다.

## 한계 (명시)

- 보도자료 기반 소식으로, 트랜잭션·커뮤니티 규모는 독립 검증이 없다.
- 신뢰도 점수의 산식·가중치는 공개되지 않았다.
- 실제 에이전트 채택률(유료 호출 비중)은 보도되지 않았다.
