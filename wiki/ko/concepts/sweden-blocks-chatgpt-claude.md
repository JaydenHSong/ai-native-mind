# 스웨덴 정부의 ChatGPT·Claude 차단 — 계약 없는 사용이 정보보안 문제라는 판단

## 쉽게 읽기

**비유**: 회사에서 '허가받은 프로그램만 써라'는 규칙과 같다. 스웨덴 정부는 ChatGPT·Claude가 나빠서 막은 게 아니라, 계약 없이 쓰는 것이 문제라고 봤다. 계약을 맺고 보안 설정을 강화한 Copilot은 통과. 같은 모델도 계약된 경로(Intric)로는 계속 쓸 수 있다 — 막은 것은 모델이 아니라 '계약 없는 경로'다.

| 용어 | 풀이 |
|------|------|
| **Regeringskansliet** | 스웨덴 정부청, 총리실·각 부처를 지원하는 행정 기구 |
| **승인 도구** | 조직이 검토·계약·보안 설정한 뒤 공식 허용한 도구 |
| **소비자형 경로** | 개인이 브라우저로 직접 여는 계약 없는 사용 방식 |

## 한줄 정의

2026-10-26 시행되는 스웨덴 정부청의 조치 — 업무용 PC에서 ChatGPT·Claude 접속을 차단하고 보안 검토를 마친 Copilot만 승인, 계약·조달 관점의 AI 거버넌스 사례로 기록.

## 핵심 내용

- **조치**: 10-26부터 업무용 PC에서 ChatGPT·Claude 브라우저 접속 차단. Copilot은 보안 검토 후 설정 강화가 이뤄져 승인됨(강화 내역은 보안상 비공개).
- **근거**: 디지털화 국장 Wettercrantz — '계약 없이 AI 서비스를 쓰면 정보보안에 영향을 미칠 수 있다'. 민감 정보 입력 사례와 AI 답변 처리 문제 확인. 미국법상 외부 서버 데이터 제공 강제 가능성도 배경.
- **예외**: 일부 직원은 정부 자체 AI 플랫폼(Intric 경유)으로 두 모델 계속 이용 — 차단 대상은 모델이 아니라 소비자형 경로.
- **확산**: DeepSeek은 이미 제한. 국세청·국가시설관리위원회도 유사 차단, 집행청은 결정 준비 중. 교통청 감사에서 10개 오픈 AI 서비스의 '광범위하고 위험한' 사용 확인.

## 왜 중요한가 (1인 개발자 관점)

1. **거버넌스는 모델이 아니라 계약이다**: 어떤 모델이냐보다 어떤 계약·설정으로 쓰느냐가 승인 기준 — 기업·기관 대상 제품을 만들 때의 핵심 체크리스트.
2. **승인 경로 설계가 곧 제품 기회**: 차단과 동시에 내부 플랫폼 경로가 남았다 — '계약된 경로로 모델을 제공하는' 사업 모델의 수요 확인.
3. **공공 부문이 먼저, 민간이 뒤따른다**: 은행의 에이전트 차단과 같은 문법이 정부로 확산 — 승인·계약·예외 경로의 3단 구조가 표준 패턴으로 굳어지는 중.

## 한계 (명시)

- Copilot 강화 내역·예외 경로의 인원·가드레일이 비공개라 실효성 검증이 어려움.
- 개인 기기·재택 PC는 범위 밖이라 우회 여지가 있음.
- Copilot에 탑재된 Claude 모델과의 관계는 스웨덴 측 확인 없음.
