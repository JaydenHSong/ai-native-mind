# GPT-6.1 Sol Ultrafast — 8배 속도 티어 (2026-10-08)

## 한줄 정의

OpenAI가 GPT-6.1 Sol에 추가한 최고속 티어 — 표준 대비 최대 8배 빠른 토큰 생성, API 가격은 표준의 6배.

## 핵심 내용

- **출시**: GPT-6.1 Sol Ultrafast — API·Codex·ChatGPT Work 대상. 표준 대비 최대 8배 빠른 토큰 생성.
- **가격**: API 기준 표준의 6배 — $12/1M 입력 토큰, $60/1M 출력 토큰.
- **접근 제한**: Pro 500 구독자·사용량 기반 Enterprise·크레딧 기반 Edu 플랜에 한해 Work/Codex 제품 접근. Pay-as-you-go 개발자는 API에서 이용 가능.
- **데이터 레지던시**: US·EU 지원.
- **개발자 불만**: 고속 모드에서 토큰 소비 급증 우려, 현 티어에서 선택이 아닌 상위 플랜 업그레이드 강제라는 지적.

## 왜 중요한가

AI 네이티브 프로그래머에게 Ultrafast는 **레이턴시가 곧 가격 결정력이 되는** 시대를 알린다. Claude Haiku 5.5가 API 최대 90% 인하로 내려가는 동안, OpenAI는 8배 속도에 6배 가격을 붙이는 프리미엄 티어로 올라간다 — 가격대 양극화가 동시 전개되는 중이다. 에이전트 하네스 설계 관점에서는 "속도 티어"가 라우팅의 새 축이 된다: 대화형 코딩 에이전트(Codex)는 Ultrafast, 배치 평가는 표준, 경량 작업은 Haiku급 — **속도·가격·품질의 3축 라우팅**이 정교해진다. 단, 토큰 소비 급증 우려는 에이전트 루프의 runaway 비용 리스크와 직결되므로 지출 상한 가드레일은 필수다.
