# Meituan LongCat-2.5 가중치 공개 — Nvidia GPU 없이 만든 1.6조 파라미터 에이전트 모델 (11-15)

## 쉽게 읽기

**비유**: 1.6조 쪽짜리 거대한 도서관을 통째로 공개한 셈이다. 다만 한 번에 읽는 건 필요한 책장(약 480억 쪽)만 꺼내 읽는 방식이라, 도서관이 커도 실제로 드는 힘은 그만큼이다. 이 도서관은 미국 칩 없이, 중국 칩만으로 지었다고 한다.

| 용어 | 풀이 |
| **MoE (전문가 혼합)** | 모델을 여러 전문가 블록으로 나누고, 토큰마다 필요한 전문가만 작동시키는 구조 |
| **활성 파라미터** | 전체 파라미터 중 토큰 하나를 처리할 때 실제로 쓰이는 부분. 비용을 결정한다 |
| **양자화(quantization)** | 숫자를 더 짧게(예: 4비트) 줄여서 저장·계산하는 방법. 메모리를 아낀다 |
| **MIT 라이선스** | 상업 이용·수정·재배포를 허용하는 가장 느슨한 오픈소스 라이선스 |
| **Terminal Bench** | 에이전트가 명령줄(터미널)에서 과제를 얼마나 잘 푸는지 재는 벤치마크 |
| **오픈웨이트** | 모델의 가중치(학습된 숫자)를 공개한 것. 학습 데이터·코드가 함께 공개되는 것은 아니다 |

## 한줄 정의

2026-11-15 — Meituan의 LongCat 팀이 1.6조 파라미터 에이전트 모델 LongCat-2.5의 가중치를 MIT 라이선스로 공개했다. 11-02 공개 후 11-10 가중치 배포. 회사 설명으로는 중국 하드웨어만으로 학습했고, 자가 호스팅 가이드는 Huawei Ascend 가속기를 겨냥한다. Nvidia GPU 안내는 없다.

## 핵심 내용

- **모델**: 네이티브 멀티모달 MoE 모델. 전체 1.6조 파라미터 중 토큰당 약 480억 개만 활성화된다. 전작 LongCat-2.0에 이미지 이해를 더했고, 긴 다단계 코딩·사무 작업을 자율적으로 처리하는 에이전트용으로 강화 학습했다.
- **공개**: Hugging Face에서 가중치를 MIT 라이선스로 배포한다(상업 이용·수정·재배포 가능, 상표·특허 권한은 제외). BF16 체크포인트 약 3.56TB, 4비트 압축판 약 1.34TB. 채팅은 longcat.ai에서 체험할 수 있다.
- **성능 주장**: Meituan 자체 측정 기준 Terminal Bench v2.1 88.4점, Claude Opus 5의 89.1점에 근접한다. 단 회사 스스로 "indicative only"(참고용)라고 밝혔고, 독립 기관의 검증 결과는 아직 없다.
- **하드웨어**: 전문가 가중치·활성화를 4비트 정밀도로 양자화하는데, 중국 칩이 이를 네이티브로 처리한다고 설명한다. 자가 호스팅 가이드의 샘플 구성은 Huawei Ascend Atlas A2 가속기 194개(이미지 처리 2개·프롬프트 섭취 64개·응답 생성 128개)다. Nvidia GPU 안내는 없다. 전작 LongCat-2.0은 5만 개 이상의 중국 AI 칩 클러스터에서 학습했다고 회사가 밝혔다.
- **가격**: 출시 한정 프로모션 API 가격은 100만 토큰당 입력 약 €0.27·출력 약 €1.07 수준이다.

## 왜 중요한가 (1인 개발자 관점)

1. **"미국 칩 없이는 안 된다"는 전제가 흔들린다**: 1.6조 파라미터급 에이전트 모델을 중국 칩만으로 학습·서빙했다는 사례는, 하드웨어 종속이 절대적이지 않음을 보여준다. 오픈웨이트 모델을 고를 때 하드웨어 요구조건이 선택 기준이 된다.
2. **에이전트 모델의 가격 경쟁이 깊어진다**: Terminal Bench 88점대 성능에 입력 €0.27 수준이면, 코딩 에이전트의 실행 비용 구조가 바뀐다. 내 하네스의 모델 선택지에서 "싸고 긴 작업을 잘하는 모델" 축이 생겼다.
3. **검증은 가중치 공개로 시작된다**: 벤치마크는 회사 자체 측정이라 믿고 쓰기 어렵지만, 가중치가 공개됐으니 누구나 직접 돌려볼 수 있다. 오픈웨이트의 가치는 "말"이 아니라 "돌려볼 수 있다"는 데 있다.

## 한계 (명시)

- "Nvidia 없이 학습했다"는 회사 주장이고, 회사 자체 게시물은 학습 칩의 벤더를 명시하지 않는다("국내"·"중국산 가속기" 표현). Huawei라는 이름은 배포 가이드에서 나온다.
- 성능 수치는 Meituan 자체 측정이고 독립 검증이 없다. 회사 스스로 참고용이라고 밝혔다.
- 가중치는 공개됐지만 학습 데이터·전체 파이프라인은 공개되지 않았다. BF16 체크포인트 3.56TB라 개인이 돌리기엔 클러스터가 필요하다.
