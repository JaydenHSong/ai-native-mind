# Moonshot Kimi K3.1 Pro — 2.8T MoE 오픈웨이트 예고, 사이버 능력은 의도적으로 낮춰 출시

## 쉽게 읽기

**비유**: 최강 엔진을 공개하면서도 "해킹용 기어"만 미리 빼 둔 차다. Moonshot은 K3.1 Pro의 사이버 공격 능력을 일부러 낮춰서 공개하기로 했다 — 가중치를 공개하면 누구나 다운로드할 수 있기 때문에, 출시 전에 위험한 부분부터 덜어낸 것이다. 그런데도 코딩 실력은 클로드 최상위 모델 바로 아래까지 올라왔다.

| 용어 | 풀이 |
|------|------|
| **MoE** | Mixture of Experts — 토큰마다 일부 전문가 네트워크만 활성화하는 구조 |
| **오픈웨이트** | 가중치를 공개해 누구나 다운로드·실행할 수 있는 모델 |
| **xdev-bench-hard** | Moonshot 내부 익스플로잇(취약점 공격) 수행 능력 테스트 |

## 한줄 정의

2026-10-23 Moonshot AI가 출시한 Kimi K3.1 시리즈 첫 모델 — 총 2.8T/활성 104B MoE, 1M 컨텍스트, API $2/$10, 가중치 11-04 공개 예고, 사이버 데이터를 학습에서 제거해 공격 능력을 의도적으로 낮춘 오픈웨이트 프런티어.

## 핵심 내용

- **규모**: 총 2.8T 파라미터, 토큰당 활성 104B. 1M 토큰 컨텍스트. 고속 변형 Highspeed(2~3배 속도 주장) 동시 출시.
- **가격**: API 입력 $2/출력 $10/캐시 히트 $0.20(100만 토큰). K3 대비 약 33% 인하 보도.
- **성능**: 업체 자체 Terminal-Bench 4.0 65.7%(Opus 5.5 66.4%, GPT-6 Astra 58.2%), BenchCAD 92.7%. 독립 Artificial Analysis 지수 55로 4위 — 가중치 공개 시 오픈웨이트 선두 예고.
- **사이버 절충**: 중간 학습·RL에서 사이버 관련 데이터 제거. 내부 xdev-bench-hard 미필터 90.5% → 출시 81.0%. ExploitBench 74.7%(Opus 5.5 91.0%). 그래도 K3(33.3%)의 2배 이상.
- **가중치 공개 (11-04)**: 약속한 기한 당일 Hugging Face(moonshotai/Kimi-K3.1-Pro)에 전체 가중치 공개. 96개 파일, 총 약 1.56TB, 접근 게이트 없음. MXFP4 가중치·MXFP8 활성화(양자화 인식 학습), 93층. vLLM 기준 8개 데이터센터 GPU(각 288GB VRAM) 필요. 11-04 기준 GGUF 빌드 없음.
- **라이선스**: Kimi K3.1 Pro License, K3 라이선스와 사실상 동일 문구. 대부분 사용자에게는 MIT 스타일로 자유롭게 사용·변경·판매 가능하나, 12개월 매출 $20M 초과 모델-서비스 사업자는 상업 이용 전 Moonshot과 별도 계약이 필요하다. 표준 오픈소스 라이선스가 아니다.
- **벤치 업데이트**: Moonshot 자체 표에서 Opus 5.5보다 앞선 항목이 37개 중 16개, 최대 격차 5.4점, 뒤처진 항목은 최대 33.5점.

## 왜 중요한가 (1인 개발자 관점)

1. **오픈웨이트의 안전 공개 템플릿**: "무엇을 뺐고, 얼마나 낮아졌는지"를 수치로 공개한 첫 사례급. 앞으로 오픈 모델을 고를 때 성능표 옆에 "능력 절충표"를 보는 습관이 생길 것.
2. **가격 파괴의 다음 라운드**: Opus급 코딩을 $2/$10에, 그것도 로컬 실행 가능한 가중치로 — 에이전트 코딩 비용 구조를 다시 짜야 하는 신호.
3. **중국 오픈웨이트의 2축**: DeepSeek의 초저가와 Kimi의 안전 절충 공개 — "싸다"와 "책임 있게 공개한다"가 같은 주에 다른 답으로 나옴.

## 한계 (명시)

- 벤치 수치는 업체 자체 실행·편찬이 주축, 독립 검증 전.
- 가중치 공개 후 파인튜닝으로 절충이 유지될지는 미지수 — 공개된 가중치는 회수 불가.
- GPT-6 Astra 출력으로 학습했다는 보도는 미확인 상태로 남아 있다. 독립 평가는 가중치 공개 이후에나 가능하다.
