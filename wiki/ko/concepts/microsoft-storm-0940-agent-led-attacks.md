# Storm-0940 — AI 에이전트 주도 대규모 공급망 공격 (Microsoft 공개)

## 쉽게 읽기

**비유**: 예전 해킹은 "특공대"였다 — 소수가 오래 공들여 뚫는 방식. Storm-0940은 "드론 부대"다 — 에이전트 프레임워크 ARTEX가 표적 선정부터 클라우드 침투까지 자동으로 돌리고, 사람은 지시만 내린다. 8개 조직 327개 계정에 15만 번 로그인 시도 — 분당 2,900번. 속도와 규모가 "인간 해커"의 문법을 벗어났다.

| 용어 | 풀이 |
|------|------|
| **Storm-0940** | Microsoft가 명명한 중국 연계 위협 행위자 |
| **ARTEX** | 에이전트 AI 침투테스트 프레임워크 — 2026년 7월 합법 보안 테스트용 공개, 남용 후 클로즈드 소스 전환 |
| **OAuth 앱 자격증명 남용** | 탈취한 앱 권한으로 사용자 로그인 없이 하류 클라우드에 인증하는 기법 |

## 한줄 정의

2026-10-21 Microsoft가 공개한 중국 연계 행위자 Storm-0940의 에이전트 주도 대규모 공급망 공격 — ARTEX 프레임워크로 수백 개 조직 자동 공격, OAuth 자격증명으로 M365 하류 인증, 표적 선정→클라우드 접근 3시간 미만.

## 핵심 내용

- **행위자**: Storm-0940 (중국 연계) — 에이전트 AI 침투테스트 프레임워크 ARTEX로 수백 개 조직 대상 공격 자동화.
- **기법**: 탈취한 OAuth 앱 자격증명으로 하류 M365 환경에 사용자 로그인 없이 인증 — 자격증명 기반 공급망 공격. "사용자"가 아니라 "앱의 권한"을 훔침.
- **속도**: 표적 선정 → 권한 있는 클라우드 접근까지 3시간 미만 (일부 사례) — 인간 팀의 킬체인이 에이전트 속도로 압축.
- **규모** (10-10~10-14): 8개 조직 327개 계정에 15만+ 로그인 실패, 피크 분당 2,900건 인증 시도.
- **이중 용도**: ARTEX는 2026-07 합법 보안 테스트용 공개 → 남용 신고 후 클로즈드 소스 전환. "공개 도구 → 공격 도구"의 전환이 3개월.
- **귀속**: 최근 공개된 ConnectWise Cloud Backup 침해를 Storm-0940 소행으로 지목 — Microsoft의 공식 귀속.
- **트윈 케이스**: 어제 (10-20) Cairn 캠페인 (건당 $50, 100+ 침해) 과 하루 차이 — "에이전트 주도 실전 공격"이 이제 복수·동시다발.

## 왜 중요한가 (1인 개발자 관점)

1. **공격의 단위 경제가 또 성립**: Cairn은 "건당 $50", Storm-0940은 "분당 2,900 시도". 방어 설계의 전제가 "공격자는 에이전트를 쓴다"로 바뀌어야 함 — 레이트 리밋·이상 탐지의 임계값을 인간 기준으로 두면 안 됨.
2. **OAuth 앱이 새로운 국경**: 훔치는 게 비밀번호가 아니라 "앱의 권한". 본인 서비스의 OAuth 스코프를 최소 권한으로 쪼개고, 서드파티 앱 권한을 정기 감사해야 — [[concepts/agent-supply-chain-security]]의 신뢰 모델에 "앱 권한 인벤토리" 항목 추가.
3. **공개 도구의 반감기**: ARTEX는 합법 도구로 나와 3개월 만에 공격 무기가 됨. 오픈소스 보안 도구를 릴리스할 때 "남용 시 회수 계획"이 필요 — 클로즈드 전환이 늦으면 무기가 됨.

## 한계 (명시)

- 행위자 귀속은 Microsoft의 주장 — 독립 검증 없음. "중국 연계"의 근거 세부 미공개.
- ARTEX의 구체적 동작 방식 (에이전트 아키텍처) 은 미공개.
- 피해 규모 (탈취 데이터 등) 는 미공개 — 시도 규모 위주의 수치.
