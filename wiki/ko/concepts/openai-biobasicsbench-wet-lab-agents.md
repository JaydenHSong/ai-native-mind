# OpenAI×Ligo BioBasicsBench — 실제 젖은 실험실 데이터 100개 과제로 에이전트를 평가, Astra 66.7%

## 쉽게 읽기

**비유**: 교과서 그림이 아니라, 실험대 위의 얼룩진 젤 사진과 손글씨 노트를 주고 "이 실험, 뭐가 잘못됐어?"라고 묻는 시험이다. 정답을 외운 학생이 아니라, 증거를 읽고 "이건 결론을 내릴 수 없어"라고 말할 줄 아는 학생을 가리는 시험이다. 최고 점수를 받은 학생도 100점 만점에 67점이다.

| 용어 | 풀이 |
|------|------|
| **Wet-lab** | 실제 생물 시료·시약·기기를 다루는 실험실 작업 (건식의 컴퓨터 실험과 반대) |
| **Mean reward** | 전문가 루브릭 기준 부분 크레딧의 평균 — 과제를 완전히 푼 비율이 아님 |
| **xhigh** | 이 평가에서 모든 모델에 공통 적용된 최고 추론 노력 설정 |

## 한줄 정의

2026-11-06 OpenAI 발표 "Measuring how AI agents handle everyday wet-lab science" — 효소 설계 기업 Ligo와 함께 BioBasicsBench를 공개했다. 논문의 깔끔한 차트가 아니라 실제 실험실에서 나오는 날것의 증거(젤 이미지·현미경 사진·기기 출력)를 읽고, 오류를 잡고, 증거가 부족하면 결론을 보류할 수 있는지를 묻는 100개 과제다. 최고 추론 설정(xhigh)에서 GPT-6 Astra가 평균 66.7%의 루브릭 크레딧을 얻었다. 단, 테스트한 7개 모델이 전부 OpenAI 자사 모델이고, 인간 기준선과 데이터셋은 함께 공개되지 않았다.

## 핵심 내용

- **과제 구성**: 100개 과제는 단백질 방법·이미징과 세포계측·정량과 분석·핵산 방법·분자 클로닝 5개 영역이다. 입력은 젤·블롯 이미지 31개, 프로토콜·노트·사양 27개, 표·기기 출력 20개, 현미경 14개 과제(유형이 겹쳐 합이 100이 되지 않는다). Ligo 과학자들이 자기 실험 데이터로 과제를 만들고 전문가 루브릭을 붙였으며, 다른 Ligo 과학자 1명과 외부 젖은 실험실 박사 1명의 검토를 거쳤다.
- **평가 규모**: 7개 모델 × 37개 모델·추론 설정 조합, 과제당 5회 시도, 총 18,500개의 채점 응답. 점수는 부분 크레딧을 주는 루브릭 평균 보상(mean reward)으로, 과제를 완전히 푼 비율이 아니다.
- **결과(xhigh, 최고 추론 설정)**: GPT-6 Astra 66.7%(95% CI 60.3–73.1%, 과제당 출력 토큰 4,704개), GPT-6.1 Sol 62.0%, GPT-5.6 Sol 43.8%, GPT-6 Luna 38.3%, GPT-5.5 35.4%, GPT-5.4 33.2%, GPT-5.2 31.2%. Astra는 GPT-5.6 Sol보다 약 절반의 출력 토큰으로 더 높은 점수를 냈다.
- **OpenAI의 단서**: "점수가 높아졌다고 해서 모델이 실험실에서 신뢰할 만한 판단을 내릴 수 있다는 뜻은 아직 아니다"라고 밝혔다. 벤치마크는 목표점이지 판정이 아니라는 프레이밍이다.
- **한계**: 7개 모델이 전부 OpenAI 자사 모델이라 경쟁사와의 비교는 안 된다. 발표 시점에 논문·데이터셋·전체 루브릭·평가 코드·원시 결과 링크가 없었다. 100개 과제만으로 모든 기기·시료·실험 맥락을 대표할 수 없다.

## 왜 중요한가 (1인 개발자 관점)

1. **에이전트 평가가 "깨끗한 문제"에서 "지저분한 증거"로 이동했다**: 기존 벤치는 정답이 있는 문제였다. BioBasicsBench는 증거가 모호하고 오류가 섞인 현실 데이터를 읽는 능력을 잰다. 에이전트를 실제 업무에 쓸 때 필요한 능력은 정답 맞히기가 아니라 "모른다고 말하기"와 "오류를 잡기"다. 이 벤치는 그 방향의 기준점이 된다.
2. **세대 간 격차가 크다**: Astra 66.7% vs GPT-5.6 Sol 43.8% — 한 세대 만에 23pp 가까이 벌어졌다. 그것도 절반의 토큰으로. 모델 선택의 기준이 "최신인가"에서 "이 업무에서 얼마나 효율적인가"로 바뀌고 있다.
3. **생명과학 에이전트의 문이 열린다**: Rosalind(승인 연구소 전용 수직 모델)에 이어, 이제 그 능력을 재는 공개 벤치까지 나왔다. 과학 에이전트는 더 이상 연구실의 호기심이 아니라, 평가 가능한 제품 영역이 되고 있다. 다만 점수가 곧 현장 신뢰는 아니라는 OpenAI의 단서를 그대로 받아들여야 한다.

## 한계 (명시)

- 7개 모델이 전부 OpenAI 자사 모델이라, 경쟁 모델과의 비교는 불가능하다. 점수는 OpenAI의 자체 보고다.
- 발표 시점에 데이터셋·루브릭·평가 코드가 공개되지 않아 독립 재현이 불가능하다.
- 66.7%는 부분 크레딧 평균이지 과제를 완전히 해결한 비율이 아니며, 인간 기준선이 없어 절대 수준을 가늠하기 어렵다.
