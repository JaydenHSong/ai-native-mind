# llama.cpp·ggml v1.0.0 출시 — 로컬 AI 추론의 안정 공개 API 약속 (11-13)

## 쉽게 읽기

**비유**: 매일 조금씩 바뀌던 설계도가 이제 "이 부분은 바꾸지 않겠다"는 약속이 붙은 정식 도면이 된 것이다. 이 도면으로 집(앱)을 지으면, 나중에 도면이 바뀌어 집이 무너지는 일이 줄어든다.

| 용어 | 풀이 |
| **llama.cpp** | 노트북·폰·서버에서 LLM을 돌리는 오픈소스 C/C++ 엔진 |
| **ggml** | llama.cpp 아래에서 텐서(숫자 묶음) 계산을 맡는 라이브러리 |
| **시맨틱 버저닝** | 버전 숫자 자체가 변경 성격을 알려주는 규칙. 메이저=호환 깨짐, 마이너=기능 추가, 패치=버그 수정 |
| **공개 API** | 다른 프로그램이 불러 쓰는 공식 함수들의 집합. 바뀌면 그걸 쓰는 앱이 고장 난다 |
| **추측 디코딩(speculative decoding)** | 작은 모델이 답을 미리 써보고 큰 모델이 검수하는 식으로 속도를 내는 방법 |
| **KV 캐시** | 모델이 이전 대화를 기억하기 위해 저장해 두는 계산 결과. 클수록 메모리를 많이 쓴다 |
| **FP8** | 숫자를 8비트(1바이트)로 줄여 저장하는 방식. 메모리와 속도를 아낀다 |

## 한줄 정의

2026-11-13 — ggml-org 팀이 llama.cpp v1.0.0과 그 아래 텐서 라이브러리 ggml v1.0.0을 출시했다. 프로젝트 시작(2023-03-10) 후 3년 반 만의 첫 1.0이다. 핵심은 속도가 아니라 약속이다. 앞으로 공개 C API를 깨는 변경은 메이저 버전 상승과 함께만 온다.

## 핵심 내용

- **버전 약속**: 두 라이브러리 모두 시맨틱 버저닝을 적용한다. MAJOR 상승은 공개 C API(`./include` 헤더) 변경, MINOR는 하위 호환 기능·백엔드 업데이트·모델 지원 추가·API 추가, PATCH는 API 변경 없는 버그 수정이다. 지금까지는 커밋 번호(b12359 등)로 버전을 매겼고 인터페이스가 수시로 바뀔 수 있었다.
- **정리**: 35개의 deprecated 공개 함수를 제거하고, warmup 설정과 defragmentation-threshold 옵션을 없앴다. NextN 추측 디코딩 API를 확장 헤더(llama-ext.h)에서 메인 공개 헤더(llama.h)로 승격했다. ggml 1.0은 deprecated API와 레거시 DIAG_MASK 연산을 제거하고, 설정 가능한 YaRN truncation과 FP8 지원을 더했다.
- **기능**: FP8 키-값(KV) 캐시를 추가했다. Qwen2.5-7B 기준 32,768 토큰 KV 페이로드가 1,792 MiB에서 896 MiB로 절반이 된다(계산치). 호스트 메모리 MoE 전문가 캐시, 새 웹 UI도 포함됐다. llama-server는 SSRF·DNS 리바인딩·MCP 도구 취소에 강해졌다.
- **규모**: 150개 이상의 모델 아키텍처 변형을 지원한다. GitHub 스타 약 135,000개, MIT 라이선스. ggml-org 팀은 2026-02부터 Hugging Face 소속으로 프로젝트를 유지한다. v1.0.0은 빌드 b12359와 일치하고, 이후 빌드도 이미 나왔다. 릴리스 노트는 29,000자가 넘는다.

## 왜 중요한가 (1인 개발자 관점)

1. **로컬 AI 앱의 기반이 안정됐다**: 내 맥·PC에서 모델을 돌리는 앱을 만들 때, llama.cpp API가 예고 없이 바뀌던 리스크가 줄었다. 1.x를 쓰면 공개 API는 유지된다는 약속이 있으니, 장기 프로젝트의 기반 라이브러리로 고를 수 있다.
2. **작은 기기에서 긴 대화가 싸졌다**: FP8 KV 캐시로 32K 토큰 대화의 메모리 부담이 절반이 된다. 맥 미니·노트북 같은 로컬 환경에서 에이전트를 오래 돌릴 때 체감되는 개선이다.
3. **보안 기본값이 올라갔다**: llama-server의 SSRF·DNS 리바인딩 방어는 로컬 서버를 네트워크에 노출할 때의 구멍을 메운다. 내 하네스의 로컬 추론 서버를 열 때 챙길 항목이다.

## 한계 (명시)

- 공식 발표나 릴리스 노트에 전후 속도 측정 수치는 없다. 성능 개선 작업은 설명하지만 백분율로 제시하지 않았다.
- v1.0.0의 약속은 공개 C API에 한정된다. 내부 동작·비공개 인터페이스는 여전히 바뀔 수 있다.
