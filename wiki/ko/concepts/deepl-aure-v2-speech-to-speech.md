# DeepL Aure v2 — 음성→음성 직통 번역 모델, 지연 50% 단축

## 쉽게 읽기

**비유**: 예전 통역은 세 사람이 이어달리기를 하는 식이었다 — 한 사람이 듣고 받아쓰고, 다음 사람이 번역하고, 마지막 사람이 소리 내어 읽었다. Aure v2는 한 사람이 듣자마자 바로 다른 언어로 말하는 식이다. 중간에 넘기는 과정이 없으니 훨씬 빨리, 말하는 사람의 목소리 느낌(리듬·억양)도 그대로 살린다.

| 용어 | 풀이 |
|------|------|
| **음성→음성 (speech-to-speech)** | 말소리를 받아 번역된 말소리로 바로 바꾸는 방식 — 글자 단계를 거치지 않음 |
| **엔드투엔드 (end-to-end)** | 여러 단계를 거치지 않고 하나의 모델이 처음부터 끝까지 한 번에 처리하는 구조 |
| **중앙값 번역 지연** | 번역된 말이 들리기까지 걸리는 시간의 중간값 — 절반은 이 시간 안에 들림 |

## 한줄 정의

2026-11-26 DeepL이 도쿄 첫 Unmute Summit에서 출시한 음성 AI 번역 모델 Aure v2 — 말→글→번역→음성의 3단계를 거치지 않고 음성을 번역된 음성으로 직접 바꾸는 엔드투엔드 구조로, 전작 대비 중앙값 번역 지연이 50% 줄었다고 한다. DeepL Voice 고객에게 즉시 제공.

## 핵심 내용

- **구조**: 엔드투엔드 음성→음성 모델 + 강화학습. 기존 파이프라인(받아쓰기·번역·음성합성)의 단계 간 핸드오프를 없애 지연을 줄이는 방식. 번역된 음성이 화자의 리듬·억양·강조를 유지한다고 함.
- **수치(자사 주장)**: 전작 Aure 대비 중앙값 번역 지연 50% 감소. DeepL 내부 연구(2026년 11월, 10개 언어쌍·1분짜리 실제 음성 녹음, 인간 검증 전사본) 기준, 번역된 단어의 절반이 3.3초 안에 들린다고 함. 6개 경쟁 시스템 대비 전 언어쌍에서 품질 우위 주장 — 모두 자사 측정, 독립 검증 없음.
- **언어**: 출시 시 6개 — 영어·독일어·프랑스어·스페인어·일본어·한국어. 추가 언어 예정.
- **제공 범위**: DeepL Voice for Online Meetings(Teams·Zoom·Meet), Voice for In-Person Conversations, DeepL API for Voice. 지원 언어에서는 자동으로 켜지며 별도 설정 없음. 가격은 미공개.
- **속도**: 전작 Aure는 11월 11일 출시 — 불과 15일 만의 후속. DeepL Voice 사용량은 2026년 3분기 기준 전년 대비 음성 분 8배 이상, 번역 회의 분 7배가량 증가.

## 왜 중요한가 (1인 개발자 관점)

1. **음성 에이전트의 '지연' 경쟁**: Grok Voice 3.0 등 음성 AI 축과 같은 흐름 — 실시간 대화에서는 정확도만큼이나 지연이 체감 품질을 결정한다. 3단계 파이프라인을 단일 모델로 합치는 건 음성 에이전트 전반의 방향이다.
2. **15일 만의 후속 출시 속도**: Aure(11-11)에서 Aure v2(11-26)까지 15일 — 음성 모델의 개선 사이클이 주 단위로 짧아지고 있다. 버전 번호보다 '무엇이 바뀌었는지'를 매번 확인해야 하는 시기다.
3. **자사 수치의 읽는 법**: 지연 50% 감소·3.3초·6개 경쟁 시스템 우위 — 전부 DeepL 내부 연구 기준이며 독립 검증이 없다. '전작 대비'라는 상대 수치와 '절대 수치'(3.3초)를 구분해서 읽어야 한다.

## 한계 (명시)

- 모든 성능 수치는 자사 내부 연구(DeepL) — 독립 검증 없음. 6개 경쟁 시스템 대비 품질 우위도 자사 주장.
- 가격은 미공개. 출시 언어는 6개로 제한.
- 전작 출시 15일 만의 후속이라, v2의 개선이 얼마나 지속 가능한지·실사용 체감은 미확인.
