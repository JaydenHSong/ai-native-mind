# GPT-4 시리즈 일괄 은퇴 — OpenAI의 세대 교체 선언

## 한줄 정의

OpenAI가 2026-10-14 공식 이메일로 API 사용자에게 통지한 **GPT-4o·GPT-4o mini·GPT-4.1·GPT-4.1 mini** 4개 모델의 일괄 은퇴 — GPT-4 시리즈에서 GPT-6 계열로의 세대 교체를 공식화한 모델 라이프사이클 관리.

## 핵심 내용 (OpenAI 공식 이메일 1차 출처, "Plan your transition from GPT-4 series to newer OpenAI models")

- **은퇴 대상**: GPT-4o, GPT-4o mini, GPT-4.1, GPT-4.1 mini — 4개 모델 일괄 은퇴 예고.
- **사유** (OpenAI 주장): 신형 모델이 더 강한 역량과 안전 성능 제공.
- **성격**: API 사용자에게 보낸 전환 계획 통지 — 마이그레이션 안내. 은퇴 시점·유예 기간의 구체 날짜는 이메일 앞부분에 명시되지 않음(상세 확인 필요).
- **위치**: GPT-4 시리즈(GPT-4o 계열) → GPT-6 계열(Astra·Sol 등)로의 세대 교체 공식화. 10/11 GPT-6.1 Sol Ultrafast 가격대 양극화와 같은 흐름.
- 언론 후속 보도 미확인 — 1차 출처 단일, 교차검증 대기.

## 왜 중요한가

1. **라이프사이클이 가격 결정력의 뒷받침**: [[concepts/gpt-61-sol-ultrafast]]의 6배 프리미엄이 설득력을 얻으려면 구세대의 저가 옵션이 사라져야 한다 — 은퇴는 프리미엄 가격대의 **전제 조건**. [[comparisons/frontier-lab-economics]]의 "가격 결정력"이 제품뿐 아니라 은퇴 스케줄에서도 만들어짐.
2. **API 마이그레이션의 강제 타임라인**: [[patterns/ai-cost-management]]의 3축 라우팅(속도·가격·품질)에 "모델 은퇴"라는 4번째 변수 — 라우팅 규칙에 deprecated 모델의 강제 이관 경로를 미리 넣어 두는 이유.
3. **공지의 경로**: 수신자 jsong@spigen.com — OpenAI가 API 사용자에게 직접 보내는 공지 이메일이 원본 소스가 됨. 이메일 구독이 모델 라이프사이클의 1차 감지 채널.

## 한계 (명시)

- 단일 1차 출처(이메일), 언론 후속 보도 미확인.
- 은퇴 시점·유예 기간 미확인 — 후속 이메일 확인 필요.
