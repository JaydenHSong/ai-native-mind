# OpenAI and ServiceNow Expand: ServiceNow Workflows Inside ChatGPT, Permissions Intact

## TL;DR

On 2026-10-28 OpenAI and ServiceNow announced an expanded partnership that connects in both directions: OpenAI models and agents go into ServiceNow products, and ServiceNow workflows go into ChatGPT and Codex. A ServiceNow MCP plugin for ChatGPT went live the same day, and ServiceNow's Action Fabric applies the organization's existing business rules and permissions inside ChatGPT, so an agent can only do what the user is already allowed to do. Codex, joint security products, and voice features follow on a 2027 roadmap.

## Key facts

- **Bidirectional connection**: not a one-way chatbot integration — OpenAI models and agents enter ServiceNow, and ServiceNow workflow actions enter ChatGPT and Codex, with ServiceNow remaining the system where actions execute and are governed.
- **The plugin in practice**: find similar incidents, assess change risk, and update ServiceNow records from inside a ChatGPT conversation. The plugin went live on October 28, 2026, with enhanced functionality expected by the end of 2026.
- **Roadmap**: Codex integration in AI Workflow Factory; joint Security and Risk solutions powered by OpenAI cyber models (early access January 2027, general availability Q2 2027); voice-driven governance and risk assessment for the Super Intelligence Control Tower (Q1 2027 target).
- **Mutual internal rollout**: ServiceNow will give all employees ChatGPT Work and Codex (previously engineering-centered); OpenAI will adopt ServiceNow across its workforce and join ServiceNow's Control Tower Alliance as a founding member.
- **Background**: the expansion extends the multi-year agreement of January 20, 2026, which made OpenAI models the preferred intelligence capability on the ServiceNow AI Platform. ServiceNow pursues a multi-model strategy alongside Google Cloud and NVIDIA.

## Why it matters

1. **The standard enterprise-agent pattern**: the hard problem in "conversation to governed action" is permission delegation, not model quality. Inheriting existing permissions, as Action Fabric does, is the gate for enterprise adoption.
2. **MCP's enterprise proof point**: MCP moves from an experimental protocol to connections into production business systems with approvals. Permission and audit-trail thinking belongs in personal MCP skill design too.
3. **The lock-in paradox**: the more convenient it is to use ChatGPT inside ServiceNow, the more workflows bind to that platform. Check export and API portability before committing.

## Limitations

- Everything beyond the plugin (Codex integration, security solutions, voice) is a scheduled roadmap item; actual release and quality are unconfirmed.
- The permissions-intact claim comes from the companies' announcements; no independent security audit result is available yet.
- The announcement centers on US availability; coverage in other regions needs separate confirmation.
