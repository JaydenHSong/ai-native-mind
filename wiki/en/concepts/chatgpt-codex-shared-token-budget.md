# ChatGPT and Codex Shared Token Allowance — One Budget for Chat and Coding from December

## Start here

**Analogy**: until now there were two cards, one for chat and one for coding. From December there is one wallet paying for both. A long afternoon of coding-agent work shrinks the evening's chat budget.

| Term | Meaning |
|------|---------|
| **Token usage** | Consumption measured in tokens, the units of information a model processes and generates |
| **Instant chat** | A lightweight chat mode excluded from the shared allowance |
| **Work** | The agentic work mode inside ChatGPT, merging toward Codex |

## One-line definition

Starting in December 2026: Plus, Pro, and Business plans share one token-based usage allowance across ChatGPT and Codex, as Work's agentic capabilities merge into the main ChatGPT experience.

## Key facts

- **Scope**: Plus, Pro, and Business plans. Chat and coding previously had effectively separate budgets. Developer billing via API platform keys is reported to stay separate.
- **Measurement**: tokens, not message counts. More capable models and more complex tasks burn the allowance faster. Per-plan totals and extra-credit prices are unpublished.
- **Exception and visibility**: Instant chat does not draw from the allowance. Combined remaining usage and reset times appear in Settings → Usage.
- **At the limit**: wait for the reset, upgrade the plan, or buy credits. OpenAI expects most users will not need to wait for resets more often than today — a forecast, not a guarantee.
- **Background**: the change extends the previously announced Chat–Work merger, after higher-tier plan limits were doubled. Anthropic has likewise merged chat and Cowork in Claude.

## Why it matters (solo-developer view)

1. **The budgeting unit changes**: managing coding-agent usage and chat usage separately stops working in December. Heavy agent work eats the chat budget.
2. **The "unlimited" narrative ends**: Plus usage that felt flat-rate becomes an explicit token meter. Checking the Settings → Usage dashboard regularly becomes a routine.
3. **Instant is a lightweight lane, not a loophole**: route light queries to Instant and schedule heavy agent work with the budget in mind — but without published per-plan totals, exact planning is impossible until December dashboards go live.

## Limitations (stated)

- Confirmed through secondary coverage of an OpenAI Help Center article; the exact start day, per-plan totals, and credit prices are unpublished.
- "Will not need to wait more often" is OpenAI's forecast, not measured data.
- December 31 has been mentioned in some coverage for related limit structures, but the official start is confirmed only as "December."
