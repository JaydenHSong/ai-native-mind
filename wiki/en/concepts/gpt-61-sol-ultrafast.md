# GPT-6.1 Sol Ultrafast — 8x Speed Tier (2026-10-08)

## One-line definition

OpenAI's new top speed tier for GPT-6.1 Sol — up to 8x faster token generation than standard, at 6x the API price.

## Key points

- **Launch**: GPT-6.1 Sol Ultrafast — for API, Codex, and ChatGPT Work. Up to 8x faster token generation than standard.
- **Pricing**: 6x the standard API rate — $12 per 1M input tokens, $60 per 1M output tokens.
- **Access**: limited to Pro 500 subscribers, usage-based Enterprise, and credit-based Edu plans for Work/Codex products. Pay-as-you-go developers can use it via API.
- **Data residency**: US and EU supported.
- **Developer complaints**: concerns about surging token consumption in fast mode, and being forced into higher-plan upgrades rather than choosing a speed option on the current tier.

## Why it matters

For the AI-native programmer, Ultrafast signals an era where **latency is pricing power**. While Claude Haiku 5.5 drops API prices by up to 90%, OpenAI climbs with a 6x premium for 8x speed — price-tier polarization unfolding simultaneously. From a harness-design view, "speed tier" becomes a new routing axis: conversational coding agents (Codex) on Ultrafast, batch evaluations on standard, lightweight tasks on Haiku-class — a more refined **speed-price-quality three-axis routing**. Token-consumption surge concerns connect directly to agent-loop runaway cost risk, so spend caps remain essential.
