# 2026-05-18 Learning Journal — harness shape · compiled skills · version-upgrade eval

## Start here

These three papers pointed to the same conclusion:

> **Agent performance depends not only on the model, but on how the harness allocates budget, how skills are packaged for runtime use, and what unit of work the evaluation actually measures.**

## Sources ingested

- **Effective Harness Engineering** — budget allocation, anti-gaming, and worktree isolation for coding agents.
- **SkillSmith** — compiling agent skills into boundary-guided runtime interfaces.
- **RoadmapBench** — evaluating long-horizon development through version-upgrade tasks.

## Main synthesis

- Better harnesses prefer **fewer, deeper attempts** over shallow fan-out when budget is fixed.
- Skills should be treated less like long natural-language documents and more like **compiled runtime interfaces**.
- Coding evaluation should move beyond bug fixes toward **release-to-release roadmap execution**.
