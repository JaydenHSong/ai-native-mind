## 1-A. ACDL — a notation language for context composition

**One-line summary**: if Context Engineering is becoming a discipline, it needs notation. ACDL describes role-message sequences, dynamic content, time-indexed references, and conditional/iterative structures so that sketches and formal code can express the same context structure.

- Four components: role-message sequence / dynamic content / time-indexed reference / conditional·iterative structure.
- Accepted at CAIS ’26; tooling, examples, and docs are available at <http://www.acdlang.org>.
- Wiki change: [[concepts/context-engineering]] gained a 2026-05-15 update section.

**Pairing**: Mise en Place (2026-05-12) describes the *process* of preparing context; ACDL describes the *shape* of the resulting context. GROUNDING.md defines constraint text; ACDL can describe how that text is injected into a prompt.

## 1-B. Constraint Decay — structural constraints can cost around 30 points

**One-line summary**: benchmarks that only check functional success hide a major reality of LLM agents. When architectural, database, and ORM constraints accumulate, even capable model configurations can drop by about 30 points, while weaker configurations approach zero.

- 100 tasks: 80 greenfield + 20 feature-implementation tasks.
- 8 web frameworks under a unified API contract.
- Framework sensitivity: Flask was stronger; FastAPI and Django were weaker in this setup.
- Main root cause: **data-layer defects**, especially query composition and ORM runtime violations.
- Wiki change: [[patterns/ai-code-review]] gained a structural-verification layer: **Phase 2.5 Structural Verify** inside Plan → Review → Execute.

**Pairing**: Verify Before You Fix (2026-05-13) grounded security repair in exploit reproduction. Constraint Decay adds a different verifier: framework-idiom / structural verification beside functional verification.

## 1-C. GroupMemBench — first measurement of multi-party memory

**One-line summary**: most memory systems assume a 1:1 setup. When group/channel structure appears, even the strongest system reaches only 46.0%; knowledge-update questions drop to 27.1%, term ambiguity to 37.7%, and simple BM25 matches or beats many agent-memory systems.

- Six question categories, adversarial queries, and graph-grounded synthetic multi-party conversations.
- Makes Theory-of-Mind-like memory properties visible: audience-adapted language and speaker-grounded belief.
- Wiki change: [[concepts/ai-memory-systems]] gained a 2026-05-15 update section.

**Pairing**: ZenBrain’s Autobiographical/Self layer is close to GroupMemBench’s speaker-grounded belief tracking. ZenBrain is an architectural prescription; GroupMemBench measures what happens when such structure is absent.
