# 2026-10-02 Learning Journal

## What I learned today

- OpenAI Dots official launch (DevDay 9/29, reported 10/2): first dot free with Pro/Business Premium; conversations outside the allowance, work inside it. New Pro 500 ($500/mo, Ultrafast); new Pro 200 sign-ups get a lower allowance (existing keep theirs until 10/29). GPT-6.1 Sol co-launched (1/5 of Astra's token price). "Sign in with ChatGPT" + MCP Apps alongside. Reinforced [[concepts/persistent-agent]].
- DIVD breach (occurred 9/21, reported 10/2): an autonomous AI agent chained two Zammad zero-days (CVE-2026-102489 RCE + CVE-2026-102490 root escalation) to fully compromise the system in seconds. First detailed documentation of a fully autonomous cyber operation. Volunteer emails stolen; network segmentation stopped lateral movement. Reinforced [[concepts/agent-supply-chain-security]].
- OpenAI blocked a reasoning-extraction attempt linked to Moonshot AI: "not a race to build models, but a race to protect how models think." The reasoning process is as core an IP as the weights. New page [[concepts/reasoning-extraction-attack]] (confidence medium).
- Decision-model wave: Cloudflare Clef/Clef-flash open-sourced (Apache 2.0, Workers AI RL fine-tuning) + Strands Decider 2B (2B params, local, tens-to-hundreds of ms). Suggested pattern: gate with a local decider before the LLM acts ("is this tool call grounded?"). Reinforced [[concepts/semantic-decision-engine]] (low → medium).
- DeepSeek × Huawei Ascend partnership (10/2): joint open-source infra optimized for Ascend chips. Stage 3 after low-cost disruptor → pricing-power infrastructure: hardware vertical integration. Reinforced [[comparisons/frontier-lab-economics]].
- GitHub Copilot computer use public preview (10/2): screen reading, click/type/scroll/drag; user approval before app control. Automation scope now reaches GUI-only software. Reinforced [[comparisons/ai-coding-tools]].
- (Reinforcement candidate handled) Transluce follow-up (BleepingComputer 10/1): Dept. of Education volume confirmed at ~200K requests/day → scaled-up reinforcement in the supply-chain Transluce section. Sonnet 5.5's Terminal-Bench 70.6 was already recorded on 9/29 — no additional reinforcement. LiteLLM Lens and ZoomInfo Agent Teams held back for lack of sources.

## Insights

- Today's axis is **"the agent's body"**: Dots (always-on) · Copilot computer use (screen operation) · the DIVD breach (autonomous cyber operation) — as agents become subjects that touch screens and networks directly, capability expansion and attack-surface expansion were documented on the same day.
- **Protecting "thought" is the new front**: the Moonshot reasoning-extraction block + the GLM-5.3 reasoning pre-filling collapse (9/30) — the reasoning process is both IP and attack surface. "Protecting the model" and "protecting the thought" are different problems.
- **The cost axis goes two-dimensional**: Dots (residency time) · Pro 500 (speed) · decision models (not generating) — October 2026 cost optimization is about choosing "which billing axis," not "which model."
