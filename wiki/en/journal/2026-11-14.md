# 2026-11-14 Learning Journal

## What I learned today

- **Sierra Poppy 1.0** (Sierra, Nov 13): Personal Agent Protocol 1.0 launched. The standard by which a personal agent discovers a business and negotiates the actions it is allowed to take, built on MCP, OpenAPI, and Shopify UCP, with OAuth letting the user control permissions. Every Shopify store in 175+ countries auto-publishes a poppy.json (no extra merchant implementation), and Meta Muse is switched on for all users, looking for Poppy first on every site it visits. 60 new design partners joined, passing 100 in total. Live deployments: Mercury (balance and transaction lookups, payments and transfers initiated under an approval policy), Synchrony (finance- and rewards-linked shopping), and Turkish Airlines (fare and booking lookups, mileage business upgrades). But the spec is still labelled draft 1.0, so breaking changes are possible.
- **OpenAI ChatGPT Wallet** (Reuters, Nov 13): the always-on dots agent completes payments on the user's behalf. After the user checks the item, total, and card and approves with Face ID or a fingerprint, the payment network issues a tokenized substitute card number, and neither the agent nor the merchant sees the real card number. Built jointly with Amex, Mastercard, and Visa; fraud detection from Forter, Riskified, Sardine, and Signifyd; payment processing from Adyen, Checkout.com, and Stripe. US ChatGPT Pro, 18+, eligible US-issued credit cards only; debit and virtual cards unsupported; works only inside a dot conversation (not Chat, Work, or Codex). 0% OpenAI fee at launch. OpenAI says ChatGPT has 1.2 billion weekly users. In the opposite direction, United Airlines changed its contract of carriage on 2026-11-11 to ban unauthorised AI agents from buying tickets — payment and merchant permission are separate fights.
- **FBI ARTEX warning** (Nov 13, FLASH-20261113-001): the open-source autonomous penetration-testing framework ARTEX is being weaponized by criminal and state-linked actors. Some intrusions went from first target identification to privilege escalation in under three hours. Google observed individual automated bursts of 2–25 seconds. Use observed since at least 2026-08 across finance, government, technology, defence, energy, and healthcare; an attack on a South Korean financial institution exposed personal data of about 67,000 people; a ConnectWise Cloud Backup supply-chain breach led to targeting attempts against more than 2,250 downstream tenants (not a confirmed breach count); more than 1,600 publicly exposed consoles as of early November (exposure is not exploitation). Microsoft linked ARTEX to the China-linked Storm-0940, and in one case an agent went from searching GitHub secrets to seizing an Azure Key Vault in five minutes. The developer deleted the repository on 2026-10-08, but forks and copies circulate. FBI advice: restrict exposed admin tools, shrink app permissions, scan repositories for secrets.
- **DeepSeek app features opened to the API** (Nov 13, official API changelog): DeepSeek opened its consumer app's features to the developer API. Web search with citations (including a deep-thinking search mode), image search, file input (PDF, Office, images), URL reading, voice interaction, and safety checks are handled server-side. deepseek-flash now points to V4.1-Flash-1017 (a dated refresh of the September release, API behaviour and token prices unchanged). Search and Fetch at $0.75 per 1,000 calls, OCR at $0.225 per 1,000 pages, ASR and TTS at a 50% launch discount. deepseek-flash token prices are $0.15 input / $0.60 output per million tokens off-peak, double at peak. Public apps built on the API must enable safety checks, and an open-source demo chat client was released alongside.
- **OpenAI disbands its robotics team** (Fortune exclusive, Nov 13, confirmed by a company spokesperson): OpenAI disbanded its standalone robotics team — the second disbanding (the first in 2020–21). The judgement is that general-purpose frontier models, especially GPT-6 Astra, can now be applied directly to robot control, so a separate team building robot-specific models is no longer the fastest path. Research staff moved into the main research organisation under Chief Research Officer Mark Chen; applied robotics and hardware staff moved to the Applied organisation under President Greg Brockman. The evidence is Nvidia's 2026-10-14 research: the GPT-6 Astra agent scored 74.8% on the simulated pick-and-place benchmark RoboLab-120, ahead of the best specialist robot model at 51.0%. But this is a simulation result, not physical-robot evidence, and it costs about $36.40 in tokens per call and takes about 18.56 seconds. Robots remain central to the long-term vision, and the 2027 humanoid demo target stands. Headcount undisclosed, no company blog post. Fortune also reported a $10.9 billion operating loss in the most recent quarter and the possibility of an IPO in early 2027.
- **Cloudflare Kitesurf open-sourced** (Unite.AI, Nov 13): the AI-agent browser engine Kitesurf was released under the Apache 2.0 licence. It fulfils a promise made at the 2026-08-06 launch. Without Chromium or a browser container, it parses HTML, applies CSS, executes page JavaScript, and renders screenshots. It runs entirely on Cloudflare Workers (Rust/WASM components) and exposes CDP endpoints for Puppeteer and agent harnesses. Developers can inspect, modify, and run it locally, or self-host it on their own Workers account (a paid plan is required). But it is still experimental, Chrome/web-platform compatibility is incomplete, and self-hosting requires adding authentication yourself (no built-in auth; workers.dev URLs are public by default). Cloudflare's claim that it uses less CPU and memory than Chromium has no published measurements, so it is unverified.

## Insight

**The day agents opened the door (Poppy), paid the money (Wallet), and read the web directly (Kitesurf), the only work left for humans is scope and approval — and the moment that threshold is lowered, attackers walk through the same door (ARTEX).** Yesterday's (Nov 13) "the seats left for humans are three: scope, approval, accountability" gets sharper today. Poppy, Wallet, and Kitesurf opened the agent's entrance, wallet, and browser on the same day, and OpenAI declared that even robots belong to general models now. Yet on that very day, the FBI warned that agent-led intrusion is already happening on a three-hour cycle. Convenience and security in the agent era share the same door — the wider the door opens, the faster the lock has to be designed. The same applies to a solo developer's harness. The more you hand the agent — entrance, wallet, browser — the firmer the three thresholds of scope, approval, and accountability must be.
