# 2026-05-19 Learning Journal — trajectory audit · virtual memory · natural-language harness

## Start here

Today’s sources widened the meaning of the harness both downward into systems and upward into policy documents.

## Sources ingested

- **HarnessAudit** — audit the full execution trajectory, not only the final output.
- **ClawVM** — manage memory with a harness-side virtual-memory contract.
- **Natural-Language Agent Harnesses** — move policy out of controller code into explicit natural-language harness objects.

## Main synthesis

- Evaluation now needs **trajectory boundary audit** rather than only success/failure scoring.
- Memory is not only a retrieval store; it can be a **runtime contract** with writeback and reset rules.
- `CLAUDE.md` / `AGENTS.md`-style files can be read as **policy objects** in the harness layer.
